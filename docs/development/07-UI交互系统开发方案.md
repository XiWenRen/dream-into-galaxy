## 2. 技术选型

### 2.1 选型: React 原生 useState/useRef + useMemo/useCallback

**原因**：
1. 当前状态复杂度可控（约 20 个状态项），无需 Redux/Zustand
2. 高频更新状态（timeState）使用 useRef 避免不必要重渲染
3. useMemo 缓存昂贵的派生计算（节气、月相等）

**未来演进**: 若状态复杂度超过 30 个独立状态项，或出现跨组件深层传递，迁移至 Zustand。

### 2.2 选型: Tailwind CSS v4 + CSS 变量实现主题

**原因**：
1. 原子化 CSS 快速实现复杂布局
2. 主题通过 CSS 变量切换，无 JS 运行时开销
3. v4 版本内置性能优化

**主题切换实现**：
```css
:root {
  --primary: #00d4ff;
  --background: #0a0e27;
  /* ... */
}

[data-theme="solar-gold"] {
  --primary: #f59e0b;
  --background: #1a1200;
  /* ... */
}
```

### 2.3 选型: Framer Motion（仅限 UI 动画）

**原因**：
1. 面板滑入/滑出、按钮缩放等 DOM 动画声明式实现简洁
2. AnimatePresence 处理组件卸载动画
3. 明确边界：Framer Motion 不管 Canvas 动画

### 2.4 选型: 对象字典实现 i18n

**原因**：
1. 项目词汇量约 500 条，对象字典完全够用
2. 无需 react-i18next 等库的额外依赖
3. 切换语言只需替换字典对象

```typescript
const translations = {
  zh: { planet_earth: '地球', term_chunfen: '春分', ... },
  en: { planet_earth: 'Earth', term_chunfen: 'Spring Equinox', ... }
};
```

## 3. 实现步骤

### Step 1: App.tsx 状态架构

```typescript
export default function App() {
  // 核心状态
  const [timeState, setTimeState] = useState<TimeState>({
    currentTimestamp: Date.now(),
    speedMultiplier: 1,
    isPaused: false
  });
  const [selectedPlanetId, setSelectedPlanetId] = useState('sun');
  const [landed, setLanded] = useState(false);
  const [latitude, setLatitude] = useState(31.23);
  const [longitude, setLongitude] = useState(121.47);
  const [theme, setTheme] = useState<ThemeType>('space-tech');
  const [lang, setLang] = useState<'zh' | 'en'>('zh');
  
  // 派生计算
  const daysSinceJ2000 = useMemo(() => 
    TimeEngine.getDaysSinceJ2000(timeState.currentTimestamp),
    [timeState.currentTimestamp]
  );
  const solarTermData = useMemo(() => 
    AstrophenomenaEngine.getCurrentSolarTerm(daysSinceJ2000),
    [daysSinceJ2000]
  );
  
  // 时间推进循环
  useEffect(() => {
    let animId = 0;
    let lastTime = performance.now();
    const loop = (now: number) => {
      const deltaSec = (now - lastTime) / 1000;
      lastTime = now;
      setTimeState(prev => {
        if (prev.isPaused) return prev;
        return {
          ...prev,
          currentTimestamp: TimeEngine.tick(prev.currentTimestamp, prev.speedMultiplier, deltaSec)
        };
      });
      animId = requestAnimationFrame(loop);
    };
    animId = requestAnimationFrame(loop);
    return () => cancelAnimationFrame(animId);
  }, []);
  
  // ...
}
```

**关键点**: 时间推进使用 rAF 而非 setInterval，确保与渲染帧同步。

### Step 3: 控制面板实现

```typescript
// CommandPanel.tsx
interface Props {
  timeState: TimeState;
  onTimeStateChange: (state: TimeState) => void;
  theme: ThemeType;
  onThemeChange: (theme: ThemeType) => void;
  lang: 'zh' | 'en';
  onLangChange: (lang: 'zh' | 'en') => void;
  // ...

export default function CommandPanel({
  timeState, onTimeStateChange, theme, onThemeChange, lang, onLangChange
}: Props) {
  const t = translations[lang];
  
  return (
    <motion.div 
      className="command-panel"
      initial={{ y: 100, opacity: 0 }}
      animate={{ y: 0, opacity: 1 }}
      transition={{ duration: 0.5 }}
    >
      <div className="time-controls">
        <button onClick={() => onTimeStateChange({ ...timeState, isPaused: !timeState.isPaused })} >
          {timeState.isPaused ? t.play : t.pause}
        </button>
        <Slider 
          value={timeState.speedMultiplier} 
          onChange={v => onTimeStateChange({ ...timeState, speedMultiplier: v })}
          min={1} max={86400} 
        />
      </div>
      <div className="theme-selector">
        {Object.keys(THEMES).map(t => (
          <button key={t} onClick={() => onThemeChange(t as ThemeType)}>{t}</button>
        ))}
      </div>
    </motion.div>
  );
}
```

## 5. 踩坑记录

1. **setInterval 与 rAF 竞争**: 早期使用 setInterval 推进时间，与 rAF 渲染循环产生时序竞争。修正为统一到单一 rAF 循环。
2. **状态更新闭包陷阱**: `setTimeState(prev => ...)` 中访问其他 state 导致 stale closure。修正为将依赖值放入 useEffect 依赖数组。
3. **频繁重渲染**: 时间推进每帧触发 App.tsx 重渲染，导致所有子组件跟着重渲染。修正为：
   - 时间推进使用 useRef 存储 currentTimestamp
   - 只有需要渲染的值（如显示的时间字符串）使用 useState
4. **Framer Motion 与 Three.js 冲突**: Framer Motion 的 layout 动画与 Canvas 尺寸变化冲突。修正为禁用 Framer Motion 的 layout 动画，手动控制 Canvas 尺寸。
5. **i18n 键缺失**: 新增功能时忘记添加英文翻译，导致切换语言后显示 undefined。修正为建立翻译检查脚本。
