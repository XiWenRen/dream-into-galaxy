# 宇宙视角渲染开发方案 (UniverseViewer)

> 版本: v1.0 | 日期: 2026-06-08 | 模块: UniverseViewer (L2 渲染层)

---

## 1. 目标

1. 在 3D 场景中渲染太阳系全景（太阳、行星、卫星、轨道线）
2. 实现太阳光照、行星明暗面、阴影、光晕
3. 支持视觉比例切换（真实比例 vs 对数压缩教学比例）
4. 实现行星球体剖面模式（内部结构展示）
5. 实现相机控制（轨道相机、跟随相机）
6. 渲染银河背景星点和星座连线

---

## 2. 技术选型

### 2.1 选型: 原生 Three.js（非 R3F）

**原因**：
1. 需要深度自定义渲染循环和 BufferGeometry 更新
2. 高频 imperative 更新（每帧修改行星位置）在原生 Three.js 中更高效
3. 双模式切换需要精细控制场景挂载/卸载

### 2.2 选型: 共享 WebGLRenderer（从 App.tsx 注入）

**原因**：
1. 避免 UniverseViewer 和 StarrySkyViewer 各自创建 WebGL 上下文
2. 减少 GPU 显存占用（从 ~600MB 降至 ~300MB）
3. 提升移动端兼容性（多数移动浏览器限制最多 8 个 WebGL 上下文）

**实现方式**：
```typescript
// App.tsx
const rendererRef = useRef<THREE.WebGLRenderer | null>(null);
useEffect(() => {
  const renderer = new THREE.WebGLRenderer({ antialias: true, alpha: true });
  rendererRef.current = renderer;
  return () => renderer.dispose();
}, []);

// UniverseViewer 接收 renderer prop
<UniverseViewer renderer={rendererRef.current} ... />
```

### 2.3 选型: MeshStandardMaterial + 自定义 Shader

**原因**：
1. MeshStandardMaterial 提供 PBR 渲染（roughness/metalness），视觉效果真实
2. `onBeforeCompile` 可注入自定义 Shader 代码（剖面裁剪、云层动画）
3. 无需从头编写完整 Shader，降低维护成本

### 2.4 选型: CanvasTexture 程序化生成

**原因**：
1. 太阳表面、云层等动态效果使用 Canvas 2D 绘制为 Texture
2. 比纯 Shader 方案更易调试和迭代
3. TextureFactory 全局缓存避免重复绘制

## 3. 实现步骤

### Step 1: 场景初始化

```typescript
useEffect(() => {
  if (!renderer || !mountRef.current) return;
  
  const scene = new THREE.Scene();
  const camera = new THREE.PerspectiveCamera(60, width / height, 0.001, 50000);
  const controls = new THREE.OrbitControls(camera, renderer.domElement);
  
  // 太阳点光源
  const sunLight = new THREE.PointLight(0xfff5e6, 2, 1000);
  sunLight.castShadow = true;
  sunLight.shadow.mapSize.set(512, 512); // 性能优化
  scene.add(sunLight);
  
  // 环境光（补充暗面）
  const ambientLight = new THREE.AmbientLight(0x404040, 0.3);
  scene.add(ambientLight);
  
  // 初始化行星 Mesh
  planetsConfig.forEach(config => {
    const geometry = new THREE.SphereGeometry(config.radius, 64, 64);
    const material = new THREE.MeshStandardMaterial({
      map: loadTexture(config.texturePath),
      roughness: 0.8,
      metalness: 0.1
    });
    const mesh = new THREE.Mesh(geometry, material);
    mesh.castShadow = true;
    mesh.receiveShadow = true;
    scene.add(mesh);
    planetMeshesRef.current[config.id] = mesh;
  });
  
  // 动画循环
  const animate = () => {
    requestAnimationFrame(animate);
    controls.update();
    renderer.render(scene, camera);
  };
  animate();
  
  return () => {
    // 清理资源
    scene.traverse(obj => {
      if (obj.geometry) obj.geometry.dispose();
      if (obj.material) {
        if (Array.isArray(obj.material)) {
          obj.material.forEach(m => m.dispose());
        } else {
          obj.material.dispose();
        }
      }
    });
  };
}, [renderer]);
```

### Step 6: 视觉比例实现

```typescript
function getVisualScaleDistance(realAU: number): number {
  if (!useVisualScale) return realAU;
  if (realAU <= 0.5) return realAU;
  return 1.2 + Math.log10(realAU - 0.2) * 1.5;
}
```

**注意**: 视觉比例仅影响渲染距离，不影响轨道引擎输出的物理坐标。

## 5. 踩坑记录

1. **双 WebGL 上下文崩溃**: 早期 UniverseViewer 和 StarrySkyViewer 各创建一个 Renderer，在低端设备上导致上下文丢失。修正为 App.tsx 创建共享 Renderer。
2. **月球轨道未闭合**: 使用 `getLunarRelativePosition` 逐点绘制轨道，因根数变化导致间隙。修正为 `getLunarOrbitPoints` 固定根数绘制。
3. **Texture 重复创建**: 每次切换行星都重新创建 CanvasTexture，导致 GC 压力。修正为 TextureFactory 全局缓存。
4. **剖面 Z-Fighting**: 剖面平面与球体表面重叠闪烁。修正为使用 `polygonOffset` 让剖面靠前。
5. **阴影分辨率过高**: PointLight shadow 2048×2048 占用 96MB 显存。修正为 512×512。
6. **云层材质 depthWrite**: 未设置 `depthWrite: false` 导致云层遮挡背后的恒星/行星。
