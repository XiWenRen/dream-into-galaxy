## 1. 目标

1. 实现 24 个节气的分步演示，按四季分组导航
2. 实现每个节气的精确天文时刻自动跳转
3. 实现物候/诗词/日照观测台三 Tab 信息面板
4. 实现圆形日照表盘（conic-gradient + 实时计算）

## 2. 选型（选型原因）

### 2.1 conic-gradient CSS 实现日照表盘

**原因**：24 小时昼夜分布天然是环形。`conic-gradient` 原生支持角度渐变，无需 Canvas/SVG，性能最优。

```css
background: conic-gradient(
  #1e3a8a 0%,
  #1e3a8a ${(sunrise/24)*100}%,
  #eab308 ${(sunrise/24)*100}%,
  #eab308 ${(sunset/24)*100}%,
  #1e3a8a ${(sunset/24)*100}%,
  #1e3a8a 100%
);
```

### 2.2 精确天文算法计算节气时刻

**原因**：节气时刻由太阳黄经决定。通过 `getSolarTermTimestamp(year, eclipticLongitude)` 逐年计算，确保演示日期与该年真实节气一致。

### 2.3 极昼极夜保护

**原因**：当 `|tan(lat) × tan(decl)| > 1` 时，`cos(ω)` 超出 [-1, 1]。必须钳制到 [-1, 1]，否则 `Math.acos` 返回 NaN。

### Step 2: 节气精确时刻计算

```typescript
// AstrophenomenaEngine.ts
static getSolarTermTimestamp(year: number, eclipticLongitude: number): number {
  // 简化实现：已知春分约在该年3月20日，太阳黄经每天增加约0.9856°
  // 从春分线性外推到目标黄经，再迭代精化
  const springEquinoxApprox = Date.UTC(year, 2, 20, 0, 0, 0); // 3月20日
  const daysFromSpring = (eclipticLongitude - 0) / 0.9856;
  let approxTs = springEquinoxApprox + daysFromSpring * 86400000;
  
  // 迭代精化：搜索太阳黄经最接近目标值的时刻
  let step = 24 * 3600 * 1000; // 1天
  for (let iter = 0; iter < 4; iter++) {
    let bestTs = approxTs;
    let minDiff = Infinity;
    for (let offset = -5; offset <= 5; offset++) {
      const ts = approxTs + offset * step;
      const days = (ts - J2000_TIMESTAMP) / 86400000;
      const lon = this.getSolarLongitude(days);
      let diff = Math.abs(lon - eclipticLongitude);
      if (diff > 180) diff = 360 - diff;
      if (diff < minDiff) { minDiff = diff; bestTs = ts; }
    }
    approxTs = bestTs;
    step /= 5;
  }
  return approxTs;
}
```

### Step 4: 日照数据计算

```typescript
// PhenomenaGuidePanel.tsx
const REF_LATITUDE = 40;
const rad = (deg: number) => deg * Math.PI / 180;
const deg = (r: number) => (r * 180) / Math.PI;

function calculateDaylightData(eclipticLongitude: number) {
  const obliquity = rad(23.439);
  const lambda = rad(eclipticLongitude);
  const decl = Math.asin(Math.sin(obliquity) * Math.sin(lambda));
  const declDeg = deg(decl);

  const latRad = rad(REF_LATITUDE);
  let cosHa = -Math.tan(latRad) * Math.tan(decl);
  cosHa = Math.max(-1, Math.min(1, cosHa)); // 极昼极夜保护
  const haRad = Math.acos(cosHa);
  const haDeg = deg(haRad);

  const dayHours = 2 * haDeg / 15;
  const sunrise = 12 - dayHours / 2;
  const sunset = 12 + dayHours / 2;
  const nightHours = 24 - dayHours;
  const noonAltitude = 90 - Math.abs(REF_LATITUDE - declDeg);

  return { declination: declDeg, dayHours, sunrise, sunset, nightHours, noonAltitude };
}
```

## 5. 踩坑记录

1. **节气数据缺失**：早期 `SOLAR_TERMS` 数组为空，导致面板无内容。需确保 24 个节气的全部字段完整填充。
2. **极昼极夜 NaN**：`Math.acos` 输入超出 [-1, 1] 时返回 NaN，导致日出时间为 NaN。修正为 `Math.max(-1, Math.min(1, cosHa))` 钳制。
3. **节气步骤配置错误**：`PHENOMENA_STEPS['solar-terms']` 早期为空数组，导致步骤导航异常。修正为动态从 `SOLAR_TERMS` 映射生成。
4. **conic-gradient 浏览器兼容性**：旧版 Safari 不支持 `conic-gradient`。需确认项目目标浏览器范围。
