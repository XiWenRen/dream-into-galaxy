# 日食演示开发方案

> 版本: v2.0 | 日期: 2026-06-08 | 所属系统: 天文演示系统
>
> **定位说明**：本文档对应 `eclipses` 现象的步骤 0~2（太阳光束 → 月球影子锥 → 地球被笼罩）。步骤 3（月食/血月）见[月食演示开发方案](08c-月食演示开发方案.md)。

---

## 1. 目标

1. 在统一交食演示框架下，实现步骤 0~2 的日食原理可视化。
2. 集成 NASA 真实日食数据的事件选择器，支持两级切换（日食/月食类型 → 具体事件）。
3. 实现时间轴滑块，支持手动拖拽控制日食进程，并自动映射到 `eclipseWindow` 时间范围。
4. 实现日食几何指标实时计算与弧形表盘渲染（白道黄道倾斜黄纬、对齐偏差角、交食状态文本）。
5. 实现月球本影锥（`moonUmbraCone`）的 3D 渲染，支持严格物理模式与演示放大模式。
6. 实现交食辅助视觉元素：白道面、黄白交线、升/降交点标记、对齐指示线、影轴线。

---

## 2. 选型（选型原因）

### 2.1 统一 `eclipses` 现象下的日食/月食共享架构

**原因**：
- `AstroPhenomenaPanel` 中只有一个 `id: 'eclipses'` 卡片，日食和月食通过 `PhenomenaGuidePanel` 内部的两级选择器切换。
- 共享同一套状态：`eclipseEventTs`、`eclipseEventType`、`eclipseWindow`、`eclipseProgress`。
- 共享同一套时间轴滑块 UI 和几何指标面板，减少重复代码。

### 2.2 NASA 权威数据 + 动态窗口计算

**原因**：
- 精确日食预测需要贝塞尔根数计算，代码量过大。教育场景使用 NASA/GSFC Fred Espenak 数据（`SOLAR_ECLIPSE_EVENTS`）更具可信度。
- `AstrophenomenaEngine.getEclipseWindow()` 提供双重策略：优先解析 NASA 数据的 `centralDuration`/`partialDuration` 字段；若无则回退到基于 `detectEclipse()` 的粗搜+精搜边界检测。

### 2.3 截断锥体（ConeGeometry）+ ShaderMaterial 渲染本影

**原因**：
- Three.js 原生 `ConeGeometry` 可以方便地表示收敛锥体，配合自定义 `ShaderMaterial` 实现径向渐变透明，视觉上既清晰又不遮挡背景星体。
- 通过 `uniforms.uOpacity` 动态调节透明度：对准时加深（`0.32 + 0.28 * alignmentFactor`），偏离时减淡，避免视觉干扰。

### 2.4 严格/演示双模式尺度切换

**原因**：
- 真实比例下，地月距离是月球直径的约 110 倍，本影锥在屏幕上的像素极小（尤其在全局视图中）。
- 演示模式下通过 `angleAmplification`（`sin(15°)/sin(5.145°)`）自适应放大轨道倾角和影子锥尺寸，确保教学可见性。
- 严格模式下按真实物理公式 `computeShadowCone()` 计算，满足高精度科普需求。

### 2.5 `onPointerDown` 事件拦截

**原因**：早期滑块拖拽时事件冒泡到 Canvas，触发相机轨道旋转。在 `input[type="range"]` 上添加 `onPointerDown={(e) => e.stopPropagation()}` 解决。

### Step 3: App.tsx 状态管理与事件处理

**文件**: `src/App.tsx`

```typescript
const [eclipseEventTs, setEclipseEventTs] = useState<number | null>(null);
const [eclipseEventType, setEclipseEventType] = useState<'solar' | 'lunar' | null>(null);
const [eclipseWindow, setEclipseWindow] = useState<{ start: number; end: number } | null>(null);

const eclipseProgress = useMemo(() => {
  if (!eclipseWindow) return 0.0;
  const total = eclipseWindow.end - eclipseWindow.start;
  if (total <= 0) return 0.0;
  const pct = (timeState.currentTimestamp - eclipseWindow.start) / total;
  return Math.max(0, Math.min(1, pct));
}, [timeState.currentTimestamp, eclipseWindow]);

const handleSelectEclipseEvent = (ts: number, type: 'solar' | 'lunar') => {
  setEclipseEventTs(ts);
  setEclipseEventType(type);
  // 优先使用 NASA 窗口数据
  const nasaWin = AstrophenomenaEngine.getNASAWindow(ts, type);
  if (nasaWin) {
    setEclipseWindow(nasaWin);
  } else {
    const windowHours = type === 'lunar' ? 4 : 3;
    setEclipseWindow({
      start: ts - windowHours * 3600 * 1000,
      end: ts + windowHours * 3600 * 1000,
    });
  }
  setEclipseProgress(0.5);
};

const handleChangeEclipseProgress = (progress: number) => {
  if (eclipseEventTs && eclipseWindow) {
    const ts = eclipseWindow.start + progress * (eclipseWindow.end - eclipseWindow.start);
    setTimeState(prev => ({ ...prev, currentTimestamp: ts }));
  }
};
```

### Step 6: 日食类型视觉区分与数据映射

| 类型 | 本影锥顶点 | 数据标志 | 视觉效果 |
|------|-----------|----------|----------|
| 全食 (total) | 到达地球表面 | `magnitude >= 1.0`, `centralDuration != null` | 本影锥覆盖地球表面，中心带完全黑暗 |
| 环食 (annular) | 未到达地球表面 | `magnitude < 1.0`, `centralDuration != null` | 月球视半径小于太阳，边缘形成火环 |
| 偏食 (partial) | 无中心带 | `centralDuration == null` | 半影覆盖，无本影锥顶点接触 |
| 全环食 (hybrid) | 全食+环食组合 | `type === 'hybrid'` | 轨迹上部分区域全食，部分区域环食 |

## 4. 关键工具函数

### 4.1 阴影锥参数计算

**文件**: `src/engine/AstrophenomenaEngine.ts`

```typescript
/**
 * 计算物理正确的阴影锥参数
 * @param lightSourceRadius 光源半径 (km)
 * @param occluderRadius 遮挡体半径 (km)
 * @param distance 光源到遮挡体的距离 (km)
 * @returns 本影锥半顶角(rad)、半影锥半顶角(rad)、本影锥长度(km)
 */
static computeShadowCone(
  lightSourceRadius: number,
  occluderRadius: number,
  distance: number
): { umbraAngle: number; penumbraAngle: number; umbraLength: number } {
  const umbraAngle = Math.asin(Math.max(-1, Math.min(1, (lightSourceRadius - occluderRadius) / distance)));
  const penumbraAngle = Math.asin(Math.max(-1, Math.min(1, (lightSourceRadius + occluderRadius) / distance)));
  const umbraLength = Math.abs(umbraAngle) > 0.0001
    ? occluderRadius / Math.abs(Math.sin(umbraAngle))
    : distance * 100;
  return { umbraAngle, penumbraAngle, umbraLength };
}

static getMoonShadowCone(sunToMoonDist: number, sunRadius = 696340, moonRadius = 1737.4) {
  const { umbraAngle, penumbraAngle, umbraLength } = this.computeShadowCone(sunRadius, moonRadius, sunToMoonDist);
  return { umbraAngle, penumbraAngle, umbraLength, umbraTipRadius: 0.001 };
}
```

```typescript
  const moonRel = OrbitEngine.getLunarRelativePosition(days);
  const es = { x: -earthPos.x, y: -earthPos.y, z: -earthPos.z };
  const em = moonRel;
  const esLen = Math.sqrt(es.x**2 + es.y**2 + es.z**2);
  const emLen = Math.sqrt(em.x**2 + em.y**2 + em.z**2);
  const dot = es.x * em.x + es.y * em.y + es.z * em.z;
  const angleDeg = (Math.acos(Math.max(-1, Math.min(1, dot / (esLen * emLen)))) * 180) / Math.PI;

  // 日食：新月期，地月向量与地日向量同向，夹角 < 0.55°
  const solarEclipse = dot > 0 && angleDeg < 0.55;
  // 月食：满月期，地日向量与地月向量反向，180°−夹角 < 1.02°
  const lunarEclipse = dot < 0 && (180 - angleDeg) < 1.02;

  return { solarEclipse, lunarEclipse, earthToSunDist: esLen, earthToMoonDist: emLen, angleDegrees: angleDeg };
}
```

### 4.3 锥体对齐辅助函数

```typescript
function alignConeToDir(cone: THREE.Mesh, dir: THREE.Vector3, center: THREE.Vector3) {
  const up = new THREE.Vector3(0, 1, 0);
  const q = new THREE.Quaternion().setFromUnitVectors(up, dir.normalize());
  cone.quaternion.copy(q);
  cone.position.copy(center);
}
```

## 6. 踩坑记录

1. **滑块事件冒泡**：拖拽时间轴滑块时事件冒泡到 Canvas，触发相机旋转。修正为 `onPointerDown={(e) => e.stopPropagation()}`。
2. **日食窗口未初始化**：切换事件后忘记重置 `eclipseWindow`，导致滑块映射到旧窗口。修正：在 `handleSelectEclipseEvent` 中始终重新计算 `eclipseWindow`。
3. **日食类型显示不全**：早期未在事件中标注 hybrid（全环食），用户困惑。修正：下拉框选项通过 `formatSolarEclipseType()` 翻译所有四种类型。
4. **半影锥视觉干扰**：早期渲染了发散的 `moonPenumbraCone`，在深色宇宙背景中呈现为巨大的模糊锥体，遮挡星体且无法区分。修正：默认隐藏半影锥，仅保留本影锥作为教学重点。
5. **对齐指示线颜色未更新**：`eclipseAlignmentLine.material.color` 未在每帧重新计算，导致对准时不会变红。修正：在渲染循环中每帧根据 `diffDeg` 重新 `lerpColors`。
6. **严格/演示模式切换后锥体未刷新**：`strictPhysicsRef` 变化时，本影锥长度未立即重新计算，导致视觉残留。修正：将 `strictPhysicsRef.current` 纳入渲染循环的条件判断，每帧重新计算 `umbraLen`。
