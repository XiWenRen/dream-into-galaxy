# 月食演示开发方案

> 版本: v2.0 | 日期: 2026-06-08 | 所属系统: 天文演示系统
>
> **定位说明**：本文档对应 `eclipses` 现象的步骤 3（地球的影子与血月）。步骤 0~2（太阳光束 → 月球影子锥 → 地球被笼罩）见[日食演示开发方案](08b-日食演示开发方案.md)。

---

## 1. 目标

1. 在统一交食演示框架下，实现步骤 3 的月食原理可视化与血月效果渲染。
2. 集成 NASA 真实月食数据的事件选择器，支持两级切换（日食/月食类型 → 具体事件）。
3. 实现时间轴滑块控制月食进程，月食窗口比日食更长（默认 ±4 小时）。
4. 特别强调血月现象的物理原理和视觉呈现：通过动态材质颜色变化展示瑞利散射效应。
5. 展示月球进入地球阴影锥的完整过程：地球截头本影锥 + 月球距离处截面盘 + 对齐指示线。
6. 实现月食子阶段快捷导航（初亏前 → 初亏 → 全食 → 复圆 → 复圆后）。

---

## 2. 选型（选型原因）

### 2.1 月食作为 `eclipses` 现象的步骤 3

**原因**：
- 与日食共享同一套状态管理和 UI 框架（`eclipseEventTs`、`eclipseEventType`、`eclipseWindow`、`eclipseProgress`）。
- `PhenomenaGuidePanel` 内部通过 `eclipseCategory` 状态切换日食/月食视图，底层状态复用。
- 教育逻辑递进：先理解月球挡太阳（日食），再理解地球挡太阳照月球（月食）。

### 2.2 截头锥（CylinderGeometry）+ 截面盘（Disc）渲染地球本影

**原因**：
- 地球本影锥在月球距离处仍有显著的截面半径（物理上约 `0.72°` 视角直径，远大于月球的 `0.5°`）。
- 若使用 `ConeGeometry` 尖锥，锥顶点远在月球轨道之外（~140 万公里），在场景中无法直观展示月球被阴影覆盖的程度。
- 采用 `CylinderGeometry` 构建从地球表面到月球距离处的**截头锥**，并在月球距离处叠加一个垂直于影轴的圆盘（`CircleGeometry` 或 `PlaneGeometry`），直观展示“月球被多大的阴影圆盘覆盖”。

### 2.3 动态材质颜色变化实现血月

**原因**：
- 真实血月不是简单的贴图切换，而是月球表面反射光从全光谱 sunlight 过渡到经地球大气过滤后的窄带红光。
- 通过每帧更新 Moon Mesh 的材质颜色（`mesh.material.color`）或 Shader uniform，基于当前食分进行平滑插值，避免突兀跳变。
- 相比切换贴图，动态颜色性能开销更低（无需加载额外纹理），且可以与任何月球表面贴图叠加。

### 2.4 4 小时交食窗口

**原因**：
- 月食全食阶段可持续 1 小时以上，偏食阶段前后可达 2~3 小时，总过程约 3~5 小时。
- 日食使用 3 小时窗口，月食若同样使用 3 小时，初亏/复圆会被截断。修正为 4 小时窗口。

### 2.5 同心圆表盘 + 子阶段快捷按钮

**原因**：
- 月食的核心教学点是“月球进入地球阴影的深度”。同心圆（半影外圆 + 本影中圆 + 月球位置点）比日食的弧形偏差角表盘更直观。
- 子阶段按钮（5 个）让用户一键跳转到关键节点，弥补月食单步骤缺少硬切分节点的不足。

### Step 3: NASA 窗口解析（月食专用）

**文件**: `src/engine/AstrophenomenaEngine.ts`

```typescript
static getNASAWindow(timestamp: number, type: 'solar' | 'lunar'): { start: number; end: number } | null {
  if (type === 'lunar') {
    // 在 LUNAR_ECLIPSE_EVENTS 中查找距离 timestamp 1.5 天内的事件
    const event = LUNAR_ECLIPSE_EVENTS.find(e => {
      const eventTs = new Date(`${e.date}T${e.greatestUTC}Z`).getTime();
      return Math.abs(timestamp - eventTs) < 1.5 * 24 * 3600000;
    });

    if (event && event.partialDuration) {
      const match = event.partialDuration.match(/(\d+)h(\d+)m/);
      if (match) {
        const hours = parseInt(match[1]);
        const minutes = parseInt(match[2]);
        const durationMs = (hours * 3600 + minutes * 60) * 1000;
        const greatestTs = new Date(`${event.date}T${event.greatestUTC}Z`).getTime();
        return {
          start: greatestTs - durationMs / 2,
          end: greatestTs + durationMs / 2
        };
      }
    }
  }
  return null;
}
```

**注意**：半影月食的 `partialDuration` 为 `null`，此时回退到默认 `±4 小时` 窗口。

### Step 5: 月食阶段显示函数

```typescript
function getLunarEclipseStage(umbralMag: number, progress: number): string {
  // 根据 umbralMagnitude 和 progress 判断当前阶段
  // 注意：progress 是滑块 0~1，不一定严格对应天文阶段，仅作 UI 展示
  if (umbralMag < 0) return isZh ? '半影月食' : 'Penumbral Eclipse';
  if (umbralMag >= 1) {
    if (progress < 0.35) return isZh ? '偏食 → 全食' : 'Partial → Total';
    if (progress > 0.65) return isZh ? '全食 → 偏食' : 'Total → Partial';
    return isZh ? '全食（血月）' : 'Total Eclipse (Blood Moon)';
  }
  return isZh ? '月偏食' : 'Partial Eclipse';
}
```

#### 6.2 每帧更新逻辑（月食渲染核心）

```typescript
const isLunarMode = eclipseEventTypeRef.current === 'lunar';

// 3. 地球阴影锥（月食演示）
if (aids.earthUmbraCone && aids.earthUmbraDisc) {
  const showEarthCones = isEclipseDemo && isLunarMode && earthToMoonDist > 0.01;
  aids.earthUmbraCone.visible = showEarthCones;
  aids.earthUmbraDisc.visible = showEarthCones;
  if (aids.earthPenumbraCone) aids.earthPenumbraCone.visible = false;

  if (showEarthCones && earthPos && moonPos) {
    const shadowDir = earthPos.clone().normalize(); // 背日方向
    const coneLen = earthPos.distanceTo(moonPos);

    // 获取真实日地距离以计算物理本影半顶角
    const earthPosRaw = OrbitEngine.getHeliocentricPositionCached('earth', daysSinceJ2000);
    const sunToEarthDistAU = Math.sqrt(earthPosRaw.x**2 + earthPosRaw.y**2 + earthPosRaw.z**2);
    const sunToEarthDistKm = sunToEarthDistAU * 149597870.7;
    const { umbraAngle } = AstrophenomenaEngine.computeShadowCone(696340, 6371, sunToEarthDistKm);

    // 截面半径
    const sectionRadius = strictPhysicsRef.current
      ? Math.max(0.0001, earthRadiusScene - coneLen * Math.tan(umbraAngle))
      : moonRadiusScene; // 演示模式下用月球半径，确保可见

    // 圆盘半径：演示模式下放大 1.5 倍
    const discRadius = strictPhysicsRef.current ? sectionRadius : moonRadiusScene * 1.5;

    // 仅在尺寸变化 > 0.001 时重建几何，避免每帧 GC
    const lastR = aids.earthUmbraCone.userData.lastSectionR || 0;
    const lastEarthR = aids.earthUmbraCone.userData.lastEarthR || 0;
    const lastLen = aids.earthUmbraCone.userData.lastLen || 0;
    if (
      Math.abs(sectionRadius - lastR) > 0.001 ||
      Math.abs(earthRadiusScene - lastEarthR) > 0.001 ||
      Math.abs(coneLen - lastLen) > 0.001
    ) {
      aids.earthUmbraCone.geometry.dispose();
      aids.earthUmbraCone.geometry = new THREE.CylinderGeometry(
        sectionRadius, earthRadiusScene, coneLen, 48, 1, true
      );
      aids.earthUmbraCone.userData.lastSectionR = sectionRadius;
      aids.earthUmbraCone.userData.lastEarthR = earthRadiusScene;
      aids.earthUmbraCone.userData.lastLen = coneLen;
    }

    // 截头锥中心位于地影方向中点
    const umbraCenter = earthPos.clone().add(shadowDir.clone().multiplyScalar(coneLen * 0.5));
    alignConeToDir(aids.earthUmbraCone, shadowDir, umbraCenter);

    // 实体截面盘：放置在月球距离处，垂直于影轴
    const discPos = earthPos.clone().add(shadowDir.clone().multiplyScalar(coneLen));
    const discUp = new THREE.Vector3(0, 0, 1);
    const discQ = new THREE.Quaternion().setFromUnitVectors(discUp, shadowDir);
    aids.earthUmbraDisc.quaternion.copy(discQ);
    aids.earthUmbraDisc.position.copy(discPos);
    aids.earthUmbraDisc.scale.set(discRadius, discRadius, 1);

    // 动态透明度
    const alignmentFactor = Math.max(0, 1 - diffDeg / 8.0);
    const umbraOpacity = 0.32 + 0.28 * alignmentFactor;
    if (aids.earthUmbraCone.material instanceof THREE.ShaderMaterial) {
      aids.earthUmbraCone.material.uniforms.uOpacity.value = umbraOpacity;
    }
    if (aids.earthUmbraDisc.material instanceof THREE.MeshBasicMaterial) {
      aids.earthUmbraDisc.material.opacity = 0.4 + 0.25 * alignmentFactor;
    }
  }
}
```

#### 6.3 血月材质动态变化

```typescript
// 在渲染循环中，根据当前交食状态更新月球材质颜色
const moonMesh = scene.getObjectByName('moon');
if (moonMesh && moonMesh instanceof THREE.Mesh) {
  const mat = moonMesh.material;
  if (mat instanceof THREE.MeshStandardMaterial || mat instanceof THREE.MeshBasicMaterial) {
    // 基础颜色
    const normalColor = new THREE.Color(0xffffff);
    const bloodColor = new THREE.Color(0x8b0000); // 暗红
    const deepBloodColor = new THREE.Color(0x4a0000); // 更深红

    let targetColor = normalColor;
    let intensity = 0;

    if (isLunarMode && lunarEclipse) {
      // 根据 umbralMagnitude 和进度计算血月强度
      const event = LUNAR_ECLIPSE_EVENTS.find(e => {
        const eventTs = new Date(`${e.date}T${e.greatestUTC}Z`).getTime();
        return Math.abs(eclipseEventTsRef.current! - eventTs) < 2 * 24 * 3600000;
      });
      const umbralMag = event?.umbralMagnitude ?? 1.0;

      if (umbralMag >= 1.0) {
        // 全食：根据 progress 偏离食甚的程度插值
        const distFromCenter = Math.abs(eclipseProgress - 0.5) * 2; // 0@食甚, 1@边缘
        intensity = (1 - distFromCenter) * 0.85;
        targetColor = intensity > 0.5 ? deepBloodColor : bloodColor;
      } else if (umbralMag > 0) {
        // 偏食：轻微泛红
        intensity = umbralMag * 0.3;
        targetColor = bloodColor;
      }
    }

    // 平滑插值（避免突兀跳变）
    const currentColor = mat.color.clone();
    currentColor.lerp(targetColor, 0.05); // 每帧 5% 过渡
    mat.color.copy(currentColor);
  }
}
```

**注意**：上述代码为示意逻辑。实际项目中，若月球使用 `ShaderMaterial`（如法线贴图 + 纹理），则应通过更新 Shader uniform（如 `uBloodFactor`）在片元着色器内混合纹理颜色与血月颜色，而非直接修改 `material.color`。

### 4.1 地球阴影锥参数

**文件**: `src/engine/AstrophenomenaEngine.ts`

```typescript
static getEarthShadowCone(
  sunToEarthDist: number,
  sunRadius = 696340,
  earthRadius = 6371
): { umbraAngle: number; penumbraAngle: number; umbraLength: number; umbraTipRadius: number } {
  const { umbraAngle, penumbraAngle, umbraLength } = this.computeShadowCone(sunRadius, earthRadius, sunToEarthDist);
  return { umbraAngle, penumbraAngle, umbraLength, umbraTipRadius: 0.001 };
}
```

### 4.2 截头锥几何重建优化

**要点**：
- `CylinderGeometry` 的重建必须判断尺寸变化阈值（`> 0.001`），禁止每帧重建。
- 旧 `geometry` 必须先 `dispose()` 再赋新值，防止 GPU 显存泄漏。
- 使用 `userData` 缓存上一次尺寸，避免额外闭包开销。

```typescript
// 正确做法（已在 Step 6 中展示）
if (Math.abs(sectionRadius - lastSectionR) > 0.001 || ...) {
  aids.earthUmbraCone.geometry.dispose();
  aids.earthUmbraCone.geometry = new THREE.CylinderGeometry(...);
  aids.earthUmbraCone.userData.lastSectionR = sectionRadius;
}
```

### 5.1 月球 Shader 阴影注入（`moonMat.onBeforeCompile`）

在星空模式初始化时，为月球材质注入自定义 Shader 代码，实现本影遮挡与血月效果：

```typescript
const eclipseUniforms = {
  uEclipseActive: { value: 0.0 },
  uShadowDirection: { value: new THREE.Vector3(0, 0, -1) },
  uUmbraRadius: { value: 4.58 * Math.PI / 180 },      // 本视角半径（弧度）
  uPenumbraRadius: { value: 7.63 * Math.PI / 180 },    // 半视角半径（弧度）
  uShadowSoftness: { value: 0.35 * Math.PI / 180 },    // 边缘软化
  uEclipseStrength: { value: 1.0 },
  uBloodIntensity: { value: 0.0 },
};
eclipseUniformsRef.current = eclipseUniforms;

moonMat.onBeforeCompile = (shader) => {
  shader.uniforms.uEclipseActive = eclipseUniforms.uEclipseActive;
  shader.uniforms.uShadowDirection = eclipseUniforms.uShadowDirection;
  shader.uniforms.uUmbraRadius = eclipseUniforms.uUmbraRadius;
  shader.uniforms.uPenumbraRadius = eclipseUniforms.uPenumbraRadius;
  shader.uniforms.uShadowSoftness = eclipseUniforms.uShadowSoftness;
  shader.uniforms.uEclipseStrength = eclipseUniforms.uEclipseStrength;
  shader.uniforms.uBloodIntensity = eclipseUniforms.uBloodIntensity;

  shader.vertexShader = `varying vec3 vWorldNormal;\n` + shader.vertexShader;
  shader.vertexShader = shader.vertexShader.replace(
    '#include <begin_vertex>',
    `#include <begin_vertex>\nvWorldNormal = normalize((modelMatrix * vec4(normal, 0.0)).xyz);`
  );

  shader.fragmentShader = `
    uniform float uEclipseActive;
    uniform vec3 uShadowDirection;
    uniform float uUmbraRadius;
    uniform float uPenumbraRadius;
    uniform float uShadowSoftness;
    uniform float uEclipseStrength;
    uniform float uBloodIntensity;
    varying vec3 vWorldNormal;
  ` + shader.fragmentShader;

  shader.fragmentShader = shader.fragmentShader.replace(
    '#include <dithering_fragment>',
    `#include <dithering_fragment>
    if (uEclipseActive > 0.5) {
      float cosDiff = dot(normalize(vWorldNormal), normalize(uShadowDirection));
      float angle = acos(clamp(cosDiff, -1.0, 1.0));
      if (angle < uUmbraRadius + uShadowSoftness) {
        float umbraMask = 1.0 - smoothstep(
          uUmbraRadius - uShadowSoftness,
          uUmbraRadius + uShadowSoftness,
          angle
        );
        vec3 coldShadow = gl_FragColor.rgb * vec3(0.08, 0.075, 0.09);
        vec3 bloodMoonColor = gl_FragColor.rgb * vec3(0.95, 0.20, 0.065) * 0.34;
        vec3 eclipseColor = mix(coldShadow, bloodMoonColor, clamp(uBloodIntensity, 0.0, 1.0));
        gl_FragColor.rgb = mix(gl_FragColor.rgb, eclipseColor, umbraMask * clamp(uEclipseStrength, 0.0, 1.0));
      }
    }`
  );
};
```

### 5.2 月食检测频率限制

为避免每帧调用 `detectEclipse()`，采用帧计数器 + 时间阈值双重限制：

```typescript
const eclipseCheckFrameInterval = 30;   // 每 30 帧检测一次
const eclipseCheckDayThreshold = 0.01;  // 或模拟时间推进 > 0.01 天（~14.4 分钟）

const shouldCheckEclipse =
  (eclipseCheckCounterRef.current % eclipseCheckFrameInterval === 0) ||
  (Math.abs(days - lastEclipseCheckDaysRef.current) > eclipseCheckDayThreshold);

const eclipses = shouldCheckEclipse
  ? AstrophenomenaEngine.detectEclipse(days)
  : lastEclipsesRef.current;

if (shouldCheckEclipse) {
  lastEclipseCheckDaysRef.current = days;
  lastEclipsesRef.current = eclipses;
}
eclipseCheckCounterRef.current++;
```

### 5.3 双模式月食激活与阴影参数计算

```typescript
const moonVisualRadius = Math.atan((7.2 * moonSkyRef.current.scale.x) / 270);
const moonPhysicalRadius = Math.max(0.0001, ((satInfo.angularDiameter ?? 30) / 120.0) * DEG_TO_RAD);
const visualExaggeration = THREE.MathUtils.clamp(moonVisualRadius / moonPhysicalRadius, 1.0, 12.0);

const earthToMoonKm = Math.max(1, eclipses.earthToMoonDist * AU_KM);
const sunToEarthKm = Math.max(1, eclipses.earthToSunDist * AU_KM);
const { umbraAngle } = AstrophenomenaEngine.computeShadowCone(696340, 6371, sunToEarthKm);
const earthUmbraRadiusKm = Math.max(1, 6371 - earthToMoonKm * Math.tan(umbraAngle));
const umbraVisualRadius = Math.atan(earthUmbraRadiusKm / earthToMoonKm) * visualExaggeration;
const shadowSoftness = Math.max(0.18 * DEG_TO_RAD, moonVisualRadius * 0.12);

// 模式 1：用户选定了具体月食事件
const selectedLunarEvent = findLunarEclipseEventByTimestamp(eclipseEventTs);
const selectedLunarWindowActive =
  eclipseEventType === 'lunar' &&
  !!eclipseWindow &&
  currentTimestamp >= eclipseWindow.start &&
  currentTimestamp <= eclipseWindow.end;

// 模式 2：轨道自然产生的月食（未选定事件时）
const actualShadowSeparation = Math.max(0, (180.0 - eclipses.angleDegrees) * DEG_TO_RAD) * visualExaggeration;
const naturalLunarEclipseActive = !selectedLunarWindowActive &&
  actualShadowSeparation < (umbraVisualRadius + moonVisualRadius + shadowSoftness);

if (selectedLunarWindowActive || naturalLunarEclipseActive) {
  // 计算本影食分、阴影方向、血月强度等参数
  const contactSeparation = umbraVisualRadius + moonVisualRadius;
  let visualShadowSeparation = Math.min(Math.PI, actualShadowSeparation);
  let eclipseStrength = 1.0;
  let umbralMagnitude = THREE.MathUtils.clamp(
    (contactSeparation - visualShadowSeparation) / (2 * moonVisualRadius), 0, 2
  );

  if (selectedLunarWindowActive && eclipseWindow) {
    const progress = THREE.MathUtils.clamp(
      (currentTimestamp - eclipseWindow.start) / Math.max(1, eclipseWindow.end - eclipseWindow.start),
      0, 1
    );
    const approach = smoothstepScalar(0, 1, progress <= 0.5 ? progress * 2 : (1 - progress) * 2);
    const peakMagnitude = Math.max(0, selectedLunarEvent?.umbralMagnitude ?? ...);
    const peakSeparation = Math.max(0, contactSeparation - peakMagnitude * 2 * moonVisualRadius);
    visualShadowSeparation = THREE.MathUtils.lerp(contactSeparation + shadowSoftness * 0.5, peakSeparation, approach);
    eclipseStrength = smoothstepScalar(0, 0.025, progress) * (1 - smoothstepScalar(0.975, 1, progress));
    umbralMagnitude = peakMagnitude * approach;
  }

  // 更新 Shader Uniforms
  if (eclipseUniformsRef.current) {
    eclipseUniformsRef.current.uEclipseActive.value = (umbralMagnitude > 0.001) ? 1.0 : 0.0;
    eclipseUniformsRef.current.uUmbraRadius.value = umbraVisualRadius;
    eclipseUniformsRef.current.uPenumbraRadius.value = umbraVisualRadius + shadowSoftness;
    eclipseUniformsRef.current.uShadowSoftness.value = shadowSoftness;
    eclipseUniformsRef.current.uEclipseStrength.value = eclipseStrength;
    eclipseUniformsRef.current.uBloodIntensity.value = smoothstepScalar(0.82, 1.0, umbralMagnitude);
    // uShadowDirection 更新逻辑（略）...
  }
}
```

### 5.4 月晕（`moonHazeSpriteRef`）动态色彩

```typescript
if (moonHazeSpriteRef.current) {
  const bloodGlow = smoothstepScalar(0.82, 1.0, umbralMagnitude);
  if (bloodGlow > 0.01) {
    // 全食阶段：鲜红橙色光晕
    moonHazeSpriteRef.current.material.color.setHex(0xff3311);
    moonHazeSpriteRef.current.material.opacity = THREE.MathUtils.lerp(0.18, 0.72, bloodGlow) * eclipseStrength;
  } else {
    // 偏食阶段：从浅蓝向暗红插值

      new THREE.Color(0xdbeafe), new THREE.Color(0x8b1a10), partial

      THREE.MathUtils.lerp(opacityNormal, 0.16, partial) * Math.max(0.35, eclipseStrength);
```

## 6. 踩坑记录

1. **月食窗口太短**：早期使用与日食相同的 3 小时窗口，导致月全食食甚前后展示不完整。修正为 4 小时，并优先解析 NASA 的 `partialDuration` 字段。
2. **血月颜色突兀**：从亮白直接跳转到暗红，视觉上像 bug。修正为基于 `umbralMagnitude` 和 `eclipseProgress` 的平滑插值，每帧 `lerp` 过渡。
3. **偏食阶段误标为血月**：当 `umbralMagnitude < 1` 时仍显示红色材质。修正为仅全食阶段（`umbralMagnitude >= 1` 且滑块接近食甚）才启用血色材质。
4. **截头锥每帧重建导致 GC**：早期未加尺寸变化阈值，每帧 `new THREE.CylinderGeometry()` 导致频繁 GC 和微卡顿。修正：使用 `userData.lastSectionR / lastLen` 缓存，仅当变化 > 0.001 时才重建。
5. **半影月食 `partialDuration` 为 null 导致窗口崩溃**：`getNASAWindow` 未处理 `null` 情况，直接返回 `{ start: NaN, end: NaN }`。修正：增加 `event.partialDuration` 空值检查，为空时回退到默认窗口。
6. **截面盘方向错误**：`earthUmbraDisc` 的 `Quaternion` 未正确对齐影轴，导致圆盘倾斜，无法直观展示月球入影深度。修正：使用 `setFromUnitVectors(new THREE.Vector3(0,0,1), shadowDir)` 确保圆盘法线严格平行于影轴。
7. **血月颜色与云层贴图冲突**：若月球使用带透明通道的贴图，直接修改 `material.color` 会导致颜色混合异常。修正：为月球材质添加 `uBloodFactor` Shader uniform，在片元着色器内基于纹理颜色进行可控混合。
