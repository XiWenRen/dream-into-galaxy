# 天文演示系统开发方案（总览）

> 版本: v4.0 | 日期: 2026-06-08 | 模块: PhenomenaDemo 系统总览

---

## 1. 目标

1. 实现天文现象选择与入口管理（AstroPhenomenaPanel）
2. 实现底部统一演示控制条（PhenomenaDemoBar），支持步骤导航、自动播放、倍速、视角切换
3. 实现右侧引导面板容器（PhenomenaGuidePanel），按现象类型渲染不同内容
4. 实现演示模式下的全局状态管理与时间自动跳转逻辑
5. 所有演示现象共享同一套控制框架，降低维护成本

## 2. 选型（选型原因）

### 2.1 集中状态机驱动（App.tsx 统管）

**原因**：演示状态（activePhenomenon / demoPhase / viewMode / isPlaying）与全局时间状态（timeState）强耦合，步骤切换时必须同步更新多个状态。

### 2.2 rAF Accumulator 模式驱动自动播放

**原因**：setInterval 与主渲染 rAF 循环存在时序竞争，曾导致步骤切换不同步。

```typescript
let acc = 0;
let last = performance.now();
const tick = (now: number) => {
  acc += now - last;
  last = now;
  const threshold = (stepDurationSec * 1000) / playbackSpeed;
  if (acc >= threshold) { acc = 0; nextStep(); }
  rafId = requestAnimationFrame(tick);
};
```

### 2.3 预置数据对象驱动 UI

**原因**：月相诗词、节气习俗、物候描述均为静态文本，无需后端 API。

## 4. 全局状态管理

### 4.1 核心状态定义

```typescript
interface PhenomenaDemoState {
  activePhenomenon: 'moon-phases' | 'eclipses' | 'retrograde' | 'solar-terms' | null;
  demoPhase: number;      // eclipses 下：0=太阳光束, 1=月球影子锥, 2=地球被笼罩, 3=月食/血月
  viewMode: 'universe' | 'starry';
  isPlaying: boolean;
  playbackSpeed: number; // 0.5 | 1 | 2
  showGuidePanel: boolean;
}
```

### 4.2 自动播放实现

```typescript
useEffect(() => {
  if (!demoState.isPlaying || !demoState.activePhenomenon) return;
  const stepDurationSec = DEMO_STEP_DURATION[demoState.activePhenomenon] || 8;
  const stepIntervalMs = (stepDurationSec * 1000) / demoState.playbackSpeed;
  let acc = 0, last = performance.now(), rafId = 0;
  const tick = (now: number) => {
    acc += now - last; last = now;
    if (acc >= stepIntervalMs) { acc = 0; setDemoState(prev => { /* nextPhase */ }); }
    rafId = requestAnimationFrame(tick);
  };
  rafId = requestAnimationFrame(tick);
  return () => cancelAnimationFrame(rafId);
}, [demoState.isPlaying, demoState.playbackSpeed, demoState.activePhenomenon]);
```

### 4.3 进入演示主入口

```typescript
const handleSelectPhenomenon = (id: string) => {
  const phenomenon = id as PhenomenaDemoState['activePhenomenon'];
  setDemoState({ activePhenomenon: phenomenon, demoPhase: 0, viewMode: 'universe', isPlaying: false, playbackSpeed: 1, showGuidePanel: true });
  setSelectedPlanetId('earth');
  // 计算初始时间...
  const now = Date.now();
  let targetTs = now;
  if (phenomenon === 'moon-phases') targetTs = getCurrentCycleNewMoon(now);
  else if (phenomenon === 'eclipses') {
    // 日食/月食共用 eclipses 现象，默认跳转到最近未来日食
    const futureSolar = SOLAR_ECLIPSE_EVENTS.find(e => new Date(e.date).getTime() > now);
    targetTs = futureSolar ? new Date(futureSolar.date).getTime() : now;
  }
  else if (phenomenon === 'solar-terms') targetTs = findNearestSpringEquinox(now);
  setTimeState(prev => ({ ...prev, currentTimestamp: targetTs, speedMultiplier: 1 }));
};
```
