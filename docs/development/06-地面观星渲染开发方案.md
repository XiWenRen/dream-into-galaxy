# 地面观星渲染开发方案 (StarrySkyViewer)

> 版本: v1.0 | 日期: 2026-06-08 | 模块: StarrySkyViewer (L2 渲染层)

---

## 1. 目标

1. 以观测者为球心，渲染全天球星图投影
2. 正确显示太阳、月球、行星在天空中的视位置
3. 渲染星座连线、星名标签、星座名称
4. 实现曙暮光大气散射、地平线网格
5. 提供望远镜模式（FOV 可调视场限制）

---

## 2. 技术选型

### 2.1 选型: Three.js Points 批量渲染恒星

**原因**：
1. 8785 颗背景暗星使用 Points 对象在一个 draw call 中渲染
2. 比独立 Sprite/Mesh 高效 100 倍以上
3. 通过 BufferGeometry attribute 控制每颗星的大小和颜色

**当前问题**: 每帧在 CPU 端更新所有星的 position buffer，是最大性能瓶颈。

**未来方案**: Shader 化（见性能优化计划）。

### 2.2 选型: 自定义 Shader 实现天空穹顶

**原因**：
1. 天空颜色由太阳高度角动态驱动，无法用静态贴图
2. 高流速下（3600x）每帧太阳高度角变化 0.25°， CubeMap 烘焙会瞬间过时
3. 自定义片段着色器实时计算大气颜色，兼容任意流速

### 2.3 选型: Sprite 渲染亮星和日月

**原因**：
1. 亮星需要交互（hover 显示名称、点击显示信息）
2. Sprite 始终朝向相机，适合天球上的标注
3. 日月需要动态纹理（月相变化）

## 3. 实现步骤

### Step 1: 天球场景初始化

```typescript
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(60, width / height, 0.1, 1000);

// 天球穹顶（大半径球面，内侧渲染）
const domeGeometry = new THREE.SphereGeometry(150, 64, 64);
const domeMaterial = new THREE.ShaderMaterial({
  vertexShader: skyDomeVert,
  fragmentShader: skyDomeFrag,
  side: THREE.BackSide,
  uniforms: {
    uSunDirection: { value: new THREE.Vector3() },
    uTime: { value: 0 }
  }
});
const dome = new THREE.Mesh(domeGeometry, domeMaterial);
scene.add(dome);

// 地平线网格
const horizonGrid = new THREE.PolarGridHelper(100, 16, 8, 64, 0x444444, 0x444444);
horizonGrid.rotation.x = Math.PI / 2;
scene.add(horizonGrid);
```

### Step 2: 恒星 Points 初始化

```typescript
// 加载 Hipparcos 星表
const starsData = await loadHipparcosCatalog();

// 创建 BufferGeometry
const geometry = new THREE.BufferGeometry();
const positions = new Float32Array(starsData.length * 3);
const colors = new Float32Array(starsData.length * 3);
const sizes = new Float32Array(starsData.length);

starsData.forEach((star, i) => {
  // 初始位置（将在 animate 中更新）
  positions[i * 3] = 0;
  positions[i * 3 + 1] = 0;
  positions[i * 3 + 2] = 0;
  
  // 颜色（基于 B-V 色指数）
  const color = bvToColor(star.bv || 0);
  colors[i * 3] = color.r;
  colors[i * 3 + 1] = color.g;
  colors[i * 3 + 2] = color.b;
  
  // 大小基于星等
  sizes[i] = Math.max(0.5, 3.0 - star.mag * 0.5);
});

geometry.setAttribute('position', new THREE.BufferAttribute(positions, 3));
geometry.setAttribute('color', new THREE.BufferAttribute(colors, 3));
geometry.setAttribute('size', new THREE.BufferAttribute(sizes, 1));

const material = new THREE.PointsMaterial({
  size: 1,
  vertexColors: true,
  transparent: true,
  opacity: 0.9,
  sizeAttenuation: false
});

const starField = new THREE.Points(geometry, material);
scene.add(starField);
```

### Step 3: 恒星位置更新（当前 CPU 方案）

```typescript
// 在 animate 循环中
const days = TimeEngine.getDaysSinceJ2000(timestamp);
const yearsSinceJ2000 = days / 365.25;
const lst = TimeEngine.getLocalSiderealTime(timestamp, longitude);

const positions = starField.geometry.attributes.position.array as Float32Array;

for (let i = 0; i < starsData.length; i++) {
  const star = starsData[i];
  
  // 1. 岁差修正
  const prec = ObserverEngine.applyPrecession(star.ra, star.dec, yearsSinceJ2000);
  
  // 2. 赤道转水平
  const horiz = ObserverEngine.getHorizontalCoordinates(prec.ra, prec.dec, lst, latitude);
  
  // 3. 消光
  const extinctedMag = ObserverEngine.getAtmosphericExtinction(star.mag, horiz.alt);
  
  // 4. 地平线裁剪
  if (horiz.alt <= 0 || extinctedMag > magLimit) {
    positions[i * 3] = 0;
    positions[i * 3 + 1] = -999; // 移到视野外
    positions[i * 3 + 2] = 0;
    continue;
  }
  
  // 5. 天球投影
  const altRad = horiz.alt * Math.PI / 180;
  const azRad = horiz.az * Math.PI / 180;
  const r = 150; // 天球半径
  
  positions[i * 3] = -r * Math.cos(altRad) * Math.cos(azRad);
  positions[i * 3 + 1] = r * Math.sin(altRad);
  positions[i * 3 + 2] = r * Math.cos(altRad) * Math.sin(azRad);
}

starField.geometry.attributes.position.needsUpdate = true;
```

**性能**: 8785 颗星 × ~40 次三角函数/帧 ≈ 35 万次三角函数调用，在中端设备上约 8ms。

### Step 4: 天空穹顶 Shader

```glsl
// fragment shader
uniform vec3 uSunDirection;
varying vec3 vWorldPosition;

void main() {
  vec3 viewDir = normalize(vWorldPosition);
  float sunHeight = dot(viewDir, uSunDirection);
  
  // 天空颜色基于太阳高度
  vec3 dayColor = vec3(0.3, 0.6, 1.0);
  vec3 sunsetColor = vec3(1.0, 0.5, 0.2);
  vec3 nightColor = vec3(0.0, 0.0, 0.02);
  
  vec3 color;
  if (sunHeight > 0.0) {
    color = mix(sunsetColor, dayColor, sunHeight);
  } else if (sunHeight > -0.1) {
    color = mix(nightColor, sunsetColor, (sunHeight + 0.1) / 0.1);
  } else {
    color = nightColor;
  }
  
  gl_FragColor = vec4(color, 1.0);
}
```

**简化**: 当前使用 fbm 噪声增加细节，但复杂度高。未来可简化为 2-octave value noise 或纯色渐变。

### Step 5: 日月渲染

```typescript
// 太阳 Sprite
const sunTexture = createSunSpriteTexture();
const sunMaterial = new THREE.SpriteMaterial({ map: sunTexture, transparent: true });
const sunSprite = new THREE.Sprite(sunMaterial);
scene.add(sunSprite);

// 更新位置
const solarPos = ObserverEngine.getSolarRADec(observerContext, days);
const solarHoriz = ObserverEngine.getHorizontalCoordinates(solarPos.ra, solarPos.dec, lst, latitude);
const sunAltRad = solarHoriz.alt * Math.PI / 180;
const sunAzRad = solarHoriz.az * Math.PI / 180;
sunSprite.position.set(
  -r * Math.cos(sunAltRad) * Math.cos(sunAzRad),
  r * Math.sin(sunAltRad),
  r * Math.cos(sunAltRad) * Math.sin(sunAzRad)
);

// 太阳颜色变化（日出日落）
if (solarHoriz.alt < 10 && solarHoriz.alt > 0) {
  sunMaterial.color.setHex(0xffaa44); // 橙红
} else if (solarHoriz.alt <= 0) {
  sunMaterial.visible = false;
} else {
  sunMaterial.color.setHex(0xffffee); // 白
}
```

## 5. 踩坑记录

1. **CPU 恒星计算瓶颈**: 每帧对 8785 颗星全量计算，阻塞主线程。计划迁移到 GPU Shader。
2. **Sprite draw call 过高**: 42 颗亮星使用独立 Sprite，每帧更新位置产生 42 次 draw call。计划合并到 Points 系统。
3. **天空颜色跳变**: 高流速下 fbm 噪声导致天空颜色闪烁。计划降低 noise octave 数。
4. **地平线以下恒星未裁剪**: 早期所有恒星都参与渲染，地平线以下浪费 GPU 资源。修正为 CPU 端裁剪（alt <= 0 时移到视野外）。
5. **星座连线每帧重建**: 早期每帧 `new BufferGeometry().setFromPoints()`，产生 GC 抖动。修正为初始化一次 BufferGeometry，每帧直接写 `position.array`。
