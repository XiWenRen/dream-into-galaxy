# 月相变化演示开发方案

> 版本: v1.0 | 日期: 2026-06-08 | 所属系统: 天文演示系统

---

## 1. 目标

1. 实现 8 个月相步骤的精确时间自动跳转
2. 实现 MoonPhaseDetailContent 详情页（天文知识 Tab + 古诗词 Tab）
3. 实现地球/月球视角聚焦交互
4. 实现自动播放与手动导航的时序同步

---

## 2. 选型（选型原因）

### 2.1 朔望月迭代搜索算法

**原因**：月相的精确时刻无法解析求解（多体摄动）。已知基准新月 + 迭代梯度下降，4 轮收敛到分钟级精度。

### 2.2 useEffect 监听 demoPhase 驱动时间跳转

**原因**：早期在 rAF 回调中直接调用 `handleSelectPhase`，因闭包捕获旧的 `demoState` 导致时间跳转不正确。改为监听 `demoPhase` 变化，确保使用最新状态。

### 2.3 MOON_PHASE_BEST_VIEW_HOURS 预设表

**原因**：月相的天文发生时刻不一定是最适合地面观测的时间。通过预设表将时间调整到最佳观测本地小时。

### Step 2: 精确新月搜索算法

```typescript
export function getCurrentCycleNewMoon(referenceTimestamp: number): number {
  const knownNewMoon = Date.UTC(2000, 0, 6, 18, 14, 0);
  const monthsSince = (referenceTimestamp - knownNewMoon) / SYNODIC_MONTH_MS;
  let baseTs = knownNewMoon + Math.floor(monthsSince) * SYNODIC_MONTH_MS;

  let step = 24 * 3600 * 1000;
  for (let iter = 0; iter < 4; iter++) {
    let bestTs = baseTs;
    let minAngle = Infinity;
    for (let offset = -5; offset <= 5; offset++) {
      const ts = baseTs + offset * step;
      const days = (ts - J2000_TIMESTAMP) / 86400000;
      const earthPos = OrbitEngine.getHeliocentricPosition('earth', days);
      const moonRel = OrbitEngine.getLunarRelativePosition(days);
      const es = { x: -earthPos.x, y: -earthPos.y, z: -earthPos.z };
      const dot = es.x * moonRel.x + es.y * moonRel.y + es.z * moonRel.z;
      const angle = Math.acos(dot / (len(es) * len(moonRel)));
      if (angle < minAngle) { minAngle = angle; bestTs = ts; }
    }
    baseTs = bestTs;
    step /= 5;
  }
  return baseTs;
}
```

**收敛性**：4 轮后步长 = 1天 / 5⁴ = 1/625 天 ≈ 2.3 分钟。

### Step 3: 任意月相时间定位

```typescript
export function getExactMoonPhaseTime(baseNewMoon: number, phaseIndex: number): number {
  if (phaseIndex === 0) return baseNewMoon;
  const targetAngle = (phaseIndex / 8) * Math.PI * 2;
  let baseTs = baseNewMoon + (phaseIndex / 8) * SYNODIC_MONTH_MS;
  let step = 24 * 3600 * 1000;
  for (let iter = 0; iter < 4; iter++) {
    let bestTs = baseTs;
    let minDiff = Infinity;
    for (let offset = -5; offset <= 5; offset++) {
      const ts = baseTs + offset * step;
      const days = (ts - J2000_TIMESTAMP) / 86400000;
      const earthPos = OrbitEngine.getHeliocentricPosition('earth', days);
      const moonRel = OrbitEngine.getLunarRelativePosition(days);
      const angle = Math.atan2(
        (-earthPos.x) * moonRel.y - (-earthPos.y) * moonRel.x,
        (-earthPos.x) * moonRel.x + (-earthPos.y) * moonRel.y
      );
      let currentPhase = angle;
      if (currentPhase < 0) currentPhase += Math.PI * 2;
      let diff = Math.abs(currentPhase - targetAngle);
      if (diff > Math.PI) diff = Math.PI * 2 - diff;
      if (diff < minDiff) { minDiff = diff; bestTs = ts; }
    }
    baseTs = bestTs;
    step /= 5;
  }
  return baseTs;
}
```

### Step 4: App.tsx 时间跳转逻辑

```typescript
const MOON_PHASE_BEST_VIEW_HOURS = [
  20.0, 19.5, 20.5, 22.0, 0.0, 2.0, 4.0, 5.0
];

// 监听 demoPhase 变化，执行时间跳转
useEffect(() => {
  if (demoState.activePhenomenon !== 'moon-phases') return;
  const phase = demoState.demoPhase;
  const base = getCurrentCycleNewMoon(timeState.currentTimestamp);
  const targetAstronomic = getExactMoonPhaseTime(base, phase);
  const bestLocalHour = MOON_PHASE_BEST_VIEW_HOURS[phase];
  const target = TimeEngine.getTimestampForLocalHour(
    targetAstronomic, bestLocalHour, timezoneOffset
  );
  setTimeState(prev => ({ ...prev, currentTimestamp: target, isPaused: true }));
}, [demoState.demoPhase, demoState.activePhenomenon]);
```

**关键点**：自动暂停 `isPaused: true`，让用户看清楚当前月相。

```tsx
function MoonPhaseDetailContent({ phaseIndex, activeTab, onTabChange, onBack }) {
  const phase = MOON_PHASES[phaseIndex];
  const tabs = [
    { key: 'knowledge', label: t.moonPhaseKnowledge },
    { key: 'poetry', label: t.moonPhasePoetry },
  ];

  return (
    <div className="space-y-3">
      {/* 头部 */}
      <div className="flex items-center justify-between">
        <div className="flex items-center gap-2">
          <span className="text-xl">{phase.icon}</span>
          <div>
            <h4 className="text-sm font-bold text-cyan-400">{t[phase.nameKey]}</h4>
            <p className="text-[10px] text-slate-500">
              第 {phase.index + 1} 个月相 · 共 8 个
            </p>
          </div>
        </div>
        {onBack && (
          <button onClick={onBack} className="text-[10px] text-slate-400 hover:text-slate-200">
            ← 返回
          </button>
        )}
      </div>

      {/* Tab 切换 */}
      <div className="flex gap-1">
        {tabs.map(tab => (
          <button
            key={tab.key}
            onClick={() => onTabChange(tab.key)}
            className={activeTab === tab.key ? '主题色高亮' : '默认'}
          >
            {tab.label}
          </button>
        ))}
      </div>

      {/* Tab 内容 */}
      {activeTab === 'knowledge' && (
        <div className="p-3 rounded-xl border border-cyan-500/30 bg-cyan-500/10">
          <p className="text-xs text-slate-200 leading-relaxed">
            {isZh ? phase.knowledgeZh : phase.knowledgeEn}
          </p>
        </div>
      )}

      {activeTab === 'poetry' && (
        <div className="p-3 rounded-xl bg-white/[0.03] border border-white/5">
          <p className="text-xs font-bold text-cyan-400">
            《{isZh ? phase.poetry.title : phase.poetry.titleEn}》
          </p>
          <p className="text-[10px] text-slate-500">
            [{isZh ? phase.poetry.dynasty : phase.poetry.dynastyEn}] {isZh ? phase.poetry.author : phase.poetry.authorEn}
          </p>
          <div className="mt-2 space-y-0.5">
            {(isZh ? phase.poetry.lines : phase.poetry.linesEn).map((line, i) => (
              <p key={i} className="text-xs text-slate-300 italic">{line}</p>
            ))}
          </div>
        </div>
      )}
    </div>
  );
}
```

## 5. 踩坑记录

1. **闭包陷阱**：在 rAF 回调中直接调用 `handleSelectPhase`，捕获旧的 `demoState`。修正为 `useEffect` 监听 `demoPhase`。
2. **月相时间未考虑时区**：`getExactMoonPhaseTime` 返回 UTC，未转换为本地最佳观测时间。修正为叠加 `getTimestampForLocalHour`。
3. **农历混淆**：早期科普文本将朔望月与恒星月混为一谈。修正为明确区分 29.53 天和 27.32 天。
