
# 剖面模式实现思路文档

## 一、核心设计思路

剖面模式通过**三步法**实现星球内部结构的可视化展示：
1. **表面裁剪** - 切掉星球表面的 1/8 区域（第一卦限）
2. **剖面填充** - 用三个扇形平面填补切口
3. **交互增强** - 鼠标悬停显示层级信息

## 三、实现核心

### 1. 表面裁剪（Shader 实现）

在星球表面的 Fragment Shader 中添加裁剪逻辑：

```glsl
// 在 SolarSystem.tsx 的各 shader 中
uniform bool uShowStructure;
varying vec3 vPosition;

void main() {
  // 裁剪条件：x>0 且 y>0 且 z>0（第一卦限）
  if (uShowStructure &amp;&amp; vPosition.x &gt; 0.0 &amp;&amp; vPosition.y &gt; 0.0 &amp;&amp; vPosition.z &gt; 0.0) {
    discard; // 丢弃该区域像素
  }
  // ... 原有渲染逻辑
}
```

### 2. 剖面填充（三平面方案）

`PlanetStructure.tsx` 使用 **三个扇形平面** 填补切口：

| 平面 | 位置 | 方向 | 覆盖区域 |
|------|------|------|---------|
| XY 平面 | Z=0 | 朝上 | X&gt;0, Y&gt;0 |
| YZ 平面 | X=0 | 朝右 | Y&gt;0, Z&gt;0 |
| XZ 平面 | Y=0 | 朝前 | X&gt;0, Z&gt;0 |

**几何体创建**（components/PlanetStructure.tsx:207）：
```tsx
&lt;circleGeometry 
  args={[radius, 64, thetaStart, Math.PI / 2]} 
/&gt;
// radius: 星球半径
// 64: 分段数（平滑度）
// thetaStart: 起始角度
// Math.PI / 2: 扇形角度（90度）
```

### 3. 层级着色（Shader 实现）

剖面使用自定义 Shader 绘制同心层级：

```glsl
// components/PlanetStructure.tsx:85-146
void main() {
  float dist = length(vPosition);
  float normDist = dist / uRadius;
  
  // 遍历层级，找到当前像素所属层级
  for (int i = 0; i &lt; 10; i++) {
    if (i &gt;= uNumLayers) break;
    if (normDist &lt;= uLayerRadii[i] + 0.001) {
      color = uLayerColors[i];
      break;
    }
  }
  
  // 悬停高亮效果
  if (isHovered) {
    color = mix(color, vec3(1.0), 0.75);
  }
}
```

## 四、交互流程

```
用户点击信息面板"内部结构"按钮
    ↓
App.tsx 更新 showStructure 和 structureTarget 状态
    ↓
SolarSystem.tsx 接收状态，切换星球表面 Shader 的裁剪
    ↓
同时渲染 PlanetStructure 组件
    ↓
鼠标悬停剖面 → 检测交点 → 显示层级信息卡片
```

## 五、关键优化点

1. **Z-Fighting 解决**：使用 `polygonOffset` 让剖面稍微靠前，避免与星球表面重叠闪烁
   ```tsx
   // components/PlanetStructure.tsx:216-218
   polygonOffset={true}
   polygonOffsetFactor={-4}
   ```

2. **悬停检测**：将交点坐标转换到局部空间，计算距离判断层级
   ```tsx
   // components/PlanetStructure.tsx:149-175
   const localPoint = e.point.clone().applyMatrix4(meshInverseMatrix);
   const dist = localPoint.length();
   const normDist = dist / radius;
   ```

3. **信息展示**：使用 `@react-three/drei` 的 `Html` 组件在 3D 空间中渲染 2D 卡片

## 六、快速复用指南

如果你想在其他项目中实现类似功能，只需：

1. 定义结构数据（类似 `PLANET_STRUCTURES`）
2. 实现表面裁剪 Shader
3. 复制 `PlanetStructure.tsx` 中的剖面渲染逻辑
4. 按需调整交互效果
