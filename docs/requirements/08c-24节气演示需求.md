# 24节气演示需求文档

> 版本: v1.0 | 日期: 2026-06-08 | 所属系统: 天文演示系统

---

## 1. 目标

### 1.1 教学目标

让用户通过 24 步分步演示（每个节气一步），理解以下天文与文化知识：
1. **24 节气的天文本质**：太阳在黄道上每 15° 一个等分点，是纯粹的天文事件，与农历无关
2. 节气与**太阳直射点纬度**的关系：夏至直射北回归线（+23.4°），冬至直射南回归线（-23.4°）
3. 不同节气对应的**昼夜长短变化**和**正午太阳高度角**
4. 24 节气对应的**物候现象**、**传统习俗**和**古典诗词**
5. 纠正"节气是农历概念"的常见误解

### 1.2 功能目标

- 实现 24 个节气的分步演示，按四季分组导航
- 每个节气自动跳转到该年该节气的精确天文时刻
- 提供物候/诗词/日照观测台三 Tab 信息面板
- 圆形日照表盘实时计算并展示日出日落、昼长夜长

## 2. 选型（选型原因）

### 2.1 24 步一步一节气模型

**原因**：24 节气是中国传统历法的核心，每个节气都有独立的天文意义和文化内涵。一步一节气让用户逐一探索，而非只展示 4 个主要节气。

### 2.2 精确天文算法计算节气时刻

**原因**：节气时刻由太阳黄经决定（如春分 = 黄经 0°）。通过 `AstrophenomenaEngine.getSolarTermTimestamp(year, eclipticLongitude)` 逐年计算，确保演示日期与该年真实节气时刻一致。

### 2.3 conic-gradient 圆形日照表盘

**原因**：
- 24 小时昼夜分布天然是圆形/环形
- `conic-gradient` 原生支持角度渐变，性能最优
- 蓝色（黑夜）+ 黄色（白昼）弧段的视觉呈现直观易懂

### Step 4: 日照观测台计算

**太阳赤纬公式**：
```
δ = arcsin(sin(ε) × sin(λ))
```
其中 ε = 23.439°（黄赤交角），λ 为太阳黄经。

**日出时角公式**：
```
cos(ω) = -tan(φ) × tan(δ)
```
其中 φ 为观测纬度（默认 40°N）。

**极昼极夜保护**：
当 `|tan(φ) × tan(δ)| > 1` 时，`cos(ω)` 超出 [-1, 1]，此时发生极昼（δ 与 φ 同号）或极夜（异号）。

**实现代码**：
```typescript
function calculateDaylightData(eclipticLongitude: number) {
  const OBLIQUITY = 23.439;
  const lambda = (eclipticLongitude * Math.PI) / 180;
  const decl = Math.asin(Math.sin(OBLIQUITY * Math.PI / 180) * Math.sin(lambda));
  const declDeg = (decl * 180) / Math.PI;

  const latRad = (REF_LATITUDE * Math.PI) / 180;
  let cosHa = -Math.tan(latRad) * Math.tan(decl);
  cosHa = Math.max(-1, Math.min(1, cosHa)); // 极昼极夜保护
  const haRad = Math.acos(cosHa);
  const haDeg = (haRad * 180) / Math.PI;

  const dayHours = 2 * haDeg / 15;
  const sunrise = 12 - dayHours / 2;
  const sunset = 12 + dayHours / 2;
  const nightHours = 24 - dayHours;
  const noonAltitude = 90 - Math.abs(REF_LATITUDE - declDeg);

  return { declination: declDeg, dayHours, sunrise, sunset, nightHours, noonAltitude };
}
```

### Step 5: 圆形日照表盘渲染

**CSS conic-gradient**：
```css
background: conic-gradient(
  #1e3a8a 0%,                    /* 午夜 */
  #1e3a8a ${(sunrise/24)*100}%,  /* 日出前 */
  #eab308 ${(sunrise/24)*100}%,  /* 日出 */
  #eab308 ${(sunset/24)*100}%,   /* 日落 */
  #1e3a8a ${(sunset/24)*100}%,  /* 日落后 */
  #1e3a8a 100%                   /* 午夜 */
);
```

**表盘元素**：
- 外圈：24 小时刻度（00, 06, 12, 18）
- 内圆：数字日出时间 + "日出"标签
- 正午指针：从圆心指向顶部的发光指针

## 4. 页面设计

### 4.1 主视口设计

**宇宙视角**：
- 相机从黄道面外侧斜上方观察地球公转
- 地球公转轨道上用 24 个发光节点标记节气位置
- 当前节气节点高亮显示，并标注太阳黄经角度
- 太阳直射点位置在地球表面用小光点标识

**地面观测视角**：
- 展示该节气日期当天太阳的轨迹（从日出到日落）
- 太阳轨迹的弧度和最高点高度随节气明显变化
