# 星表与观星系统需求文档 (StarDatabase / ObserverEngine)

> 版本: v1.0 | 日期: 2026-06-08 | 模块: StarDatabase / ObserverEngine / ExtraStarsDatabase (L0/L1 引擎层)

---

## 1. 模块目标

星表与观星系统是 GalaxySim3D 的**地面观测计算中枢**，负责：
1. 存储和管理恒星数据（Hipparcos 星表、42 颗亮星详细数据、星座连线关系）
2. 计算从任意太阳系天体表面观测到的星空图像
3. 执行岁差、章动、赤道-水平坐标转换、大气消光等天文计算
4. 支持从地球以外的天体（如月球、火星）表面观星

**核心价值**: 将抽象的星表数据转化为用户在"地面观星"模式下看到的真实星空，包括正确的恒星位置、亮度、颜色、星座连线和日月位置。

## 2. 核心原理与算法

### 2.1 星表数据与 Hipparcos 星表

**Hipparcos 星表** 是欧洲空间局 (ESA) 于 1997 年发布的恒星位置精密星表：
- 测量方法: 空间三角视差测量（卫星在地球轨道外观测）
- 覆盖范围: 全天约 118,000 颗恒星
- 精度: 位置精度约 0.001 角秒（ milliarcsecond 级别）
- 项目中使用子集: 视星等 ≤ 6.5 的约 8,785 颗亮星

**星表字段说明**：
- **HIP 编号**: Hipparcos 恒星唯一标识
- **RA (Right Ascension)**: 赤经，单位小时 (0~24h)，J2000.0 历元
- **Dec (Declination)**: 赤纬，单位度 (-90°~+90°)，J2000.0 历元
- **Vmag (Visual Magnitude)**: 视星等，数值越小越亮
- **B-V 色指数**: 蓝-目视星等差，决定恒星颜色（蓝星 B-V < 0，红星 B-V > 0.5）
- **Plx (Parallax)**: 视差角，用于计算距离: `距离(pc) = 1000 / Plx(mas)`
- **pmRA, pmDE**: 自行（赤经/赤纬方向的年移动量，单位 mas/年）

**视星等尺度**：
- 太阳: -26.7（白昼不可直视）
- 满月: -12.7
- 天狼星: -1.46（最亮恒星）
- 北极星: 2.0
- 肉眼极限（郊区）: 6.0~6.5
- 肉眼极限（城市）: 4.0~5.0

**星等差公式**: `m₁ - m₂ = -2.5 × log₁₀(F₁/F₂)`
即星等差 5 等对应亮度比 100 倍，差 1 等对应亮度比约 2.512 倍。

### 2.2 岁差修正 (Precession)

**物理原理**: 地球自转轴像陀螺一样进动，周期约 25,800 年。这导致春分点每年西移约 50.3 角秒，恒星的赤道坐标随之缓慢变化。

**IAU 2006 岁差矩阵**（从 J2000.0 到当前历元）：
```
ζ_A = 2.650545 + 2306.077181 × T + 0.2988499 × T² + 0.01801828 × T³  (角秒)
θ_A = 2004.191903 × T - 0.4294934 × T² - 0.04182264 × T³  (角秒)
z_A = -2.650545 + 2306.077181 × T + 1.0927348 × T² + 0.01826837 × T³  (角秒)
```
其中 `T = yearsSinceJ2000 / 100`（儒略世纪数）。

**简化理解**: 
- 经过 100 年，恒星坐标变化约 1.4 度
- 经过 2000 年（如公元元年至现在），变化约 30 度
- 因此在公元前时期，北极星不是现在的勾陈一，而是天龙座的右枢

### 2.3 章动修正 (Nutation)

**物理原理**: 月球轨道面（白道面）相对于黄道面有 5.1° 的倾角，且白道面本身在进动（周期 18.6 年）。这导致地球自转轴在岁差基础上叠加微小摆动。

**IAU 1980 简化章动模型**:
```
Δψ = -17.20"·sin(Ω) - 1.32"·sin(2L) - 0.23"·sin(2L') + 0.21"·sin(2Ω)
Δε = +9.20"·cos(Ω) + 0.57"·cos(2L) + 0.10"·cos(2L') - 0.09"·cos(2Ω)
```
其中:
- Ω = 月球升交点黄经 = 125.04452° - 1934.136261° × T
- L = 太阳平黄经
- L' = 月球平黄经

**影响量级**: ±17 角秒（经度）和 ±9 角秒（倾角），对肉眼观测不可见，但在精确计算中必须包含。

### 2.4 黄道-赤道坐标转换

**黄赤交角 (Obliquity of Ecliptic)**: 地球赤道面与黄道面的夹角，J2000.0 时刻约 23.439°。

**转换公式**（从黄道笛卡尔坐标到赤道笛卡尔坐标）：
```
X_eq = X_ecl
Y_eq = Y_ecl × cos(ε) - Z_ecl × sin(ε)
Z_eq = Y_ecl × sin(ε) + Z_ecl × cos(ε)
```
其中 ε 为黄赤交角 + 章动倾角修正。

**赤道到水平坐标转换**:
```
时角 HA = LST - RA  (小时)
高度角 sin(Alt) = sin(Dec)·sin(φ) + cos(Dec)·cos(φ)·cos(HA)
方位角 cos(Az) = (sin(Dec) - sin(Alt)·sin(φ)) / (cos(Alt)·cos(φ))
```
其中 φ 为观测者纬度，Az 从南点开始（天文惯例）或从北点开始（导航惯例）。

### 2.5 大气消光 (Atmospheric Extinction)

**物理原理**: 星光穿过地球大气层时，因散射和吸收而衰减。低高度角的星光穿过更厚的大气层，衰减更严重。

**简化消光模型**:
```
消光系数 k ≈ 0.2（可见光平均，干净大气）
大气质量 X = 1 / sin(Alt)  （当 Alt > 10°）
星等衰减 Δm = k × X
```

**影响**:
- 天顶（Alt=90°）: Δm ≈ 0.2 等
- 高度角 30°: Δm ≈ 0.4 等
- 高度角 10°: Δm ≈ 1.2 等（接近地平线时急剧变暗）

**颜色变化**: 消光对蓝光影响更大，因此低高度角的恒星看起来更红（类似日出日落时太阳变红）。

### 2.6 多参考系观测

项目支持从任意太阳系天体表面观测星空：

**从非地球天体观测的特殊性**：
1. **恒星时计算不同**: 使用该天体的自转周期而非地球的 23.934 小时
2. **行星视运动**: 从其他行星看，地球和其他行星的位置不同
3. **太阳视运动**: 太阳在天空中的轨迹取决于该天体的黄赤倾角
4. **月球视运动**: 若从月球看，地球几乎固定在天空某处（潮汐锁定）

**多参考系坐标转换链路**：
```
目标天体日心坐标 - 观测天体日心坐标 = 相对矢量
→ 赤道坐标 (RA, Dec) → 水平坐标 (Az, Alt)
```

## 4. 接口契约

```typescript
interface DetailedStar {
  id: number;
  nameKey: string;
  ra: number;        // 赤经 (小时)
  dec: number;       // 赤纬 (度)
  mag: number;       // 视星等
  color: number;     // 16进制颜色
  dist: number;      // 距离 (光年)
  nameZh: string;
  nameEn: string;
  constellZh: string;
  constellEn: string;
  pmRa?: number;     // 自行 RA (mas/年)
  pmDec?: number;    // 自行 Dec (mas/年)
}

interface PlanetSkyInfo {
  id: string;
  ra: number;
  dec: number;
  distAU: number;
  angularDiameter: number;
  magnitude: number;
  color: number;
}

interface ObserverContext {
  bodyId: string;
  latitude: number;
  longitude: number;
}

class ObserverEngine {
  /** 章动角计算 */
  static getNutationAngles(days: number): {deltaPsiRad: number; deltaEpsilonRad: number};

  /** 黄道转赤道坐标 */
  static eclipticToEquatorial(x: number, y: number, z: number, days?: number): {x, y, z};

  /** 矢量转赤经/赤纬 */
  static vectorToRADec(vx: number, vy: number, vz: number): {ra: number; dec: number};

  /** 任意天体的本地恒星时 */
  static getLocalSiderealTime(ctx: ObserverContext, timestamp: number): number;

  /** 太阳视位置 */
  static getSolarRADec(ctx: ObserverContext, days: number): {ra: number; dec: number};

  /** 行星视位置 */
  static getPlanetRADec(ctx: ObserverContext, targetId: string, days: number): PlanetSkyInfo;

  /** 月球视位置 */
  static getLunarRADec(ctx: ObserverContext, days: number): {ra: number; dec: number};
}
```

## 7. 已知问题与边界

1. **自行忽略**: 当前模型未考虑恒星自行（除岁差外），经过数千年后位置会有微小偏差
2. **大气消光简化**: 使用固定消光系数 k=0.2，未考虑不同波长、不同大气条件的影响
3. **光污染**: 未模拟城市光污染对极限星等的影响
4. **大气折射**: 未考虑大气折射（低高度角恒星实际位置比视位置高约 0.5°）
5. **双星系统**: Hipparcos 星表将部分双星合并为一个条目，可能造成视觉位置偏差
6. **星座边界**: 星座连线基于西方传统，未包含中国星官的全部细节
