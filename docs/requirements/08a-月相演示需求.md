# 月相变化演示需求文档

> 版本: v1.0 | 日期: 2026-06-08 | 所属系统: 天文演示系统

---

## 1. 目标

### 1.1 教学目标

让用户通过 8 步分步演示，理解以下天文知识：
1. 月相变化的本质是**日-地-月三者相对位置**的改变
2. **朔望月**（29.53 天）与**恒星月**（27.32 天）的区别
3. 每个月相的最佳地面观测时间与天空方位
4. 月相在中国古典诗词中的文化意象

### 1.2 功能目标

- 实现 8 个月相的精确时间自动跳转
- 支持"宇宙原理视角"与"地面观测视角"双模式切换
- 提供每个月相的科普知识与关联诗词详情页
- 支持地球/月球视角聚焦交互

## 2. 选型（选型原因）

### 2.1 8 步分步模型

**原因**：月相变化是连续过程，但教育场景需要关键节点。新月→峨眉月→上弦月→盈凸月→满月→亏凸月→下弦月→残月，8 个阶段覆盖了从不可见到满亮再回到不可见的完整周期，每个阶段都有明显的视觉特征和观测意义。

### 2.2 朔望月迭代搜索算法

**原因**：月相的精确时刻无法解析求解（月球运动受多体摄动）。采用已知基准新月 + 迭代梯度下降搜索，4 轮即可收敛到分钟级精度，满足教育演示需求，无需引入庞大的 ELP-2000 历表。

### 2.3 最佳观测本地时间修正

**原因**：月相的天文发生时刻（朔/望）不一定是最适合地面观测的时间。例如上弦月发生在白天时地面看不到，需将时间调整到当天傍晚 20:30（南方高空）。通过 `MOON_PHASE_BEST_VIEW_HOURS` 预设每个月相的最佳本地小时，再用 `getTimestampForLocalHour` 进行时区转换。

### Step 4: 精确新月搜索算法

```typescript
export function getCurrentCycleNewMoon(referenceTimestamp: number): number {
  const knownNewMoon = Date.UTC(2000, 0, 6, 18, 14, 0);
  const monthsSince = (referenceTimestamp - knownNewMoon) / SYNODIC_MONTH_MS;
  let baseTs = knownNewMoon + Math.floor(monthsSince) * SYNODIC_MONTH_MS;
  
  let step = 24 * 3600 * 1000;
  for (let iter = 0; iter < 4; iter++) {
    let bestTs = baseTs;
    let minAngle = Infinity;
    for (let offset = -5; offset <= 5; offset++) {
      const ts = baseTs + offset * step;
      const days = (ts - J2000_TIMESTAMP) / 86400000;
      const earthPos = OrbitEngine.getHeliocentricPosition('earth', days);
      const moonRel = OrbitEngine.getLunarRelativePosition(days);
      const es = { x: -earthPos.x, y: -earthPos.y, z: -earthPos.z };
      const dot = es.x * moonRel.x + es.y * moonRel.y + es.z * moonRel.z;
      const angle = Math.acos(dot / (len(es) * len(moonRel)));
      if (angle < minAngle) { minAngle = angle; bestTs = ts; }
    }
    baseTs = bestTs;
    step /= 5;
  }
  return baseTs;
}
```

## 4. 页面设计

### 4.1 主视口设计

**宇宙视角（viewMode='universe'）**：
- 相机预设：从地球外侧斜上方俯瞰日-地-月系统
- 高亮：月球轨道线高亮，日-地连线用半透明光束表示
- 地球始终为选中状态

**地面观测视角（viewMode='starry'）**：
- 观测点：默认 31.23°N, 121.47°E（可修改）
- 天空中的月球按真实方位和高度角显示
- 月相 Sprite 根据 `phaseIndex` 显示对应的照亮比例
