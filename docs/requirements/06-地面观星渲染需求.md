# 地面观星渲染需求文档 (StarrySkyViewer)

> 版本: v1.0 | 日期: 2026-06-08 | 模块: StarrySkyViewer (L2 渲染层)

---

## 1. 模块目标

地面观星渲染器是 GalaxySim3D 的**天顶投影渲染引擎**，负责：
1. 以观测者为球心，渲染全天球星图投影
2. 正确显示太阳、月球、行星在天空中的视位置
3. 渲染星座连线、星名标签、星座名称
4. 实现曙暮光大气散射、地平线网格、方位标记
5. 提供望远镜模式（FOV 可调视场限制）
6. 实现日月出没时间计算和视觉效果

**核心价值**: 为用户提供真实的地面天文观测体验，是连接轨道计算与实际观星的桥梁。

---

## 2. 核心原理与渲染技术

### 2.1 天球投影几何

**天球 (Celestial Sphere)** 是天文学中的虚拟概念：
- 以观测者为球心，任意大的假想球面
- 所有天体（无论远近）都投影在这个球面上
- 恒星因为距离极远，其相对位置不随观测者移动而改变（忽略视差）

**水平坐标到 3D 坐标的转换**：
```
X = -cos(Alt) × cos(Az)
Y = sin(Alt)
Z = cos(Alt) × sin(Az)
```
注意坐标系约定：Y 轴向上（高度角），Az 从北向东转。

**天球半径**: 渲染中使用一个较大的固定半径（如 150 场景单位），所有恒星、星座连线、日月都投影在这个半径上。

### 2.2 恒星渲染策略

**背景暗星（Hipparcos 星表，~8785 颗）**：
- 使用 THREE.Points 批量渲染
- 每颗星是一个顶点，颜色和大小通过 attribute 控制
- 大小与亮度相关: `pointSize ∝ 10^(-0.4 × mag)`
- 岁差修正必须在 CPU 或 GPU 中完成，将 J2000.0 坐标转换到当前历元

**亮星（42 颗）**：
- 使用 THREE.Sprite 独立渲染（便于交互和标签）
- 或合并到同一 Points 系统中通过 attribute 区分
- 每颗亮星有名称标签，可点击显示信息

**星座连线**：
- 使用 THREE.LineSegments
- 连线只连接位于地平线上的恒星（或至少有一颗在地平线上）
- 连线颜色通常为淡蓝色或淡紫色，半透明

### 2.3 大气散射与天空颜色

**物理原理**: 白天天空的颜色由瑞利散射决定——大气分子对短波长（蓝光）散射更强。

**简化模型**（片段着色器）：
```
天空颜色 = 大气颜色 × (1 - 太阳高度因子) + 地平线颜色 × 地平线因子
太阳高度因子 = max(dot(视线方向, 太阳方向), 0)
```

**曙暮光 (Twilight) 分级**：
- 民用曙暮光: 太阳高度角 -0° ~ -6°，天空仍较亮
- 航海曙暮光: -6° ~ -12°，较暗但地平线可见
- 天文曙暮光: -12° ~ -18°，几乎完全黑暗
- 黑夜: 太阳高度角 < -18°，最佳观星条件

**项目实现**: 根据太阳高度角动态调整天空背景色和恒星可见亮度阈值。

### 2.4 日月渲染

**太阳**：
- 白天: 在天球上渲染为明亮的圆盘 Sprite
- 日落/日出: 颜色从白变黄、橙、红
- 靠近地平线: 受大气折射和消光影响，视觉形状略扁

**月球**：
- 根据月相渲染不同的照亮比例
- 使用 Sprite 或 Mesh，配合遮罩纹理
- 月相纹理基于实际光照方向计算

**行星**：
- 在天空中渲染为较亮的点（类似亮星）
- 金星最亮可达 -4.4 等，肉眼可见为明显亮点
- 行星不闪烁（与恒星的重要区别）

### 2.5 望远镜模式

**功能**: 模拟不同倍数光学望远镜的视场（FOV）

**实现方式**：
- 用圆形遮罩限制可见区域
- 调整相机 FOV: `FOV = 实际望远镜视场`
  - 双筒望远镜: 7°~10°
  - 低倍望远镜: 1°~3°
  - 高倍望远镜: 0.5°~1°
- 可叠加十字丝、刻度网格

## 4. 性能需求

| 指标 | 目标 |
|------|------|
| 恒星计算 | 当前 CPU 循环 8785 颗/帧，需优化为 Shader 化或缓存 |
| 星座连线 | 只计算地平线以上的连线 |

| 帧率目标 | 1x 流速 ≥ 60fps，3600x 流速 ≥ 45fps |

## 5. 验证要点

| 验证项 | 方法 | 预期结果 |
|--------|------|----------|
| 北极星位置 | 北纬 40° 观测 | 高度角 ≈ 40°，靠近北点 |

| 岁差效果 | 2000 年 vs 1900 年北极星位置 | 约 1.4° 偏移 |
| 望远镜模式 | 切换倍率 | 视场角相应变化 |
| 白天恒星 | 正午时分 | 不可见（或被太阳淹没） |

## 6. 已知问题与边界

1. **CPU 瓶颈**: 当前每帧对 8785 颗恒星执行岁差+水平坐标+消光计算，是最大性能瓶颈
2. **Shader 化需求**: 必须将恒星计算迁移到 GPU 顶点着色器
3. **Sprite 性能**: 42 颗亮星使用独立 Sprite，每帧逐个更新位置，draw call 高
4. **天空颜色简化**: 当前使用 fbm 噪声计算大气散射，复杂度高，需简化
5. **无大气折射**: 未模拟大气折射，低高度角天体位置有约 0.5° 偏差
6. **无城市光污染**: 未模拟光污染对极限星等的影响
