# 月食演示需求文档

> 版本: v2.0 | 日期: 2026-06-08 | 所属系统: 天文演示系统
>
> **定位说明**：在 GalaxySim3D 的演示架构中，日食与月食统一归属于 `eclipses` 现象（共 4 个演示步骤）。本文档负责阐述**步骤 3**（地球的影子与血月）的教学目标与功能需求。步骤 0~2（太阳光束 → 月球影子锥 → 地球被笼罩）见[日食演示需求](08b-日食演示需求.md)。

---

## 1. 目标

### 1.1 教学目标

让用户通过时间轴驱动的交互演示理解：

1. **月食的本质**：在满月（望）时，地球运行到日月之间，地球的影子锥投射到月球表面，遮挡了原本照射月球的阳光。
2. **本影、半影与伪本影的区别**：
   - **半影（Penumbra）**：月球进入地球半影区时，太阳光被地球部分遮挡，月球亮度轻微变暗，称为**半影月食（Penumbral Lunar Eclipse）**。肉眼通常难以察觉。
   - **本影（Umbra）**：月球进入地球本影区时，太阳光被地球完全遮挡。若仅部分进入，为**月偏食（Partial Lunar Eclipse）**；若完全进入，为**月全食（Total Lunar Eclipse）**。
   - 与日食不同，月食不存在“伪本影”概念，因为地球的阴影锥长度（约 **140 万公里**）远大于地月距离（约 **38 万公里**），本影锥顶点始终远在月球轨道之外。
3. **月食的类型及其几何判定条件**：
   - **半影月食**：月球的中心距地影轴大于 `R本影 + R月`，但小于 `R半影 + R月`。
   - **月偏食**：月球部分盘面进入地球本影。本影食分 `0 < u < 1`。
   - **月全食**：月球整个盘面进入地球本影。本影食分 `u ≥ 1`。
4. **血月（Blood Moon）现象的物理原理**：
   - 月全食时，地球挡住了直射月球的阳光，但月球并不会完全变黑。
   - 地球大气层对太阳光中的**蓝光**产生强烈的**瑞利散射（Rayleigh Scattering）**，将其散射到四面八方；而对**红光**的散射较弱，红光能够穿透大气层并发生折射。
   - 折射后的红光被“弯曲”到地球本影锥内，照射到月球表面，月球再将其反射回地球。
   - 因此，月全食期间的月球呈现暗红色或古铜色，称为“血月”。
   - 血月的深浅受地球大气状态影响：火山喷发后大气中尘埃增多，血月会更暗甚至呈黑灰色（丹戎标度 Danjon Scale）。
5. **通过真实 NASA/GSFC 权威数据感受月食的科学记录**：数据覆盖 2020–2030 年共 25 次月食事件，包含本影食分、偏食/全食持续时间、沙罗周期编号等字段。

### 1.2 功能目标

- 在统一交食演示框架下，实现步骤 3 的三维可视化教学。
- 集成 NASA 真实月食数据（`LUNAR_ECLIPSE_EVENTS`），支持下拉选择具体事件，默认优先展示月全食事件（视觉效果最佳）。
- 提供时间轴滑块，让用户手动控制月食进程（半影食始 → 初亏 → 食既 → 食甚 → 生光 → 复圆 → 半影食终）。
- 实时显示月食几何指标：本影食分（Umbral Magnitude）、对齐偏差角、月球入影深度百分比、当前阶段状态。
- 特别强调血月现象的物理原理，在信息面板中提供瑞利散射的文字 + 色彩可视化解释。
- 支持**严格物理模式**与**演示放大模式**两种尺度切换。

## 2. 选型（选型原因）

### 2.1 将月食作为统一 `eclipses` 现象的第 4 个步骤

**原因**：
- 日食与月食在物理上互为对偶现象，共享同一套交食检测引擎、事件选择器和时间轴控制框架。
- 将月食放在步骤 3（最后一步），教育叙事上形成递进：先理解“谁在挡太阳”（步骤 1~2：月球挡太阳），再理解“谁在挡月球的光”（步骤 3：地球挡太阳）。
- 代码层面，影子锥渲染逻辑（`earthUmbraCone`、`earthUmbraDisc`）与日食的 `moonUmbraCone` 共享同一套 `computeShadowCone` 数学工具，统一维护成本低。

### 2.2 单步骤但包含完整时间轴与子阶段导航

**原因**：
- 月食的全过程比日食长得多（半影月食可持续 4~6 小时，全食阶段也可达 1 小时以上），不适合用多步骤硬切分。
- 采用单一步骤（步骤 3）+ 时间轴滑块的连续探索模式，更符合月食作为“缓慢上演的天象”的物理特征。
- 在引导面板中，使用 **5 个子阶段按钮**（初亏前 → 初亏 → 全食 → 复圆 → 复圆后）作为快捷导航，兼顾连续性与关键节点跳转。

### 2.3 NASA 真实月食数据驱动 + 血月材质动态变化

**原因**：
- 精确月食预测同样需要复杂的地球椭球阴影模型和月球天平动修正，教育场景直接使用 NASA 权威数据。
- 血月是月全食最吸引人的视觉特征，必须在 3D 渲染中通过动态材质颜色变化直观呈现（而非仅文字说明）。
- 数据量可控（2020–2030 年 25 次月食事件），其中月全食 9 次、月偏食 7 次、半影月食 9 次。

### 2.4 4 小时交食窗口 + 同心圆表盘

**原因**：
- 月食全过程通常持续 3~5 小时（日食通常 2~3 小时）。使用 4 小时窗口比日食的 3 小时更合理，能完整覆盖初亏到复圆。
- 月食的几何重点是“月球进入地球阴影的深度”，同心圆表盘（外圆半影边界、中圆本影边界、内圆月球当前位置）比日食的弧形偏差角表盘更直观。

## 3. 核心天文原理（需求文档必须包含的真实世界知识）

### 3.1 地球阴影锥的几何学

月食的本质是地球遮挡了射向月球的阳光。地球在背日方向投下巨大的阴影锥：

1. **本影锥（Umbra）**：太阳光被地球完全遮挡的区域。本影锥半顶角 `θ_u` 满足：
   ```
   sin(θ_u) = (R☉ − R⊕) / d☉地
   ```
   其中 `R☉ ≈ 696,340 km`，`R⊕ ≈ 6,371 km`，`d☉地` 为日地中心距离。

   地球本影锥长度 `L_u`：
   ```
   L_u = R⊕ / sin(|θ_u|) = R⊕ · d☉地 / (R☉ − R⊕)
   ```
   在典型的日地距离下，`L_u ≈ 1,400,000 km`，远大于地月平均距离 `384,400 km`。这意味着：
   - 地球本影锥顶点**永远**在月球轨道之外，月球不可能进入伪本影。
   - 只要月球进入地球本影，就一定是**全食**或**偏食**，不存在“环月食”。

2. **半影锥（Penumbra）**：太阳光被地球部分遮挡的区域。半影锥半顶角 `θ_p`：
   ```
   sin(θ_p) = (R☉ + R⊕) / d☉地
   ```
   地球半影锥在月球距离处的截面半径约 `3,500 km`，远大于月球半径 `1,737 km`，因此半影区很容易覆盖整个月球。

3. **本影食分（Umbral Magnitude）**：
   ```
   u = (R本影 + R月 − d_axis) / (2 · R月)
   ```
   其中 `d_axis` 为月球中心到地影轴的距离。
   - `u < 0`：月球未进入本影，仅半影食。
   - `0 ≤ u < 1`：月偏食。
   - `u ≥ 1`：月全食。`u` 越大，全食阶段越长。

### 3.2 月食 vs 日食的关键物理差异

| 对比项 | 日食 | 月食 |
|--------|------|------|
| 遮挡天体 | 月球遮挡太阳 | 地球遮挡太阳（月球被遮） |
| 阴影投射方向 | 月球 → 地球 | 地球 → 月球 |
| 本影锥长度 | ~373,000 km（与地月距离相当） | ~1,400,000 km（远大于地月距离） |
| 观测位置限制 | 仅地球上本影带内窄区可见全食 | 整个夜半球都能看到 |
| 发生条件 | 朔（新月）+ 黄白交点附近 | 望（满月）+ 黄白交点附近 |
| 全食持续时间 | 仅数分钟（最长约 7.5 分钟） | 可达 1 小时以上（最长约 1 小时 47 分钟） |
| 特殊现象 | 贝利珠、钻石环、日冕 | 血月（瑞利散射） |
| 安全注意 | **绝对不可直视太阳** | 可直接肉眼观测，完全安全 |
| 发生频率 | 每年 2~5 次，同一地点全食间隔数百年 | 每年至少 2 次，全食约每 1~2 年一次 |

### 3.3 瑞利散射与血月的光物理学

血月现象是连接天文观测与大气物理的绝佳教学点：

1. **瑞利散射定律**：大气分子对短波长（蓝光，~450 nm）的散射强度与波长四次方成反比（`I ∝ 1/λ⁴`）。因此蓝光的散射强度约为红光的 `(700/450)⁴ ≈ 5.9` 倍。
2. **光路弯曲**：月全食时，直射月球的阳光被地球本体挡住。但地球大气层像一个“透镜”，将日出/日落时穿透大气层的阳光折射到本影锥内。
3. **红光占优**：蓝光在穿透大气层的过程中被反复散射到四面八方（这就是天空呈蓝色的原因），只剩红光能沿着弯曲路径到达月球。
4. **月球反射**：到达月球表面的红光被月壤反射回地球，进入观测者的眼睛，因此月亮看起来是暗红色的。
5. **丹戎标度（Danjon Scale）**：用于量化月全食时月球的亮度，从 0（极暗，几乎不可见）到 4（亮铜红色，非常显眼）。影响因素包括：
   - 地球大气中的火山尘埃含量（尘埃多 → 更暗）
   - 月全食时月球在地影中的深度（越深 → 越暗）
   - 地球大气层的透明度（云层/污染多 → 更暗）

### 3.4 月食的完整阶段定义

一次典型的月全食包含以下 7 个阶段（时间顺序）：

| 阶段 | 英文名 | 定义 | 天文条件 |
|------|--------|------|----------|
| P1 | 半影食始 | 月球东侧边缘与地球半影外切 | 月球首次接触半影 |
| U1 | 初亏 | 月球东侧边缘与地球本影外切 | 月球首次接触本影，偏食开始 |
| U2 | 食既 | 月球完全进入地球本影 | 全食开始，血月出现 |
| 食甚 | Maximum | 月球中心最接近地影轴 | 本影食分达到最大值 |
| U3 | 生光 | 月球西侧边缘与地球本影内切 | 全食结束，偏食恢复 |
| U4 | 复圆 | 月球西侧边缘与地球本影外切 | 偏食结束 |
| P4 | 半影食终 | 月球西侧边缘脱离地球半影 | 月食完全结束 |

**注意**：半影月食只有 P1 和 P4；月偏食有 P1、U1、U3、U4；月全食才有完整的 7 个阶段。

### Step 5: 时间轴滑块与交食窗口

**窗口计算**：
- 月食默认窗口为 `±4 小时`（以 NASA 食甚时刻为中心），比日食的 3 小时更长，因为月食全过程通常更久。

  - 若 NASA 数据提供了 `partialDuration`（如 `"03h38m"`），解析为毫秒后，以食甚为中心对称展开窗口。

- 若无 NASA 数据，回退到 `getEclipseWindow(timestamp, 'lunar')`，使用 `detectEclipse()` 的 `lunarEclipse` 标志进行粗搜+精搜边界检测。

### Step 7: 月食几何指标与同心圆表盘

**显示指标**：
- **本影食分（Umbral Magnitude）**：
  - `u < 0`：半影月食
  - `0 ≤ u < 1`：月偏食
  - `u ≥ 1`：月全食（越大全食时间越长）
- **对齐偏差角**：日-地-月三点偏离直线的角度（单位：度）
- **月球入影深度百分比**：`(1 − d_axis / (R本影 + R月)) × 100%`
- **当前状态文本**：如 "半影月食 / 初亏 / 全食（血月）/ 食甚 / 生光 / 复圆"

**同心圆表盘设计**（引导面板内）：
- 外圆虚线：半影边界
- 中圆实线：本影边界
- 中心黑点：地影轴方向
- 月球图标沿轨道弧线移动，实时显示进入阴影的比例
- 颜色编码：月球图标在表盘中从亮白 → 暗红 → 黑，对应半影食 → 全食 → 食甚

### Step 8: 主视口渲染（月食部分）

**步骤 3（地球的影子与血月）**：
- 宇宙视角：地球位于日-月之间，展示地球阴影锥（`earthUmbraCone`）和月球进入阴影的过程。
- 地球本影锥采用**截头锥（CylinderGeometry）** + **截面盘（Disc）**组合：
  - 截头锥从地球表面（底半径 `earthRadiusScene`）收敛到月球距离处的截面半径。
  - 截面盘（`earthUmbraDisc`）放置在月球距离处，垂直于影轴，直观展示月球被阴影覆盖的程度。
  - 严格模式下，截面半径按物理公式 `Math.max(0.0001, earthRadiusScene − coneLen · tan(θ_u))` 计算；演示模式下放大至 `moonRadiusScene * 1.5` 以确保可见。
- 地球半影锥（`earthPenumbraCone`）默认隐藏，理由同日食半影锥（发散锥在深色宇宙背景中视觉干扰大）。
- 对齐指示线（`eclipseAlignmentLine`）连接地月中心，对准时高亮变红。
- 影轴线（`umbraAxisLine`）从地球中心沿背日方向延伸。
- 地面观测视角（`starry` 模式）：展示满月逐渐被地球阴影“咬掉”，全食阶段呈现暗红色。

### Step 9: 星空模式（地面观测视角）下的月食呈现

当用户切换至 `starry` 模式时，系统以地面观测者的第一人称视角呈现月食全过程，核心技术为**月球 Shader 实时阴影注入**与**月晕动态色彩变化**。

**月球 Shader 阴影注入（`moonMat.onBeforeCompile`）**：
- 通过 `eclipseUniformsRef` 向月球材质注入 7 个 Shader Uniform：
  - `uEclipseActive`：是否激活月食阴影计算（`0.0` 或 `1.0`）
  - `uShadowDirection`：地球本影方向的单位向量（实时更新）
  - `uUmbraRadius`：本影在月球视角下的角半径（弧度）
  - `uPenumbraRadius`：半影在月球视角下的角半径（弧度）
  - `uShadowSoftness`：阴影边缘软化宽度（弧度）
  - `uEclipseStrength`：整体食强度（用于淡入淡出）
  - `uBloodIntensity`：血月红色强度（`0.0` ~ `1.0`）
- 片元着色器逻辑：
  1. 计算月球表面法线与阴影方向的夹角 `angle`
  2. 若 `angle < uUmbraRadius + uShadowSoftness`，则进入月食着色
  3. 使用 `smoothstep` 生成本影遮罩 `umbraMask`
  4. 颜色混合：从正常月球纹理 → 冷阴影色（`rgb(0.08, 0.075, 0.09)`）→ 血月色（`rgb(0.95, 0.20, 0.065) * 0.34`）
  5. 血月强度由 `uBloodIntensity` 控制，当本影食分 `umbralMagnitude > 0.82` 时逐渐激活

**月晕（`moonHazeSpriteRef`）动态色彩变化**：
- **无食 / 初亏前**：月晕为标准朦胧白月光晕（`#dbeafe` 浅蓝色），透明度与月相百分比正相关。
- **偏食阶段**：月晕颜色从浅蓝向暗红（`#8b1a10`）插值，透明度降低，模拟月球亮度下降。
- **全食阶段（血月）**：月晕变为鲜红橙色（`#ff3311`），透明度升高至 `0.18~0.72`，形成血月周围的发光光晕，增强视觉冲击力。

**双模式月食激活机制**：
1. **选定事件模式**（`selectedLunarWindowActive`）：用户从下拉框选中某次月食事件，且当前时间在 `eclipseWindow` 范围内。此时使用 NASA 数据的 `umbralMagnitude` 和滑块 `progress` 精确控制阴影参数，确保与真实事件一致。
2. **自然模拟模式**（`naturalLunarEclipseActive`）：未选中特定事件时，由轨道引擎 `detectEclipse()` 实时计算地月日几何关系，当 `actualShadowSeparation < umbraVisualRadius + moonVisualRadius + shadowSoftness` 时自动触发月食渲染。此模式下食分由实时轨道决定，可能不完全匹配历史记录。

**性能优化**：
- 月食检测频率被限制为每 30 帧或模拟时间每推进 `0.01` 天（约 14.4 分钟）执行一次，避免每帧调用 `detectEclipse()` 带来的计算开销。
- 视觉夸大系数（`visualExaggeration = clamp(moonVisualRadius / moonPhysicalRadius, 1.0, 12.0)`）确保即使月球在屏幕上的显示尺寸被人为放大，阴影锥参数仍能正确匹配视觉比例。

**观测状态指示**：
- 星空模式底部信息栏显示 `⚠️食` / `⚠️Eclipse` 红色脉冲警告，提示用户当前正处于月食状态。
