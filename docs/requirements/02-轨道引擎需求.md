# 轨道引擎需求文档 (OrbitEngine)

> 版本: v1.0 | 日期: 2026-06-07 | 模块: OrbitEngine (L1 引擎层)

---

## 1. 模块目标

轨道引擎是 GalaxySim3D 的**核心物理计算引擎**，负责：
1. 计算任意时刻所有行星、卫星在日心黄道坐标系中的精确位置
2. 计算月球相对于地球的位置（受摄动影响）
3. 计算各天体的自转角度，确保贴图与 UTC 时间同步
4. 提供 NASA Horizons 校验方法，确保轨道精度

**核心价值**: 轨道引擎的输出是所有渲染和天象计算的基础。其精度决定了行星位置、月相、交食等关键功能的科学可信度。

## 2. 核心原理与算法

### 2.1 克卜勒轨道根数传播

行星轨道根数不是恒定的，会因行星间引力摄动而缓慢变化。项目中使用**一阶时间变率**模型：

```
L(t) = L₀ + dL × T
ϖ(t) = ϖ₀ + dϖ × T
Ω(t) = Ω₀ + dΩ × T
e(t) = e₀ + de × T
I(t) = I₀ + dI × T
```

其中 `T = days / 36525` 为自 J2000.0 起的儒略世纪数。

**为什么需要变率？**
- 若不考虑变率，500 年后的轨道位置误差可达数度
- NASA JPL 发布的轨道根数通常包含 3000 年内的线性变率项
- 本项目采用 Meeus《天文算法》表 30.A 的简化根数

### 2.2 克卜勒方程求解

给定平均近点角 M，求解偏近点角 E 的 Newton-Raphson 迭代：

```
f(E) = E - e·sin(E) - M = 0
f'(E) = 1 - e·cos(E)

Eₙ₊₁ = Eₙ - f(Eₙ)/f'(Eₙ)
  = Eₙ - (Eₙ - e·sin(Eₙ) - M) / (1 - e·cos(Eₙ))
```

**收敛性分析**：
- 初值取 E₀ = M 即可
- 偏心率 e < 0.25（除水星 0.206、冥王星 0.249）
- 5 次迭代后误差 < 1e-12 弧度，远超天文需求

### 2.3 轨道平面到黄道坐标的旋转

求解 E 后，先计算轨道平面内的坐标：
```
x_orbit = a·(cos(E) - e)
y_orbit = a·√(1-e²)·sin(E)
```

再通过三个欧拉角旋转到黄道坐标系：
1. 绕 Z 轴转 ω（近日点幅角）
2. 绕 X 轴转 I（轨道倾角）
3. 绕 Z 轴转 Ω（升交点黄经）

组合旋转矩阵：
```
X = x·(cosω·cosΩ - sinω·sinΩ·cosI) - y·(sinω·cosΩ + cosω·sinΩ·cosI)
Y = x·(cosω·sinΩ + sinω·cosΩ·cosI) - y·(sinω·sinΩ - cosω·cosΩ·cosI)
Z = x·sinω·sinI + y·cosω·sinI
```

### 2.4 月球位置计算

月球运动复杂，项目中采用分层精度策略：

#### 基础模型（简化二体开普勒）
- 半长轴 a = 0.00257 AU（固定）
- 偏心率 e = 0.0549（固定）
- 倾角 I = 5.145°（固定）
- 平均近点角 M = (135° + 13.176396°/天 × days) mod 360°
- 近地点黄经 ϖ 线性进动：0.1114°/天
- 升交点黄经 Ω 线性退行：-0.05295°/天

**精度**: ±2°~3°，对应时间误差 1~2 天。

#### Meeus 低精度模型（推荐）
在基础模型上增加主要周期摄动修正项：
```
Δλ = +1.27°·sin(2D - M_m)   // 出差 (Evection)
     +0.66°·sin(2D)          // 二均差 (Variation)
     +0.19°·sin(M_s)         // 周年差 (Annual Equation)
```
其中 D 为日月平距角，M_m 为月球平近点角，M_s 为太阳平近点角。

**精度**: ±0.5°，对应时间误差 ~1 小时，满足教育演示需求。

#### 高精度边界
如需更高精度，需引入 ELP-2000 分析历表（~1000 项）或 DE440 数值历表。

### 2.5 月球轨道可视化修正

月球轨道在空间中不断进动。若用真实轨迹点连接，轨道线首尾的间隙可达 3°（27 天内近地点进动）。

**正确做法**: 轨道可视化应使用**瞬时轨道根数**绘制闭合椭圆，而非真实轨迹。即固定某一时刻的根数，遍历真近点角 0~2π 绘制数学椭圆。

### 2.6 自转角度计算

**物理原理**: 天体自转角度 = 初始角度 + (经过的 UT1 时间 / 自转周期) × 2π

**地球的特殊性**: 地球自转必须使用恒星时而非太阳时，因为贴图上的经度是基于恒星的。

**贴图校准偏移**: Three.js 默认球体 UV 起点的物理方向与天文坐标系存在 -90°（-π/2）偏差，必须叠加校准偏移量：
```
rotationY = earthRotationAngle + baseOffset(-π/2) + userFineTune
```

### 2.7 NASA Horizons 校验 LUT

为修正简化轨道模型与真实历表的系统性偏差，项目预计算了 2018-2028 年每 10 天的位置偏差表（Look-Up Table）。

**使用方法**: 
1. 计算目标 JD 在 LUT 中的前后两个采样点
2. 线性插值得到 (dx, dy, dz) 偏差
3. 叠加到克卜勒轨道输出上

**覆盖范围**: 2018-2028 年，太阳系 9 大天体（含月球），每 10 天一个采样点。

## 4. 接口契约

```typescript
interface KeplerElements {
  id: string;
  a: number;       // 半长轴 AU
  e: number;       // 偏心率
  I: number;       // 倾角度
  L: number;       // 平均黄经 J2000
  longPeri: number; // 近日点黄经
  node: number;    // 升交点黄经
  period: number;  // 公转周期 天
  dL?: number;     // 平均黄经变率 deg/cy
  dLongPeri?: number;
  dNode?: number;
  dE?: number;
  dI?: number;
}

class OrbitEngine {
  /** 日心坐标 (AU) */
  static getHeliocentricPosition(id: string, days: number, useOffsets?: boolean): {x, y, z};

  /** 月地相对坐标 (AU) */
  static getLunarRelativePosition(days: number): {x, y, z};

  /** 原始月球模型（无 LUT 校准） */
  static getLunarRelativePositionRaw(days: number): {x, y, z};

  /** 自转角度 (弧度) */
  static getRotationAngle(id: string, timestamp: number): number;

  /** 月球轨道可视化点（闭合椭圆） */
  static getLunarOrbitPoints(days: number, samples: number): {x, y, z}[];

  /** NASA Horizons 校验 */
  static validateOrbitEngine(): {success: boolean; log: string};
}
```

## 7. 已知问题与边界

1. **月球精度边界**: 简化模型在月食时刻可能有 1~2 天偏差，已通过 LUT 和 Meeus 修正改善
2. **卫星模型简化**: 天然卫星使用圆形轨道近似，不考虑轨道倾角和偏心率
3. **小天体缺失**: 目前未包含小行星带、柯伊伯带、彗星等
4. **相对论效应**: 未考虑广义相对论对水星近日点进动的修正（43 角秒/世纪）
5. **LUT 有效期**: 校准表仅覆盖 2018-2028 年，超出范围后精度下降
