# GalaxySim3D 项目总需求文档

> 版本: v1.0 | 日期: 2026-06-07 | 项目: 梦入银河 (GalaxySim3D)

---

## 1. 项目定位与目标

### 1.1 产品定位

**梦入银河** 是一个面向 12-18 岁青少年群体的 **3D Web 宇宙知识教学系统**，核心定位是**兴趣指引与科学启蒙**。系统以严谨的天文物理计算为基石，以高保真三维渲染为载体，让用户能够直观探索太阳系、银河系乃至地面观星的完整宇宙体验。

### 1.2 核心目标

| 维度 | 目标描述 |
|------|----------|
| **科学性** | 所有星体位置基于 J2000.0 历元标准，使用真实克卜勒轨道根数计算；自转角度与 UTC 时间严格同步；坐标系与 NASA Horizons 对齐并通过校验 |
| **教育性** | 提供星体多层剖面展示、天文现象模拟（日食/月食/24节气）、地面星空观测，降低天文知识的学习门槛 |
| **沉浸感** | 双模式无缝切换（太空视角↔地面观星）、成熟光照系统、镜头光晕、无极缩放过渡、望远镜模式 |
| **可扩展性** | 引擎层与渲染层完全解耦，支持多人并行开发；核心模拟引擎独立单元测试验证 |
| **国际化** | 全系统 i18n，默认中文，支持英文切换 |

### 1.3 目标用户

12-18 岁对宇宙科学感兴趣的青少年，以及中小学天文科普教育场景。

## 2. 天文学核心知识背景

本节提供项目涉及的真实世界天文知识，是理解需求的前提。所有引擎计算必须以这些物理事实为准绳。

### 2.1 历元 J2000.0

**历元 (Epoch)** 是天文学中定义坐标系和轨道根数所对应的参考时刻。**J2000.0** 是国际天文学联合会 (IAU) 采用的标准历元，对应：

- **公历**: 2000年1月1日 12:00 TT (Terrestrial Time)
- **UTC**: 2000年1月1日 11:58:55.816 (因 TT 与 UTC 存在 ΔT 偏移)
- **儒略日**: JD 2451545.0
- **时间戳**: 946728000000 ms (Unix epoch)

**为什么需要历元？**
- 由于岁差、章动和自行，恒星的赤道坐标（赤经/赤纬）会随时间缓慢变化
- 行星的轨道根数（半长轴、偏心率等）也会因摄动而缓慢演化
- 必须指定一个共同参考时刻，才能比较和转换不同年代的天文观测数据

### 2.2 克卜勒轨道与轨道根数

**克卜勒定律** 描述了行星在太阳引力作用下的运动规律。在给定历元，每颗行星的轨道可用 6 个**轨道根数 (Orbital Elements)** 完全描述：

| 根数 | 符号 | 单位 | 物理意义 |
|------|------|------|----------|
| 半长轴 | a | AU | 轨道椭圆的大小，决定公转周期 |
| 偏心率 | e | 无量纲 | 轨道椭圆的扁平程度 (0=圆, <1=椭圆) |
| 轨道倾角 | I | 度 | 轨道面与黄道面的夹角 |
| 升交点黄经 | Ω | 度 | 轨道面与黄道面交线（升交点）的方向 |
| 近日点黄经 | ϖ | 度 | 近日点相对于升交点的方向 |
| 平均黄经 | L | 度 | 若轨道为圆，行星在历元时刻的位置 |

**克卜勒方程求解**：
给定平均近点角 M，需要通过迭代求解偏近点角 E：
```
E - e·sin(E) = M
```
通常使用 Newton-Raphson 迭代法，5 次迭代即可达到机器精度。

**真近点角与位置**：
```
cos(v) = (cos(E) - e) / (1 - e·cos(E))
r = a·(1 - e²) / (1 + e·cos(v))
```

### 2.3 坐标系统

项目涉及三种主要坐标系，必须严格区分：

#### 2.3.1 日心黄道坐标系 (Heliocentric Ecliptic)
- **原点**: 太阳中心
- **XY 平面**: 地球公转黄道面 (J2000.0 平黄道)
- **X 轴**: 指向春分点方向
- **单位**: 天文单位 AU (1 AU ≈ 149,597,870.7 km)
- **用途**: 轨道引擎内部计算，行星间相对位置

#### 2.3.2 天球赤道坐标系 (Equatorial / RA-Dec)
- **原点**: 地球中心（或观测者）
- **赤道面**: 地球赤道向外扩展的天球大圆
- **赤经 (RA, α)**: 沿赤道从春分点向东计量，单位 时角 (0~24h)
- **赤纬 (Dec, δ)**: 垂直于赤道，向北为正，向南为负，单位度 (-90°~+90°)
- **用途**: 星表记录、望远镜指向、天体编目

#### 2.3.3 地面水平坐标系 (Horizontal / Az-Alt)
- **原点**: 观测者位置
- **地平圈**: 以观测者为球心，地平线为天球大圆
- **方位角 (Azimuth)**: 从正北顺时针计量到天体垂直圈 (0°~360°)
- **高度角 (Altitude)**: 从地平面向天顶计量 (0°~90°)
- **用途**: 地面观星渲染、判断天体出没

**坐标转换链路**：
```
日心黄道 (x,y,z) ──► 地心赤道 (RA, Dec) ──► 水平坐标 (Az, Alt)
     │                    │                     │
  轨道引擎          黄赤转换矩阵            恒星时 + 地理坐标
```

### 2.4 时间系统

项目必须处理多种时间尺度：

| 时间尺度 | 英文 | 说明 |
|----------|------|------|
| 协调世界时 | UTC | 民用时间基准，含闰秒 |
| 世界时 UT1 | UT1 | 基于地球实际自转，用于恒星时计算 |
| 地球时 TT | TT | 均匀原子时，比 UTC 快 ΔT ≈ 64~70 秒 |
| 质心力学时 | TDB | 相对论性均匀时标，用于精密星历 |

**恒星时 vs 太阳时**：
- **太阳日**: 太阳连续两次上中天的时间 ≈ 24h
- **恒星日**: 遥远恒星连续两次上中天的时间 ≈ 23h 56m 4.1s
- 差异原因：地球在自转的同时还在公转，每天需要多转约 1° 才能重新对准太阳
- **格林尼治平恒星时 (GMST)** 公式：
  ```
  GMST = 18.697374558 + 24.06570982441908 × d  (小时)
  ```
  其中 d 为距 J2000.0 的 UT1 天数。

### 2.5 岁差与章动

**岁差 (Precession)**：
- 地球自转轴像陀螺一样缓慢摆动，周期约 25,800 年
- 导致春分点每年西退约 50.3 角秒
- 经过数百年，恒星的赤道坐标会发生显著变化
- 项目使用 IAU 2006 岁差模型，将 J2000.0 坐标转换到当前历元

**章动 (Nutation)**：
- 在岁差基础上叠加的微小周期性摆动（周期约 18.6 年）
- 主要由月球轨道面（白道面）的进动引起
- 对恒星位置的影响约 ±17 角秒（经度）和 ±9 角秒（倾角）
- 项目使用 IAU 1980 简化章动模型

### 2.6 月球运动

月球轨道是太阳系中最复杂的天体运动之一：

**基本参数**：
- 半长轴: 0.00257 AU (约 384,400 km)
- 偏心率: 0.0549（变化范围 0.043~0.067）
- 轨道倾角: 5.145°（相对黄道面）
- 恒星月: 27.32166 天（相对恒星转一圈）
- 朔望月: 29.53059 天（月相周期）

**主要摄动项**：
月球运动受太阳引力强烈扰动，主要摄动包括：

| 摄动名称 | 振幅 | 周期 | 物理来源 |
|----------|------|------|----------|
| 出差 (Evection) | ±1.27° | ~31.8 天 | 太阳引力使轨道长轴周期性摆动 |
| 二均差 (Variation) | ±0.66° | ~14.8 天 | 太阳引力导致的短周期距离变化 |
| 周年差 (Annual Equation) | ±0.19° | 1 年 | 地球轨道偏心率改变摄动强度 |
| 倾角章动 | ±0.0025° | 18.6 年 | 地球自转轴摆动 |

**教育场景精度要求**：
- 对于科普演示，月球位置精度达到 ±0.5°（约 1 小时时间误差）即可满足月食/月相演示需求
- 使用 Meeus《天文算法》低精度月球算法（约 20 项三角修正）即可达到此精度

### 2.7 太阳黄经与 24 节气

**24 节气** 是中国传统历法的核心，其本质是**太阳在黄道上的 24 个等分点**：

- 以春分点为 0°，每 15° 为一个节气
- 节气时刻 = 太阳黄经到达 0°, 15°, 30°, ... 345° 的时刻
- 本质上是**天文事件**，与农历（阴阳合历）不同

**计算公式**：
```
太阳黄经 λ☉ = (L_earth - 180°) mod 360°
当前节气 = floor(λ☉ / 15°)
```

### 2.8 月相与交食

**月相**：由日-地-月夹角决定：
- 新月 (朔): 夹角 0°，月球与太阳同向
- 上弦月: 夹角 90°
- 满月 (望): 夹角 180°
- 下弦月: 夹角 270°
- 朔望月周期: 29.53059 天

**日食**：月球运行到日地之间，遮挡太阳光
- 条件: 新月期间，月球位于黄道面附近（交点月）
- 类型: 全食、环食、偏食、混合食

**月食**：地球运行到日月之间，地球阴影遮挡月球
- 条件: 满月期间，月球位于黄道面附近
- 类型: 全食、偏食、半影食

### 2.9 恒星与星表

**视星等 (Apparent Magnitude)**：
- 古希腊天文学家喜帕恰斯将肉眼可见最暗星定为 6 等
- 最亮星为 1 等（后扩展为负值，如天狼星 -1.46，太阳 -26.7）
- 星等差 5 等 = 亮度比 100 倍
- 公式: `m₁ - m₂ = -2.5·log₁₀(F₁/F₂)`

**Hipparcos 星表**：
- 欧洲空间局 (ESA) 1997 年发布的精密星表
- 包含约 118,000 颗恒星的位置、视差、自行、视星等
- 项目中使用亮星子集（视星等 ≤ 6.5，约 8,785 颗）

**岁差对恒星的影响**：
恒星的赤道坐标（RA, Dec）会因岁差而变化。经过 t 年后的近似变化：
```
ΔRA ≈ (1.2812323 × sin(RA) × tan(Dec) + 0.0002199) × t  (角秒)
ΔDec ≈ 1.2812323 × cos(RA) × t  (角秒)
```
对于地面观星，必须将 J2000.0 星表坐标修正到当前历元。

### 2.10 行星物理参数

**自转与黄赤倾角**：
- 大多数行星自转方向与公转相同（逆时针，从北极看）
- 金星逆向自转（倾角 177°），天王星"横躺"自转（倾角 98°）
- 自转周期决定昼夜长度，黄赤倾角决定季节变化

**潮汐锁定**：
- 月球被地球潮汐锁定，自转周期 = 公转周期（27.3 天）
- 因此地球上始终只能看到月球的同一面

## 6. 关键约束与假设

### 6.1 科学约束

1. **坐标系统一**: 所有引擎内部计算必须使用 J2000.0 日心黄道坐标系
2. **时间基准**: 所有轨道计算基于 TT/TDB 时标，UT1 仅用于恒星时计算
3. **数据权威来源**: 轨道根数来自 NASA JPL Horizons，恒星数据来自 Hipparcos 星表
4. **月球精度边界**: 教育场景下，Meeus 低精度模型（±0.5°）是可接受的精度边界

### 6.2 技术约束

1. **引擎层零渲染依赖**: `engine/` 目录下任何文件不得引用 Three.js 或 DOM API
2. **单向数据流**: 数据只从 L0 → L1 → L2 → L3 → L4 流动，禁止反向依赖
3. **状态集中管理**: 所有可变状态集中在 `App.tsx`，通过 props 向下传递
4. **纯函数优先**: 引擎计算必须是纯函数（相同输入 → 相同输出），便于测试和缓存
