# 宇宙视角渲染需求文档 (UniverseViewer)

> 版本: v1.0 | 日期: 2026-06-08 | 模块: UniverseViewer (L2 渲染层)

---

## 1. 模块目标

宇宙视角渲染器是 GalaxySim3D 的**太空漫游渲染引擎**，负责：
1. 在 3D 场景中渲染太阳系全景：太阳、八大行星、月球、天然卫星
2. 渲染行星轨道线、卫星轨道线
3. 渲染银河背景星点、星座连线（宇宙视角下）
4. 实现太阳光照、行星明暗面、阴影、大气散射、日冕光晕
5. 支持视觉比例切换（真实比例 vs 对数压缩教学比例）
6. 实现行星球体剖面模式（内部结构展示）
7. 处理相机控制（轨道相机、跟随相机、自由漫游）

**核心价值**: 为用户提供沉浸式的 3D 太空探索体验，是项目最主要的视觉呈现方式。

## 2. 核心原理与渲染技术

### 2.1 Three.js 场景架构

**场景层级结构**：
```
Scene
├── Sun (Mesh + PointLight)
├── Planets
│   ├── Mercury Group
│   ├── Venus Group
│   ├── Earth Group (Earth Mesh + Clouds + Atmosphere)
│   ├── Mars Group (Mars + Phobos + Deimos)
│   ├── Jupiter Group (Jupiter + Io + Europa + Ganymede + Callisto + Ring)
│   ├── Saturn Group (Saturn + Titan + Rhea + Enceladus + Ring)
│   ├── Uranus Group (Uranus + Titania + Oberon + Ariel + Ring)
│   └── Neptune Group (Neptune + Triton + Proteus + Ring)
├── Moon Orbit Line
├── Planet Orbit Lines
├── Background Stars (Points)
├── Constellation Lines (LineSegments)
└── Milky Way (Sprite / Shader)
```

### 2.2 行星材质系统

**贴图类型**：
- **Diffuse Map (漫反射贴图)**: 行星表面颜色（8K/4K/2K 分辨率）
- **Normal Map (法线贴图)**: 表面凹凸细节
- **Specular Map (高光贴图)**: 水面/冰面的反射特性
- **Cloud Map (云层贴图)**: 地球等有大气的行星

**材质选择策略**：
- 近距离（LOD_CLOSE）: 使用高分辨率贴图 + 法线贴图
- 中距离（LOD_MID）: 使用中等分辨率贴图
- 远距离（LOD_FAR）: 使用低分辨率贴图或纯色

**地球多层渲染**：
1. **地表**: SphereGeometry + MeshStandardMaterial + 8K 贴图
2. **云层**: 稍大 SphereGeometry + 透明 MeshPhongMaterial + 云层贴图
3. **大气层**: 更大 SphereGeometry + 自定义 Shader（瑞利散射模拟）
4. **剖面模式**: 使用 clipping planes 切掉 1/8 球体，内部用同心球展示核/幔/壳

### 2.3 光照模型

**太阳点光源**：
- 类型: THREE.PointLight
- 颜色: #fff5e6（微微偏黄）
- 强度: 随距离衰减（物理正确或视觉优化）
- 阴影: 启用 castShadow，分辨率 512×512（移动端）或 2048×2048（桌面端）

**行星明暗面**：
- MeshStandardMaterial 的 roughness/metalness 参数控制反射特性
- 岩石行星: roughness 高，metalness 低
- 气态行星: roughness 低，metalness 中等

**日冕光晕 (LensFlare)**：
- 当相机直视太阳时激活
- 使用 Sprite + 径向渐变纹理
- 包含光斑 (ghost) 效果

### 2.4 轨道线渲染

**轨道线类型**：
- 行星轨道: 基于当前轨道根数的闭合椭圆，细线，半透明
- 月球轨道: 基于瞬时根数的闭合椭圆（注意：不是真实轨迹）
- 卫星轨道: 围绕 parent 的圆形轨道

**动态更新策略**：
- 轨道根数缓慢变化，不需要每帧更新
- 可设置更新频率: 每 30 帧或每 0.01 天模拟时间

### 2.5 视觉比例 (Visual Scale)

**真实比例的问题**：
- 若按真实 AU 渲染，内行星（水星、金星）在屏幕上只有几个像素
- 外行星（天王星、海王星）距离过远，无法同时看到所有行星

**对数压缩公式**（教学演示模式）：
```
renderDistance = 1.2 + log10(realAU - 0.2) × 1.5
```

**切换机制**：
- `useVisualScale = true`: 外行星轨道对数压缩，便于教学演示
- `useVisualScale = false`: 严格按 AU 展示，用于科学验证

| 指标 | 目标 |
|------|------|

## 6. 已知问题与边界

1. **双 WebGL 上下文**: 当前 UniverseViewer 和 StarrySkyViewer 各创建一个 WebGLRenderer，需合并为单一上下文
2. **阴影分辨率**: PointLight 阴影消耗大，在移动端可能需要禁用或降分辨率
3. **贴图加载**: 8K 贴图文件大（~20MB），需要 LOD 和异步加载策略
4. **远距离渲染**: 超过 1000 AU 时，浮点精度可能导致抖动
5. **土星环**: 使用 RingGeometry 或自定义 Shader，透明度混合需注意渲染顺序
6. **剖面 Z-Fighting**: 剖面平面与球体表面可能产生 Z-Fighting，需用 polygonOffset
