# 天文演示系统需求文档（总览）

> 版本: v4.0 | 日期: 2026-06-08 | 模块: PhenomenaDemo 系统总览

---

## 1. 模块定位

天文演示系统是 GalaxySim3D 的**教育内容编排与交互体验中枢**，将复杂天文现象拆解为可交互的分步演示，支持"宇宙原理视角"与"地面观测视角"双镜头教学。

---

## 2. 演示现象总览

| 现象 | 文档 | 步骤数 | 核心教学点 |
|------|------|--------|-----------|
| **月相变化** | [月相演示需求](08a-月相演示需求.md) | 8 步 | 日-地-月相对位置、朔望月、最佳观测时间 |
| **交食（日食+月食）** | [日食演示需求](08b-日食演示需求.md) + [月食演示需求](08c-月食演示需求.md) | 4 步 | 步骤 0~2：日食（太阳光束→月球影子锥→地球被笼罩）；步骤 3：月食（地球影子与血月） |
| **24 节气** | [24节气演示需求](08d-24节气演示需求.md) | 24 步 | 太阳黄经、昼夜长短、物候诗词 |

## 3. 公共架构需求

### 3.1 演示模式全局布局

```
┌─────────────────────────────────────────────────────────────┐
│  LEFT DRAWER                   MAIN VIEWPORT                │
│  ┌─────────────┐              ┌───────────────────────────┐ │
│  │ 现象卡片列表  │              │  Universe / StarrySky     │ │
│  └─────────────┘              └───────────────────────────┘ │
│                                                              │
│  RIGHT GUIDE PANEL          BOTTOM DEMO BAR                 │
│  ┌─────────────────┐      ┌─────────────────────────────┐ │
│  │ 现象标题 + 内容   │      │ ❌ ⏮ 🌑...🌘 ⏭ ▶ 慢 中 快 [原理][观测] │ │
│  │ Tab 内容 / 数据   │      └─────────────────────────────┘ │
│  │ 步骤点阵导航     │                                        │
│  └─────────────────┘                                        │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 公共组件清单

| 组件 | 文件 | 职责 |
|------|------|------|
| AstroPhenomenaPanel | `components/AstroPhenomenaPanel.tsx` | 左侧现象选择卡片列表 |
| PhenomenaDemoBar | `components/PhenomenaDemoBar.tsx` | 底部步骤导航 + 播放控制 + 视角切换 |
| PhenomenaGuidePanel | `components/PhenomenaGuidePanel.tsx` | 右侧引导面板（现象内容容器） |

### 3.3 公共交互规则

- **进入演示**：点击现象卡片 → 重置 `demoState` → 跳转到该现象的初始时间
- **步骤切换**：点击底部步骤点 / 上下箭头 / 自动播放 → 更新 `demoPhase` → 自动跳转时间
- **视角切换**：点击"原理"/"观测"按钮 → 触发 2.5 秒无极缩放过渡 → 切换 Viewer
- **退出演示**：点击 ❌ → 恢复普通探索模式 → 保留当前时间

### 3.4 公共状态定义

```typescript
interface PhenomenaDemoState {
  activePhenomenon: 'moon-phases' | 'eclipses' | 'retrograde' | 'solar-terms' | null;
  demoPhase: number;      // eclipses 现象下：0=太阳光束, 1=月球影子锥, 2=地球被笼罩, 3=月食/血月
  viewMode: 'universe' | 'starry';
  isPlaying: boolean;
  playbackSpeed: number; // 0.5 | 1 | 2
  showGuidePanel: boolean;
}
```

## 4. 非功能需求

| 指标 | 目标 |
|------|------|
| 步骤切换延迟 | < 500ms |
| 自动播放间隔 | 每步 8 秒（1x 倍速） |
| 时间轴拖拽响应 | 主视口同步更新，延迟 < 100ms |
| i18n 覆盖 | 所有现象名称、描述、诗词、习俗必须中英双语 |
