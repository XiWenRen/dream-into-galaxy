# 时间引擎需求文档 (TimeEngine)

> 版本: v1.0 | 日期: 2026-06-07 | 模块: TimeEngine (L1 引擎层)

---

## 1. 模块目标

时间引擎是 GalaxySim3D 的**时间基准中枢**，负责：
1. 管理模拟时间流：将真实世界时间戳与天文历元进行换算
2. 提供多种天文时间尺度（UTC、TT、TDB、UT1）的转换
3. 计算本地恒星时（Local Sidereal Time），为地面观星提供时角基准
4. 驱动时间递增逻辑，支持任意倍速的时间流逝

**核心价值**: 所有其他引擎（轨道、天象、观星）都依赖时间引擎提供的时间参数。时间引擎的精度直接影响整个系统的天文计算精度。

---

## 2. 核心原理与算法

### 2.1 历元与时间戳换算

**历元 J2000.0** 是天文计算的零点：
- UTC 时间戳: `946728000000` ms (2000-01-01T12:00:00Z)
- 儒略日: `2451545.0`

**换算公式**：
```
daysSinceJ2000 = (timestamp - J2000_TIMESTAMP) / 86400000
```
其中 86400000 = 24 × 60 × 60 × 1000，为一天的毫秒数。

### 2.2 时间尺度转换

真实世界的天文计算涉及多种时间尺度，必须正确区分：

#### UTC (协调世界时)
- 民用时间基准，由原子钟维持
- 不定期插入闰秒以与地球自转 (UT1) 保持同步
- 项目中作为用户输入和输出的时间表示

#### TT (地球时 / Terrestrial Time)
- 均匀原子时标，与地心坐标系绑定
- 与 UTC 的关系: `TT = UTC + ΔT`
- ΔT 在 2000 年约 64.3 秒，每年增加约 0.5 秒
- Meeus 简化公式（2000-2100 年适用）：
  ```
  ΔT ≈ 64.3 + 0.5 × (year - 2000)  (秒)
  ```
- 轨道计算、历元换算应使用 TT，以保证时间间隔的均匀性

#### TDB (质心力学时)
- 用于精密星历（如 VSOP87、DE 系列）的相对论性均匀时标
- 与 TT 的差异极小（最大约 2ms），由周期性相对论修正项决定
- 对于浏览器级精度，`TDB ≈ TT`

#### UT1 (世界时)
- 基于地球实际自转，包含地球自转速率不规则变化
- 与 UTC 的差异: `|UT1 - UTC| < 0.9 秒`（通过闰秒控制）
- 恒星时必须基于 UT1 计算，因为地球自转对应 UT1

### 2.3 格林尼治平恒星时 (GMST)

**物理意义**: GMST 表示格林尼治子午线相对于春分点的角度，反映地球的自转状态。

**计算公式**（基于 UT1）：
```
d = UT1 days since J2000.0
GMST = 18.697374558 + 24.06570982441908 × d  (小时)
```

**简化理解**: 地球每 UT1 天自转约 24.0657 小时（恒星时小时），而不是恰好 24 小时。这多出的 0.0657 小时（约 3m 56s）正是因为地球在自转的同时还在公转，每天需要多转一点才能重新对准太阳。

### 2.4 本地恒星时 (LST)

**物理意义**: 观测者所在经度的子午线相对于春分点的角度。

**计算公式**：
```
LST = GMST + longitude / 15  (小时)
```
经度每增加 15°，LST 增加 1 小时（因为地球自转 360°/24h = 15°/h）。

**用途**: 地面观星时将赤道坐标（RA, Dec）转换为水平坐标（Az, Alt）时，LST 是必需的中间参数：
```
时角 HA = LST - RA
```

## 3. 功能需求

### 3.1 基础时间换算

| 需求 ID | 功能 | 输入 | 输出 | 精度要求 |
|---------|------|------|------|----------|
| REQ-TE-001 | UTC → J2000 天数 | UTC 时间戳 (ms) | 距 J2000.0 的天数 (float) | ±1e-6 天 (~0.1秒) |
| REQ-TE-002 | ΔT 计算 | UTC 时间戳 | TT - UTC 差值 (秒) | ±5 秒（Meeus简化公式） |
| REQ-TE-003 | UTC → TT | UTC 时间戳 | TT 时间戳 (ms) | ±5 秒 |
| REQ-TE-004 | UTC → TDB | UTC 时间戳 | TDB 时间戳 (ms) | ±5 秒 |
| REQ-TE-005 | UTC → UT1 | UTC 时间戳 | UT1 时间戳 (ms) | ±1 秒 |
| REQ-TE-006 | TT/TDB → J2000 天数 | 时间戳 | TDB 天数 since J2000 | ±1e-6 天 |
| REQ-TE-007 | UT1 → J2000 天数 | 时间戳 | UT1 天数 since J2000 | ±1e-6 天 |

### 3.2 时间递增驱动

| 需求 ID | 功能 | 说明 |
|---------|------|------|
| REQ-TE-008 | tick 递增 | `nextTimestamp = current + speedMultiplier × deltaSeconds × 1000` |
| REQ-TE-009 | 倍速范围 | 支持 0x（暂停）到数百万倍速 |
| REQ-TE-010 | 高流速兼容 | 每帧时间戳可能大幅跳变，下游系统不得假设时间连续 |

### 3.3 恒星时计算

| 需求 ID | 功能 | 输入 | 输出 | 精度要求 |
|---------|------|------|------|----------|
| REQ-TE-011 | GMST 计算 | UTC 时间戳 | 格林尼治平恒星时 (0~24h) | ±0.1 秒 |
| REQ-TE-012 | LST 计算 | UTC 时间戳 + 经度(°) | 本地恒星时 (0~24h) | ±0.1 秒 |
| REQ-TE-013 | 非地球天体 LST | 天体 ID + 时间戳 + 经度 | 该天体上的本地恒星时 | ±0.1 秒 |

### 3.4 辅助时间工具

| 需求 ID | 功能 | 说明 |
|---------|------|------|
| REQ-TE-014 | 本地小时转换 | 将某一天的 UTC 时间戳转换为指定时区下特定小时的 UTC 时间戳 |
| REQ-TE-015 | 闰年/闰秒处理 | 依赖 JavaScript Date 的内置处理 |

## 4. 接口契约

```typescript
// 常量
const J2000_TIMESTAMP = 946728000000; // ms

class TimeEngine {
  /** UTC → J2000 天数 */
  static getDaysSinceJ2000(timestamp: number): number;

  /** ΔT = TT - UTC (秒) */
  static getDeltaT(timestamp: number): number;

  /** UTC → TT */
  static getTT(timestamp: number): number;

  /** UTC → TDB (≈ TT) */
  static getTDB(timestamp: number): number;

  /** UTC → UT1 */
  static getUT1(timestamp: number): number;

  /** TDB 天数 since J2000 */
  static getDaysSinceJ2000TDB(timestamp: number): number;

  /** UT1 天数 since J2000 */
  static getDaysSinceJ2000UT1(timestamp: number): number;

  /** 时间递增 */
  static tick(currentTimestamp: number, speedMultiplier: number, deltaTimeSeconds: number): number;

  /** 本地恒星时 (小时, 0~24) */
  static getLocalSiderealTime(timestamp: number, longitude: number): number;

  /** 指定时区本地小时 → UTC 时间戳 */
  static getTimestampForLocalHour(dateTimestamp: number, localHour: number, timezoneOffset: number): number;
}
```

## 5. 依赖关系

```
TimeEngine
 └── 依赖: 无 (L0 层级之上，但无外部模块依赖)
 └── 被依赖: OrbitEngine, AstrophenomenaEngine, ObserverEngine, UniverseViewer, StarrySkyViewer
```

**核心约束**: TimeEngine 是**最底层引擎之一**，不得依赖任何其他引擎或渲染层。

## 6. 验证要点

| 验证项 | 方法 | 预期结果 |
|--------|------|----------|
| J2000 历元点 | `getDaysSinceJ2000(946728000000)` | 返回 0 |
| 一天后 | `getDaysSinceJ2000(946728000000 + 86400000)` | 返回 1.0 |
| ΔT 2000年 | `getDeltaT(946728000000)` | ≈ 64.3 秒 |
| ΔT 2020年 | `getDeltaT(1577836800000)` | ≈ 74.3 秒 |
| GMST 已知时刻 | 对比已知天文年历 | 误差 < 0.01h |
| LST 经度影响 | 东经 15° vs 0° 同一时刻 | LST 差 = 1h |
| tick 1x | speed=1, delta=1s | 时间戳增加 1000ms |
| tick 86400x | speed=86400, delta=1s | 时间戳增加 1 天 |

---

## 7. 已知边界与限制

1. **ΔT 预测不确定性**: Meeus 线性外推在 2100 年后误差会增大，长期运行需更新 ΔT 模型
2. **UT1 ≈ UTC 近似**: 未接入 IERS 发布的 EOP（地球定向参数）数据，UT1 精度约 ±1 秒
3. **非地球天体 LST**: 基于匀速自转假设，不考虑自转轴进动（对短期模拟无影响）
4. **无闰秒表**: 依赖浏览器 Date 的闰秒处理，无法预知未来闰秒
