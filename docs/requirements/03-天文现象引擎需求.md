# 天文现象引擎需求文档 (AstrophenomenaEngine)

> 版本: v1.0 | 日期: 2026-06-07 | 模块: AstrophenomenaEngine (L1 引擎层)

---

## 1. 模块目标

天文现象引擎是 GalaxySim3D 的**天象计算与推演引擎**，负责：
1. 计算太阳黄经，进而确定 24 节气时刻
2. 计算月相（朔望月周期中的 8 个阶段）
3. 检测日食和月食的发生条件、类型、食分
4. 搜索给定时间窗口内的交食事件
5. 为天文现象演示提供时间跳转和相位定位支持

**核心价值**: 将抽象的轨道数据转化为用户可直观理解的天文现象（节气、月相、交食），是教育功能的核心支撑。

## 2. 核心原理与算法

### 2.1 太阳黄经计算

**太阳黄经 (Solar Longitude, λ☉)** 是太阳在黄道坐标系中的经度角度，以春分点为 0°，向东计量 0°~360°。

**计算方法**：
```
λ☉ = (L_earth - 180°) mod 360°
```
其中 L_earth 为地球的平均黄经（由 OrbitEngine 提供）。

**简化理解**: 从太阳看，地球在黄经 L_earth 方向；反过来，从地球看，太阳就在相反方向（L_earth - 180°）。

**精度**: 使用简化轨道模型的太阳黄经精度约 ±0.1°，对应节气时刻误差约 ±8 小时。这对于科普演示完全足够。

### 2.2 24 节气

**24 节气** 本质上是太阳黄经的 24 个等分点，每 15° 一个节气：

| 角度 | 节气 | 含义 |
|------|------|------|
| 0° | 春分 | 昼夜平分，太阳直射赤道 |
| 15° | 清明 | 天气晴朗，草木繁茂 |
| 30° | 谷雨 | 雨水增多，谷物生长 |
| 45° | 立夏 | 夏季开始 |
| 60° | 小满 | 麦类灌浆 |
| 75° | 芒种 | 麦类成熟，稻子播种 |
| 90° | 夏至 | 白昼最长，太阳直射北回归线 |
| 105° | 小暑 | 天气开始炎热 |
| 120° | 大暑 | 一年中最热 |
| 135° | 立秋 | 秋季开始 |
| 150° | 处暑 | 暑气结束 |
| 165° | 白露 | 天气转凉，露凝而白 |
| 180° | 秋分 | 昼夜再次平分 |
| 195° | 寒露 | 露水更凉 |
| 210° | 霜降 | 天气渐冷，初霜出现 |
| 225° | 立冬 | 冬季开始 |
| 240° | 小雪 | 开始降雪 |
| 255° | 大雪 | 降雪增多 |
| 270° | 冬至 | 白昼最短，太阳直射南回归线 |
| 285° | 小寒 | 气候开始寒冷 |
| 300° | 大寒 | 一年中最冷 |
| 315° | 立春 | 春季开始 |
| 330° | 雨水 | 降雨开始 |
| 345° | 惊蛰 | 春雷始鸣，蛰虫惊醒 |

**当前节气判定**：
```
当前节气索引 = floor(λ☉ / 15°)
下一节气角度 = (当前索引 + 1) × 15°
到下一节气的天数 ≈ (15° - λ☉%15°) / (360°/365.25°)
```

**注意**: 24 节气是**天文事件**，基于太阳黄经；而农历是**阴阳合历**，基于月相。两者概念不同，不可混用。

### 2.3 月相计算

**月相的本质**: 月相由日-地-月三者的相对位置决定。从地球看，月球被太阳照亮的部分所占比例取决于日地连线和月地连线之间的夹角（相位角）。

**相位角计算**：
```
cos(phaseAngle) = (r_moon² + r_earth-sun² - r_earth-moon²) / (2 × r_moon × r_earth-sun)
```
简化计算中，使用黄道面投影夹角即可。

**8 个月相阶段**：

| 相位索引 | 名称 | 相位角范围 | 天文术语 |
|----------|------|------------|----------|
| 0 | 新月 (朔) | 0° ± 7.5° | New Moon |
| 1 | 峨眉月 | 45° ± 22.5° | Waxing Crescent |
| 2 | 上弦月 | 90° ± 22.5° | First Quarter |
| 3 | 盈凸月 | 135° ± 22.5° | Waxing Gibbous |
| 4 | 满月 (望) | 180° ± 7.5° | Full Moon |
| 5 | 亏凸月 | 225° ± 22.5° | Waning Gibbous |
| 6 | 下弦月 | 270° ± 22.5° | Third Quarter |
| 7 | 残月 | 315° ± 22.5° | Waning Crescent |

**朔望月周期**: 29.53059 天。这是月相变化的周期，不同于恒星月（27.32166 天）。

**区分恒星月与朔望月**：
- **恒星月**: 月球相对遥远恒星转一圈的时间（27.3 天）
- **朔望月**: 月相从新月到下一个新月的时间（29.5 天）
- 差异原因: 地球在绕太阳公转，月球需要多转约 29° 才能重新对准日地连线

### 2.4 交食检测

#### 2.4.1 日食 (Solar Eclipse)

**发生条件**:
1. 必须在**朔**（新月）前后，月球位于日地之间
2. 月球必须位于黄道面附近（在交点前后约 18°）

**检测算法**：
```
1. 计算日-地-月夹角 angle
2. 计算日地距离 r_sun、月地距离 r_moon
3. 太阳视角半径: θ_sun = R_sun / r_sun
4. 月球视角半径: θ_moon = R_moon / r_moon
5. 若 angle < θ_moon - θ_sun: 环食 (Annular)
   若 angle < θ_sun - θ_moon: 全食 (Total)
   若 angle < θ_sun + θ_moon: 偏食 (Partial)
   否则: 无食
```

**交点月 (Draconic Month)**: 27.2122 天。月球连续两次经过同一交点的时间。日食必须发生在交点月的新月时刻。

#### 2.4.2 月食 (Lunar Eclipse)

**发生条件**:
1. 必须在**望**（满月）前后，地球位于日月之间
2. 月球必须位于黄道面附近（地球阴影锥范围内）

**检测算法**：
```
1. 计算地球阴影锥在月球距离处的半径 R_shadow
2. 计算地心看月球的角距离 angle
3. 若 angle < R_shadow - R_moon: 全食 (Total)
   若 angle < R_shadow + R_moon: 偏食 (Partial)
   若 angle < R_penumbra + R_moon: 半影食 (Penumbral)
   否则: 无食
```

**沙罗周期 (Saros Cycle)**: 约 18 年 11 天。经过一个沙罗周期后，日、地、月的相对几何关系几乎重复，因此相似的交食会再次发生在相近的日期。

### 2.5 月相精确时间定位

为了演示月相变化，需要能够精确找到特定月相发生的时间点：

**新月定位算法**：
1. 已知基准新月: 2000-01-06 18:14 UTC
2. 粗略估计: `base + n × 29.53059 天`
3. 迭代精化: 在估计值前后 ±5 天范围内，以递减步长搜索日地月夹角最小的时刻
4. 4 轮迭代后精度可达分钟级

**任意月相定位**: 在新月基准上叠加相位角偏移：
```
目标时间 ≈ baseNewMoon + (phaseIndex / 8) × 29.53059 天
```
再通过迭代精化到实际轨道位置。

## 4. 接口契约

```typescript
interface SolarTermInfo {
  index: number;
  nameKey: string;
  angle: number; // 太阳黄经角度
}

interface MoonPhaseInfo {
  phaseIndex: number; // 0~7
  nameKey: string;
  percent: number; // 照亮比例 0~1
}

interface EclipseStatus {
  solarEclipse: boolean;
  lunarEclipse: boolean;
  earthToSunDist: number;
  earthToMoonDist: number;
  angleDegrees: number;
}

interface EclipseEvent {
  timestamp: number;
  type: 'solar' | 'lunar';
  dateStr: string;
  detail?: SolarEclipseEvent | LunarEclipseEvent;
  magnitude?: number;
}

class AstrophenomenaEngine {
  /** 太阳黄经 0~360° */
  static getSolarLongitude(days: number): number;

  /** 当前节气 + 下一节气 */
  static getCurrentSolarTerm(days: number): {current: SolarTermInfo; next: SolarTermInfo; currentLong: number};

  /** 月相 0~7 */
  static getMoonPhase(days: number): MoonPhaseInfo;

  /** 交食检测 */
  static detectEclipse(days: number): EclipseStatus;

  /** 搜索交食事件 */
  static searchEclipseEvents(centerTimestamp: number, windowYears?: number): EclipseEvent[];

  /** 交食描述 */
  static getEclipseDescription(event: EclipseEvent, lang: 'zh' | 'en'): string;
}

// 辅助函数
function getCurrentCycleNewMoon(referenceTimestamp: number): number;
function getExactMoonPhaseTime(baseNewMoon: number, phaseIndex: number): number;
```

## 5. 数据来源

### 5.1 24 节气

节气定义基于太阳黄经，是纯粹的几何计算，无需外部数据。

### 5.2 交食事件

项目预置了 NASA 权威交食数据：
- **日食数据**: 覆盖 2015-2035 年的日全食、日环食、日偏食
- **月食数据**: 覆盖同一时期的月全食、月偏食
- 每条记录包含: 日期、食甚 UTC 时间、类型、食分、可见区域

**使用策略**: 
- 演示模式优先使用 NASA 真实数据
- 实时检测使用轨道计算进行快速估算
- 两者交叉验证

## 7. 已知问题与边界

1. **实时检测精度**: 基于简化轨道模型的实时检测仅能判断"是否可能发生交食"，无法精确预测食带和时刻
2. **极区交食**: 当前模型未考虑极区特殊几何（如午夜太阳背景下的日食）
3. **半影月食**: 半影食的视觉变化微弱，检测阈值需调试
4. **历法混淆**: 24 节气常被误认为农历概念，UI 需明确标注"天文节气"
5. **朔望月 vs 恒星月**: 科普文本必须严格区分 27.3 天和 29.5 天
