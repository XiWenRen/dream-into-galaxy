# 日食演示需求文档

> 版本: v2.0 | 日期: 2026-06-08 | 所属系统: 天文演示系统
>
> **定位说明**：在 GalaxySim3D 的演示架构中，日食与月食统一归属于 `eclipses` 现象（共 4 个演示步骤）。本文档负责阐述**步骤 0~2**（太阳光束 → 月球影子锥 → 地球被笼罩）的教学目标与功能需求。步骤 3（月食/血月）见[月食演示需求](08c-月食演示需求.md)。

---

## 1. 目标

### 1.1 教学目标

让用户通过分步演示理解：

1. **日食的本质**：在新月（朔）时，月球运行到日地之间，其影子锥投射到地球表面，遮挡了部分区域的太阳光。
2. **本影（Umbra）与半影（Penumbra）的物理区别**：
   - **本影**：太阳光被月球完全遮挡的区域，此处可看到**日全食**或**日环食**。
   - **半影**：太阳光被月球部分遮挡的区域，此处只能看到**日偏食**。
   - **伪本影（Antumbra）**：当本影锥顶点未到达地球表面时，在顶点延长线处形成的区域，此处看到**日环食**。
3. **日食的类型及其几何判定条件**：
   - **日全食（Total）**：本影锥顶点到达地球表面，且月球视半径大于太阳视半径（地月距离较近时）。
   - **日环食（Annular）**：本影锥顶点未到达地球表面，月球视半径小于太阳视半径（地月距离较远时）。
   - **日偏食（Partial）**：观测者位于半影区内，或地月日三者未完全对准时。
   - **全环食（Hybrid）**：同一次日食中，由于地球曲率，部分地区看到全食，部分地区看到环食。
4. **为什么不是每个月都有日食**：
   - 白道（月球轨道面）与黄道（地球公转面）存在约 **5.14°** 的倾角。
   - 只有当月球运行到**黄白交点（Node）**附近，且同时处于**朔（新月）**时，才可能发生日食。
   - 每年通常只有 **2~5** 次日食，且同一地点看到全食的平均间隔约为 **360~410 年**。
5. **通过真实 NASA/GSFC 权威数据感受日食的科学记录**：数据覆盖 2020–2030 年共 22 次日食事件，包含沙罗周期编号、中心食带路径、最大食发生地经纬度等字段。

### 1.2 功能目标

- 在统一交食演示框架下，实现步骤 0~2 的三维可视化教学。
- 集成 NASA 真实日食数据（`SOLAR_ECLIPSE_EVENTS`），支持下拉选择具体事件，并自动跳转到食甚时刻。
- 提供时间轴滑块，让用户手动控制日食进程（初亏 → 食甚 → 复圆），滑块范围使用 `AstrophenomenaEngine.getEclipseWindow()` 动态计算。
- 实时显示日食几何指标：白道黄道倾斜黄纬、地月日对齐偏差角、当前交食状态文本。
- 支持**严格物理模式**与**演示放大模式**两种尺度切换，便于在真实比例与教学可见性之间取舍。

## 2. 选型（选型原因）

### 2.1 将日食作为统一 `eclipses` 现象的前 3 个步骤

**原因**：
- 日食与月食在物理上互为对偶现象（月球遮太阳 vs 地球遮太阳），共享同一套交食检测引擎（`AstrophenomenaEngine.detectEclipse`）和几何指标仪表板。
- 统一后可以减少重复代码（交事件选择器、时间轴滑块、几何指标面板均为共用组件）。
- 教育叙事上，先理解“月球影子投射到地球”（日食），再理解“地球影子投射到月球”（月食），逻辑递进自然。

### 2.2 3 步原理演示模型（步骤 0~2）

| 步骤 | 图标 | 名称 | 教学内容 |
|------|------|------|----------|
| 0 | ☀️ | 太阳光束 | 建立日常光照 baseline，展示太阳向地球与月球发射光线的常态 |
| 1 | 🌑 | 月球影子锥 | 核心原理——月球遮挡太阳，形成本影锥与半影锥；解释全食/环食的几何差异 |
| 2 | 🌍 | 地球被笼罩 | 地球表面的本影带从西向东扫过；展示中心食带路径与观测地域差异 |

**原因**：日食涉及复杂的三维几何与尺度问题（地月距离约为地日距离的 1/390，月球直径约为太阳的 1/400）。直接展示全尺度宇宙视角下，影子锥几乎不可见。通过分步骤拆解，配合系统尺度切换按钮，让用户先建立概念，再观察真实比例。

### 2.3 NASA 真实日食数据驱动

**原因**：
- 精确日食预测需要贝塞尔根数（Besselian Elements）和复杂的地球椭球/天平动修正，代码量过大，不适合教育项目。
- 使用 NASA/GSFC Fred Espenak 的权威数据（`https://eclipse.gsfc.nasa.gov/`）具有科学可信度，且数据量可控（2020–2030 年 22 次日食事件）。
- 每条记录包含：`date`, `type`, `greatestUTC`, `magnitude`, `centralDuration`, `region`, `centralPath`, `sarosSeries`, `maxLat`, `maxLon`，足以支撑教育场景的日期跳转、类型标注、可见区域描述。

### 2.4 时间轴滑块 + 几何指标仪表 + 严格/演示双模式

**原因**：
- 日食是一个持续数小时的动态过程（全食阶段仅数分钟，但偏食阶段前后可达 2~3 小时）。滑块让用户自由探索任意阶段。
- 几何指标将抽象的轨道力学转化为直观的数字和弧形表盘，帮助用户理解“为什么不是每次新月都发生日食”。
- 严格物理模式（`strictPhysicsRef.current = true`）下，影子锥长度、截面半径按真实公式 `computeShadowCone(R☉, R⊕, d)` 计算；演示模式下适当放大角度和锥体，确保在屏幕上有足够的像素可见性。

## 3. 核心天文原理（需求文档必须包含的真实世界知识）

### 3.1 影子锥的几何学

日食的本质是**光沿直线传播**与**天体遮挡**的结合。当月球位于太阳和地球之间时，月球会在背日方向投下两个同轴锥形阴影：

1. **本影锥（Umbra）**：太阳光被月球完全遮挡的区域。本影锥的半顶角 `θ_u` 满足：
   ```
   sin(θ_u) = (R☉ − R月) / d☉月
   ```
   其中 `R☉ ≈ 696,340 km`，`R月 ≈ 1,737.4 km`，`d☉月` 为日月中心距离。

   本影锥长度 `L_u`：
   ```
   L_u = R月 / sin(|θ_u|) = R月 · d☉月 / (R☉ − R月)
   ```
   在典型的日地距离（1 AU ≈ 149,597,870.7 km）下，`L_u ≈ 373,000 km`，略大于地月平均距离（384,400 km）。这意味着：
   - 当地月距离**小于** `L_u` 时，本影锥顶点到达地球表面，产生**日全食**。
   - 当地月距离**大于** `L_u` 时，本影锥顶点未到达地球，地球表面经过的是**伪本影**，产生**日环食**。

2. **半影锥（Penumbra）**：太阳光被月球部分遮挡的区域。半影锥半顶角 `θ_p` 满足：
   ```
   sin(θ_p) = (R☉ + R月) / d☉月
   ```
   半影锥是**发散**的（因为 `R☉ + R月 > d☉月 · sin(any)` 在物理上不收敛），所以在地球表面形成的半影区远大于本影区。

3. **视直径与食分**：
   - 太阳视直径约 `0.53°`（32′），月球视直径在 `0.49° ~ 0.55°` 之间变化（因月球轨道偏心率）。
   - **食分（Magnitude）** = （月球视半径 + 太阳视半径 − 中心距）/（2 × 太阳视半径）。
   - 食分 `≥ 1.0` 时，月球完全覆盖太阳盘面，对应全食或环食（取决于地月距离）。

### 3.2 黄白交点与交食季节

- 白道面与黄道面的交线称为**交点线**，两个交点为**升交点（Ascending Node）**和**降交点（Descending Node）**。
- 由于太阳引力摄动，交点线以约 **18.6 年** 为周期向西退行（章动），每年交点位置变化约 `19.4°`。
- 只有当朔望月发生在**交点附近约 ±11°~15°** 的范围内时，地月日三者才足够共线以产生交食。这个有效窗口称为**交食季节（Eclipse Season）**，每年通常有 **2 个**交食季节，每个季节约 **34~37 天**。
- 因此，每年最多可有 **7 次**交食（日+月混合），最少 **2 次**。

### 3.3 沙罗周期（Saros）

- **沙罗周期** ≈ **18 年 11 天 8 小时**，是日食/月食的重要周期。
- 在一个沙罗周期内，地球、月球和太阳的相对几何关系几乎重复，因此发生的日食/月食类型相似。
- 由于多余的 8 小时，地球自转了约 1/3 圈，所以同一沙罗序列中的每次日食在地球上的可见区域会向西偏移约 `120°` 经度。
- 一个沙罗序列通常包含 **70~85 次**日食，持续约 **1,260~1,550 年**。
- 项目数据中的 `sarosSeries` 字段即来源于此，例如 2024-04-08 日全食属于沙罗序列 **139**。

### 3.4 日全食的特殊光学现象（教育扩展）

虽然当前版本以几何原理演示为主，但需求文档应预留对这些真实现象的描述接口：
- **贝利珠（Baily's Beads）**：食既前/生光后，月球崎岖边缘的最后一缕/第一缕阳光穿过月面环形山形成的珍珠状光点。
- **钻石环（Diamond Ring）**：贝利珠消失前/出现后，仅剩最后一道强光与周围日冕形成钻石戒指般的视觉效果。
- **日冕（Corona）**：日全食期间，太阳外层大气（温度约 1–3 百万开尔文）发出的微弱白光，仅在全食阶段肉眼可见。

## 4. 实现步骤

### Step 1: 日食数据结构与事件管理

**文件**: `src/data/eclipseEvents.ts`

```typescript
export interface SolarEclipseEvent {
  date: string;              // "YYYY-MM-DD"
  type: 'total' | 'annular' | 'hybrid' | 'partial';
  greatestUTC: string;       // "HH:MM:SS" 食甚时刻 UTC
  magnitude: number;         // 食分: >=1.0 为全食/环食, <1.0 为偏食
  centralDuration: string | null; // 中心食持续时间, null 表示偏食
  region: string;            // 可见区域描述
  centralPath: string | null;// 中心食带路径, null 表示偏食
  sarosSeries: number;       // 沙罗周期序列号
  maxLat: number;            // 最大食发生地纬度（大致）
  maxLon: number;            // 最大食发生地经度（大致）
}
```

**数据量**：2020–2030 年共 22 次日食事件，其中全食 6 次、环食 7 次、偏食 7 次、全环食 2 次。

### Step 3: App.tsx 中日食步骤的时间跳转逻辑

**文件**: `src/App.tsx`

```typescript
} else if (phenomenon === 'eclipses') {
  // phase 0: 太阳光束 (用最近的日食日期)
  // phase 1: 月球影子锥 (用最近的日全食/环食日期)
  // phase 2: 地球被笼罩 (用最近的日全食日期)
  // phase 3: 月食/血月 (用最近的月全食日期) → 见月食文档
  const now = Date.now();
  let targetTs = now;
  if (phase === 0) {
    const nextSolar = SOLAR_ECLIPSE_EVENTS.find(e => new Date(e.date).getTime() > now);
    targetTs = nextSolar ? new Date(nextSolar.date).getTime() : new Date(SOLAR_ECLIPSE_EVENTS[0].date).getTime();
  } else if (phase === 1 || phase === 2) {
    const centerEclipses = SOLAR_ECLIPSE_EVENTS.filter(e => e.type === 'total' || e.type === 'annular' || e.type === 'hybrid');
    const nextCenter = centerEclipses.find(e => new Date(e.date).getTime() > now);
    targetTs = nextCenter ? new Date(nextCenter.date).getTime() : new Date(centerEclipses[0].date).getTime();
  }
  setTimeState(prev => ({ ...prev, currentTimestamp: targetTs }));
}
```

### Step 5: 时间轴滑块与交食窗口

### Step 7: 主视口分步骤渲染（日食部分）

**步骤 0（太阳光束）**：
- 宇宙视角：从地球外侧观察太阳照射地球与月球的日常状态。
- 白道面、黄白交线、升交点/降交点标记球可见（`moonOrbitPlane`, `moonNodesLine`, `ascendingNodeMarker`, `descendingNodeMarker`）。

**步骤 1（月球影子锥）**：
- 宇宙视角：精确展示月球本影锥（`moonUmbraCone`）。
- 锥体方向：背日方向（`moonPos.clone().normalize()`）。
- 锥体长度：严格模式下 `earthToMoonDist * 0.98`，演示模式下 `earthToMoonDist * 1.02`。
- 底部半径：`moonRadiusScene * 1.1`。
- 半影锥（`moonPenumbraCone`）在演示中默认隐藏，因为发散半影锥在 3D 场景中视觉干扰大且难以与宇宙背景区分。
- 相机预设：从黄道面上方俯视日-月-地连线。

**步骤 2（地球被笼罩）**：
- 宇宙视角：地球表面有一个移动的黑色圆形阴影（本影带）。
- 阴影从西向东移动（与月球公转方向一致，也与地球自转方向一致）。
- 对齐指示线（`eclipseAlignmentLine`）连接地月中心，对准时高亮变红。
- 影轴线（`umbraAxisLine`）标示影子锥的中心轴。

### Step 8: 星空模式（地面观测视角）下的日食呈现

当用户点击底部 "🌍 观测" 按钮切换至 `starry` 模式时，系统从宇宙原理视角切换为地面观测者视角，呈现以下关键视觉效果：

**天空背景剧变**：
- 日全食期间，即使原本为白天，天空背景色也会强制变为极深蓝黑色（`#02030d`），模拟“白昼如夜”的真实观测体验。
- 渲染器通过 `renderer.setClearColor(new THREE.Color(0x02030d), 1.0)` 实现，仅在 `eclipseState.solarEclipse && sunCoords.alt > 0` 时触发。

**太阳盘面与日冕**：
- 正常情况下，太阳盘面使用亮白色（`#fffef5`），并叠加程序化日冕精灵（`sunCoronaSpriteRef`），日冕透明度随太阳高度角变化。
- **日全食发生时**：太阳盘面颜色突变为极暗灰色（`#0c0c0c`），模拟月球完全遮挡太阳盘面；同时日冕精灵透明度升至 `1.0`，尺寸放大至 `85.0`（平时为 `68.0`），颜色变为暖白色（`#fffaea`），呈现全食阶段肉眼可见的日冕光芒。
- **日偏食发生时**：太阳盘面逐渐变暗（通过 `sunMat.color` 插值），但不会像全食那样完全变黑。

**望远镜模式特殊处理**：
- 当用户开启望远镜放大模式时，日冕精灵自动隐藏（`visible = false`），防止大面积光晕遮挡太阳盘面表面细节，避免过曝。

**月球表现**：
- 日食期间，星空模式下的月球变为极暗（`#111111`），月晕（`moonHazeSpriteRef`）隐藏，因为此时月球处于新月阶段，几乎不可见。

### 6.2 天文精度

| 指标 | 允许偏差 | 验证方法 |
|------|----------|----------|
| 日食日期 | 使用 NASA 数据，无偏差 | 与 `eclipse.gsfc.nasa.gov` 交叉比对 |
| 食甚时刻 | 使用 NASA 数据，无偏差 | 与 `eclipse.gsfc.nasa.gov` 交叉比对 |
| 食分 | 使用 NASA 数据，无偏差 | 与 `eclipse.gsfc.nasa.gov` 交叉比对 |
| 实时检测（简化模型） | 仅判断 "是否可能发生"，类型判定（全/环/偏）不保证 | 使用 `detectEclipse()` 的 `0.55°` 阈值作为定性判断 |
| 本影锥半顶角 | 与理论值偏差 ≤ 5% | 对比 `computeShadowCone(696340, 1737.4, d☉月)` 的理论输出 |
| 影子锥方向 | 背日方向误差 ≤ 1° | 验证 `shadowDir = moonPos.normalize()` 与真实地月连线夹角 |
