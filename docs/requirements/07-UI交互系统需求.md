# UI 交互系统需求文档

> 版本: v1.0 | 日期: 2026-06-08 | 模块: App.tsx / 各 Panel 组件 (L3/L4 层)

---

## 1. 模块目标

UI 交互系统是 GalaxySim3D 的**用户界面与控制中心**，负责：
1. 管理全局应用状态（时间、选中行星、模式切换、主题等）
2. 渲染驾驶舱风格的控制面板和信息面板
3. 处理用户输入（点击、拖拽、滚轮、键盘快捷键）
4. 实现国际化（i18n）和主题切换
5. 协调各渲染器和引擎模块之间的数据流

**核心价值**: UI 是用户与复杂天文系统的交互接口。良好的 UI 设计能显著降低天文知识的学习门槛。

---

## 2. 核心设计原则

### 2.1 状态集中管理

所有可变状态集中在 `App.tsx`，通过 props 向下传递：
```
App.tsx (状态中心)
├── timeState: { currentTimestamp, speedMultiplier, isPaused }
├── selectedPlanetId
├── landed (宇宙视角/地面观星)
├── latitude, longitude (观测者坐标)
├── theme, lang
└── ...
```

**禁止**: 子组件维护与父组件重复的同步状态。

### 2.2 单向数据流

```
用户交互 → App.tsx 更新状态 → 重新渲染 → 引擎计算 → 视觉更新
```

引擎层不得反向修改 UI 状态。

### 2.3 响应式设计

- 桌面端: 侧边面板 + 底部控制条
- 平板端: 可折叠面板 + 触屏手势
- 最低分辨率支持: 1280×720

## 4. 国际化需求

### 4.1 翻译覆盖范围

所有用户可见文本必须支持双语：
- 行星名称和描述
- UI 按钮和标签
- 节气名称
- 月相名称
- 星座名称
- 交食类型
- 错误提示和信息提示

### 4.2 翻译键命名规范

```
planet_earth        // 行星名称
term_chunfen        // 节气
phase_waxing_crescent // 月相
eclipse_total       // 交食类型
```

## 5. 主题系统

### 5.1 四套主题

| 主题 ID | 名称 | 主色调 | 风格描述 |
|---------|------|--------|----------|
| space-tech | 太空科技 | 蓝青 (#00d4ff) | 科幻 HUD 风格，简洁线条 |
| cosmic-dark | 宇宙深空 | 紫蓝 (#8b5cf6) | 深邃星空感，渐变背景 |
| neon-hologram | 霓虹全息 | 粉紫 (#ec4899) | 高对比霓虹，未来感 |
| solar-gold | 太阳金辉 | 金橙 (#f59e0b) | 温暖色调，教育友好 |

### 5.2 主题变量

每个主题定义以下 CSS 变量：
- `--primary`: 主色调
- `--background`: 背景色
- `--surface`: 面板背景色
- `--text`: 主文字色
- `--text-secondary`: 次要文字色
- `--accent`: 强调色
- `--border`: 边框色

## 7. 已知问题与边界

1. **状态管理复杂度**: App.tsx 状态过多，未来可能需要引入状态管理库（Zustand/Redux）
2. **动画性能**: Framer Motion 动画在高流速下可能产生额外开销
3. **移动端适配**: 当前设计以桌面端为主，移动端面板布局需优化
4. **日期选择器**: 原生 date picker 样式与主题系统不一致
5. **键盘快捷键**: 尚未实现全面的键盘快捷键支持
