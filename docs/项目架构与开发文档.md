## 1. 背景与系统目标

### 1.1 项目背景

GalaxySim3D 是一个面向青少年群体的**3D Web 宇宙知识教学系统**，核心定位是**兴趣指引与科学启蒙**。系统以严谨的天文物理计算为基石，以高保真三维渲染为载体，让用户能够直观探索太阳系、银河系乃至地面观星的完整宇宙体验。

参考标杆: [NASA Eyes on the Solar System](https://eyes.nasa.gov/apps/solar-system/)

### 1.2 核心目标

| 维度 | 目标描述 |
|------|----------|
| **科学性** | 所有星体位置基于 J2000.0 历元标准，使用真实克卜勒轨道根数计算；自转角度与 UTC 时间严格同步；坐标系与 NASA Horizons 对齐并通过校验 |
| **教育性** | 提供星体多层剖面展示、天文现象模拟（日食/月食/24节气）、地面星空观测，降低天文知识的学习门槛 |
| **沉浸感** | 双模式无缝切换（太空视角↔地面观星）、成熟光照系统、镜头光晕、无极缩放过渡、望远镜模式 |
| **可扩展性** | 引擎层与渲染层完全解耦，支持多人并行开发；核心模拟引擎独立单元测试验证 |
| **国际化** | 全系统 i18n，默认中文，支持英文切换 |

### 1.3 目标用户

12-18 岁对宇宙科学感兴趣的青少年，以及中小学天文科普教育场景。

## 3. 专有名词对齐表

> **本表为项目内强制使用的标准术语**。所有代码变量名、函数名、文档、口头沟通必须遵循，以避免歧义。

### 3.1 核心引擎层名词

| 中文名称 | 英文名称 | 代码标识 | 职责定义 |
|----------|----------|----------|----------|
| **时间引擎** | Time Engine | `TimeEngine` | 管理模拟时间流：UTC 时间戳 ↔ J2000 历元天数换算、恒星时计算、Tick 递增 |
| **轨道引擎** | Orbit Engine | `OrbitEngine` | 计算星体在 3D 空间中的日心坐标：克卜勒方程求解、轨道根数传播、月球相对位置、自转角度 |
| **天文现象引擎** | Astrophenomena Engine | `AstrophenomenaEngine` | 基于轨道引擎输出计算衍生天象：太阳黄经、24节气、月相、日食/月食检测 |
| **星表数据库** | Star Database | `StarDatabase` | 存储恒星数据（赤经/赤纬/星等/颜色）、星座连线关系、背景星生成算法 |

### 3.2 渲染引擎层名词

| 中文名称 | 英文名称 | 代码标识 | 职责定义 |
|----------|----------|----------|----------|
| **宇宙视角** | Universe View / Space View | `UniverseViewer` | 3D 太空漫游模式：太阳系全景、行星轨道、卫星系统、银河背景 |
| **地面观星** | Landed View / Sky View | `StarrySkyViewer` | 地面天顶模式：以观察者为球心的天球投影、日月位置、星图、星座连线 |
| **无极缩放** | Stepless Transition | `SteplessTransition` | 宇宙视角与地面观星之间的无缝视觉过渡动画（非瞬间切换） |
| **望远镜模式** | Telescope Mode | `TelescopeOverlay` | 地面观星下的 FOV 可调视场限制器，模拟不同倍数光学设备 |
| **剖面模式** | Cross-Section Mode | `crossSectionActive` | 将行星球体切开展示内部圈层结构（核/幔/壳/大气层） |

### 3.3 UI 与交互层名词

| 中文名称 | 英文名称 | 代码标识 | 职责定义 |
|----------|----------|----------|----------|
| **驾驶舱 UI** | Cockpit UI / HUD | `CelestialControls` | 底部悬浮控制台：时间流速控制、日期显示、节气信息、预设跳转 |
| **星体面板上** | Planet Info Panel | `PlanetInfoPanel` | 右侧可折叠抽屉：显示当前选中星体的物理参数、简介、剖面开关 |
| **视觉比例优化** | Visual Scale Optimize | `useVisualScale` | 轨道距离的非线性压缩开关（外行星对数缩放，方便同时观测） |
| **真实比例** | Real Scale | `useVisualScale = false` | 严格按天文单位 AU 展示轨道，不做任何视觉压缩 |

### 3.4 天文专业术语

| 中文名称 | 英文名称 | 说明 |
|----------|----------|------|
| **历元 J2000.0** | J2000.0 Epoch | 标准参考时刻：2000-01-01T12:00:00 TT |
| **日心坐标** | Heliocentric Position | 以太阳为原点的 3D 笛卡尔坐标，单位 AU |
| **黄道坐标系** | Ecliptic Coordinate System | 以地球公转平面为基准的坐标系 |
| **恒星时** | Sidereal Time | 以遥远恒星为参考的地球自转角度计量 |
| **太阳黄经** | Solar Longitude | 太阳在黄道坐标系中的经度角度，节气计算的基础 |
| **视星等** | Apparent Magnitude | 从地球观测到的恒星亮度，数值越小越亮 |
| **赤经/赤纬** | Right Ascension / Declination | 天球赤道坐标系中的经度（时角）和纬度（角度） |
| **方位角/高度角** | Azimuth / Altitude | 地面水平坐标系：方位角（北为0°顺时针）和高度角（地平为0°，天顶90°） |
| **月相** | Moon Phase | 由日-地-月夹角决定：新月/上弦/满月/下弦等8个阶段 |
| **交食** | Eclipse | 日食（月球遮挡太阳）和月食（地球阴影遮挡月球） |

### 3.5 禁用或不推荐术语

| 不推荐说法 | 原因 | 应使用 |
|------------|------|--------|
| "登录星球" | 歧义（login?） | **地面观星** / **进入星球视角** |
| "天空模式" | 模糊 | **地面观星** / **Landed View** |
| "太空模式" | 模糊 | **宇宙视角** / **Universe View** |
| "普通模式" | 无信息量 | **完整模式** / **剖面模式关闭** |
| "节气"（单独使用） | 可能指农历节气而非天文节气 | **24节气** / **Solar Terms** |

### 4.3 模块依赖规则

> **核心约束：只允许上层依赖下层，禁止同层横向依赖，禁止下层依赖上层。**

```
L4 应用层
 └── 依赖: L3, L2, L1, L0

L3 UI 层
 └── 依赖: L1 (读取引擎计算结果)
 └── 禁止: 直接调用 L2 渲染器内部方法

L2 渲染层
 └── 依赖: L1 (获取坐标/角度数据)
 └── 依赖: L0 (获取贴图/星表)
 └── 禁止: 直接修改 L1 引擎状态

L1 引擎层
 └── 依赖: L0 (读取常量数据)
 └── 禁止: 依赖任何 L2/L3/L4
 └── 要求: 每个引擎独立单元测试

L0 数据层
 └── 禁止: 依赖任何上层模块
 └── 要求: 纯数据常量，无副作用
```

## 5. 核心引擎接口契约

### 5.1 TimeEngine

```typescript
// J2000.0 历元时间戳 (2000-01-01T12:00:00Z)
const J2000_TIMESTAMP = 946728000000;

class TimeEngine {
  // UTC 时间戳 → 距 J2000.0 天数
  static getDaysSinceJ2000(timestamp: number): number;

  // 时间推进: 当前时间 + 倍速 × 真实流逝秒数
  static tick(currentTimestamp: number, speedMultiplier: number, deltaTimeSeconds: number): number;

  // 本地恒星时 (用于地面观星的时角计算)
  static getLocalSiderealTime(timestamp: number, longitude: number): number; // 返回 0~24 小时
}
```

### 5.2 OrbitEngine

## 6. 关键设计决策

### 6.1 为什么轨道引擎和渲染引擎必须解耦？

1. **科学可验证性**: 轨道计算是纯数学问题，不依赖 Three.js 或 DOM，可以用确定性单元测试验证
2. **并行开发**: A 组维护轨道精度，B 组维护视觉效果，互不阻塞
3. **多端复用**: 同样的引擎可驱动 WebGL 渲染器、2D Canvas 渲染器、甚至后端 API
4. **时间穿越**: 引擎只需输入时间戳即可输出任意历史/未来时刻的星体位置

### 6.2 视觉比例 (useVisualScale)  vs 真实比例

| 模式 | 用途 | 实现 |
|------|------|------|
| 视觉比例 (`true`) | 教学演示，同时看到所有行星 | 外行星轨道对数压缩: `renderA = 1.2 + log10(a - 0.2) * 1.5` |
| 真实比例 (`false`) | 科学验证，感受真实距离 | 严格使用半长轴 `a` (AU)，不做任何压缩 |

### 6.3 坐标系约定

所有引擎统一使用 **J2000.0 黄道坐标系**:
- 原点: 太阳中心
- X-Y 平面: 地球公转黄道面
- X 轴: 指向春分点方向
- 单位: 天文单位 AU (约 1.496 亿公里)

地面观星渲染器内部转换为 **水平坐标系** (Azimuth-Altitude):
- 由赤经/赤纬 + 观察者地理坐标 + 恒星时 换算

## 7. 开发规范

### 7.1 文档语言
- **所有项目文档默认使用中文撰写**，以节省 Token 并降低团队沟通成本

- `feat:` 新功能
