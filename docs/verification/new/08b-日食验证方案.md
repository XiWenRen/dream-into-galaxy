# 日食演示验证方案

> 版本: v1.0 | 日期: 2026-06-08 | 所属模块: 天文演示系统 — 日食演示（`eclipses` 现象步骤 0~2）

---

## 1. 验证目标

1. **数据准确性**：NASA 日食数据（`SOLAR_ECLIPSE_EVENTS`）的日期、食甚时刻、食分、沙罗序列号与权威来源一致。
2. **引擎计算正确性**：`AstrophenomenaEngine.computeShadowCone()` 和 `detectEclipse()` 的数学输出与理论值偏差在允许范围内。
3. **渲染正确性**：月球本影锥（`moonUmbraCone`）的方向、长度、透明度在严格/演示双模式下均符合预期。
4. **交互正确性**：时间轴滑块、事件选择器、步骤切换、严格/演示模式切换均按需求文档工作。
5. **性能稳定性**：日食演示场景下帧率满足基准要求，无内存泄漏或 GC 卡顿。

## 3. 单元测试（引擎层 L1）

### 3.1 阴影锥参数计算

**被测函数**: `AstrophenomenaEngine.computeShadowCone(lightR, occluderR, distance)`

| 用例 ID | 输入 | 理论输出 | 允许偏差 | 验证方法 |
|---------|------|----------|----------|----------|
| SOL-CONE-01 | `R☉=696340, R月=1737.4, d=1.5e8` (km) | `umbraAngle≈0.00468 rad`, `umbraLength≈3.73e5 km` | 角度 ≤ 1%, 长度 ≤ 1% | Jest 断言 |
| SOL-CONE-02 | `R☉=696340, R⊕=6371, d=1.5e8` (km) | `umbraAngle≈0.00461 rad`, `umbraLength≈1.38e6 km` | 角度 ≤ 1%, 长度 ≤ 1% | Jest 断言 |
| SOL-CONE-03 | 遮挡体半径 ≥ 光源半径（极限情况）| `umbraAngle` 为负或 `NaN` 时安全处理 | 不抛异常 | Jest 异常捕获 |

```typescript
// 示例测试代码
test('computeShadowCone 日食标准条件', () => {
  const result = AstrophenomenaEngine.computeShadowCone(696340, 1737.4, 1.5e8);
  expect(result.umbraAngle).toBeCloseTo(0.00468, 3);
  expect(result.penumbraAngle).toBeCloseTo(0.00466 * (696340+1737.4)/(696340-1737.4), 3);
  expect(result.umbraLength).toBeCloseTo(3.73e5, -3); // 千公里级精度
});
```

### 3.2 交食检测算法

**被测函数**: `AstrophenomenaEngine.detectEclipse(days)`

| 用例 ID | 测试日期 | 预期 `solarEclipse` | 预期 `lunarEclipse` | 验证来源 |

| SOL-DET-02 | 2025-03-14（月全食）| `false` | `true` | NASA 数据 |
