> 版本: v1.0 | 日期: 2026-06-08 | 范围: TimeEngine / OrbitEngine / AstrophenomenaEngine / ObserverEngine

## 1. 验证目标

确保所有引擎模块的数学计算正确、边界条件处理完善、纯函数行为一致。

## 2. TimeEngine 验证

### 2.1 边界条件测试

| 测试用例 | 输入 | 预期输出 | 说明 |
|----------|------|----------|------|
| J2000 历元点 | `946728000000` | `0` | 零点验证 |
| 一天后 | `+86400000` | `1.0` | 基本换算 |
| 一年前 | `-31536000000` | `-365` | 负数天数 |
| 2100年 ΔT | `4102444800000` | `114.3` | 外推边界 |

### 2.2 GMST/LST 测试

| 测试用例 | 输入 | 预期输出 | 验证方法 |
|----------|------|----------|----------|
| J2000 时刻 GMST | `946728000000` | `≈18.697h` | 对比天文年历 |
| 经度 15° | lon=15 | LST-GMST=1h | 地球自转 15°/h |
| 经度 -75° | lon=-75 | LST-GMST=-5h | 西经为负 |
| 24h 归一化 | GMST=25 | GMST=1 | 取模正确 |

### 2.3 tick 测试

| 测试用例 | 输入 | 预期输出 |
|----------|------|----------|
| 1x 1秒 | speed=1, delta=1 | +1000ms |
| 86400x 1秒 | speed=86400, delta=1 | +86400000ms |
| 0x 暂停 | speed=0, delta=10 | +0ms |

// __tests__/TimeEngine.test.ts
describe('TimeEngine', () => {
  test('J2000 epoch returns 0 days', () => {
    expect(TimeEngine.getDaysSinceJ2000(946728000000)).toBeCloseTo(0, 6);
  });
  
  test('One day later returns 1.0', () => {
    expect(TimeEngine.getDaysSinceJ2000(946728000000 + 86400000)).toBeCloseTo(1.0, 6);
  });
  
  test('LST longitude dependency', () => {
    const ts = Date.now();
    const lst0 = TimeEngine.getLocalSiderealTime(ts, 0);
    const lst15 = TimeEngine.getLocalSiderealTime(ts, 15);
    expect(lst15 - lst0).toBeCloseTo(1, 1); // 1 hour difference
  });
});
