# 渲染层验证方案

> 版本: v1.0 | 日期: 2026-06-08 | 范围: UniverseViewer / StarrySkyViewer / TelescopeOverlay

---

## 1. 验证目标

确保 3D 渲染结果在视觉上正确、性能上达标、交互上流畅。

---

## 2. UniverseViewer 视觉验证

### 2.1 地球自转同步验证

**方法**: 
1. 将时间设置为 UTC 12:00（任意日期）
2. 在宇宙视角下观察地球
3. 验证本初子午线（0° 经线）是否正对太阳

**通过标准**: 本初子午线与日心连线的偏差 < 5°

**验证日期**: 
- 春分日（2024-03-20 12:00 UTC）
- 夏至日（2024-06-21 12:00 UTC）
- 秋分日（2024-09-22 12:00 UTC）
- 冬至日（2024-12-21 12:00 UTC）

### 2.2 行星相对位置验证

**方法**: 
1. 设置特定日期（如 2024-06-01）
2. 截图记录各行星相对位置
3. 与 Stellarium / NASA Eyes 对比

**通过标准**: 行星相对角度偏差 < 5°

### 2.3 光照方向验证

**方法**: 
1. 任意时刻观察任意行星
2. 验证明暗分界线是否垂直于日-行星连线

**通过标准**: 暗面严格背向太阳

### 2.4 剖面模式验证

**方法**: 
1. 选中地球，点击"内部结构"
2. 验证 1/8 球体是否被正确切掉
3. 验证内部层级（核/幔/壳）是否正确显示

**通过标准**: 切口平整，层级颜色与数据一致，无 Z-Fighting

### 2.5 视觉比例验证

**方法**: 
1. 切换真实比例和教学比例
2. 观察外行星（土星、天王星、海王星）的间距变化

**通过标准**: 教学比例下外行星间距明显压缩，便于同时观测

## 3. StarrySkyViewer 视觉验证

### 3.1 北极星位置验证

**方法**: 
1. 设置观测纬度为 40°N（北京）
2. 在地面观星模式下观察北极星

**通过标准**: 北极星高度角 ≈ 40°，靠近北点方向

### 3.2 太阳轨迹验证

**方法**: 
1. 设置观测点为北京（40°N, 116°E）
2. 春分日：验证太阳从正东方升起，正西方落下
3. 夏至日：验证太阳从东北方升起，西北方落下

**通过标准**: 日出/日落方向与理论值偏差 < 3°

### 3.3 月相显示验证

**方法**: 
1. 跳转到已知月相日期（如满月、上弦月）
2. 观察月球的照亮方向和比例

**通过标准**: 
- 上弦月：亮面朝西
- 满月：整个圆面照亮
- 新月：不可见或极暗

### 3.4 星座连线验证

**方法**: 
1. 冬季夜晚（如 2024-01-15 20:00）
2. 在北京观测猎户座
3. 验证猎户座腰带三星（参宿一、参宿二、参宿三）是否连成直线

**通过标准**: 星座连线与真实星图一致

### 3.5 望远镜模式验证

**方法**: 
1. 开启望远镜模式
2. 调节不同倍率（7x, 20x, 50x）
3. 观察视场角变化和十字丝显示

**通过标准**: FOV 与倍率成反比，十字丝居中

## 4. 交互验证

### 4.1 相机控制

| 操作 | 预期结果 |
|------|----------|
| 鼠标拖拽 | 旋转视角 |
| 滚轮向前 | 靠近目标 |
| 滚轮向后 | 远离目标 |
| 点击行星 | 选中该行星，显示信息面板 |
| 右键拖拽 | 平移视角 |

### 4.2 模式切换

| 操作 | 预期结果 |
|------|----------|
| 进入地面观星 | 2.5 秒过渡动画，显示星空 |
| 返回宇宙视角 | 2.5 秒过渡动画，显示太阳系 |
| 快速连续切换 | 无卡顿，动画不重叠 |

## 5. 渲染性能验证

### 5.1 帧率测试

**测试方法**: 
1. Chrome DevTools Performance 面板录制 10 秒
2. 统计平均帧率和 1% 低帧率

**通过标准**:

| 场景 | 中端设备目标 |
|------|-------------|
| 1x 流速宇宙视角 | 平均 ≥ 60fps，1% low ≥ 45fps |
| 1x 流速地面观星 | 平均 ≥ 55fps，1% low ≥ 40fps |
| 3600x 流速宇宙视角 | 平均 ≥ 45fps |
| 3600x 流速地面观星 | 平均 ≥ 30fps |

### 5.2 内存测试

**测试方法**: 
1. Chrome DevTools Memory 面板
2. 录制堆快照，观察内存增长趋势

**通过标准**:
- 运行 10 分钟后，内存增长 < 50MB
- 无明显的内存泄漏（对象计数稳定）

### 5.3 显存测试

**测试方法**: 
1. Chrome `chrome://gpu` 页面
2. 观察 GPU 内存占用

**通过标准**:
- 单 WebGL 上下文
- 显存占用 < 300MB

## 6. 兼容性验证

### 6.1 WebGL 支持

**测试方法**: 
1. 检测 `window.WebGLRenderingContext`
2. 不支持时显示优雅降级提示

**通过标准**: 不支持 WebGL 的设备显示"您的设备不支持 WebGL，请使用现代浏览器"

### 6.2 移动端触摸

**测试方法**: 
1. 使用真机或 Chrome DevTools 设备模拟
2. 测试单指旋转、双指缩放

**通过标准**: 触摸交互流畅，无误触
