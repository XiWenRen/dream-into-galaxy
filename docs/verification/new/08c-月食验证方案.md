# 月食演示验证方案

> 版本: v1.0 | 日期: 2026-06-08 | 所属模块: 天文演示系统 — 月食演示（`eclipses` 现象步骤 3）

---

## 1. 验证目标

1. **数据准确性**：NASA 月食数据（`LUNAR_ECLIPSE_EVENTS`）的日期、食甚时刻、本影食分、偏食/全食持续时间与权威来源一致。
2. **引擎计算正确性**：地球阴影锥参数、`getNASAWindow()` 的 `partialDuration` 解析、`detectEclipse()` 的月食判定逻辑正确。
3. **渲染正确性**：地球截头本影锥（`earthUmbraCone`）+ 截面盘（`earthUmbraDisc`）的位置、尺寸、透明度符合预期；血月材质颜色过渡平滑自然。
4. **交互正确性**：时间轴滑块、子阶段快捷按钮、事件选择器、严格/演示模式切换均按需求文档工作。
5. **性能稳定性**：月食演示场景下帧率满足基准要求，截头锥几何重建不触发频繁 GC。

## 3. 单元测试（引擎层 L1）

### 3.1 地球阴影锥参数计算

**被测函数**: `AstrophenomenaEngine.getEarthShadowCone(sunToEarthDist)`

| 用例 ID | 输入 | 理论输出 | 允许偏差 | 验证方法 |
|---------|------|----------|----------|----------|
| LUN-CONE-01 | `d☉地 = 1.0 AU` (1.496e8 km) | `umbraAngle≈0.00461 rad`, `umbraLength≈1.38e6 km` | 角度 ≤ 1%, 长度 ≤ 1% | Jest 断言 |
| LUN-CONE-02 | `d☉地 = 1.017 AU` (远日点) | `umbraAngle` 略小，`umbraLength` 略大 | 单调性：远日点 `umbraLength` > 近日点 | Jest 断言 |
| LUN-CONE-03 | `d☉地 = 0.983 AU` (近日点) | `umbraAngle` 略大，`umbraLength` 略小 | 单调性：近日点 `umbraLength` < 远日点 | Jest 断言 |

```typescript
test('getEarthShadowCone 标准日地距离', () => {
  const result = AstrophenomenaEngine.getEarthShadowCone(1.496e8);
  expect(result.umbraLength).toBeGreaterThan(1.3e6); // 必须远大于地月距离
  expect(result.umbraLength).toBeLessThan(1.5e6);
  // 验证本影锥长度 > 地月平均距离（384,400 km）
  expect(result.umbraLength).toBeGreaterThan(384400 * 3);
});
```

### 3.2 NASA 窗口解析

**被测函数**: `AstrophenomenaEngine.getNASAWindow(timestamp, 'lunar')`

| 用例 ID | 测试事件 | `partialDuration` | 预期窗口宽度 | 验证方法 |
|---------|----------|-------------------|-------------|----------|
| LUN-WIN-01 | 2025-03-14 月全食 | `"03h38m"` | `03h38m` | Jest 断言 |
| LUN-WIN-02 | 2025-09-07 月全食 | `"03h29m"` | `03h29m` | Jest 断言 |
| LUN-WIN-03 | 2020-01-10 半影月食 | `null` | `null`（回退默认） | Jest 断言 |
| LUN-WIN-04 | 非月食日期 | — | `null` | Jest 断言 |

```typescript
test('getNASAWindow 解析月全食 partialDuration', () => {
  const ts = new Date('2025-03-14T06:59:56Z').getTime();
  const win = AstrophenomenaEngine.getNASAWindow(ts, 'lunar');
  expect(win).not.toBeNull();
  const durationHours = (win!.end - win!.start) / 3600000;
  expect(durationHours).toBeCloseTo(3 + 38/60, 1);
});
```

### 3.3 交食检测算法（月食分支）

**被测函数**: `AstrophenomenaEngine.detectEclipse(days)`

| 用例 ID | 测试日期 | 预期 `solarEclipse` | 预期 `lunarEclipse` | 验证来源 |
|---------|----------|---------------------|---------------------|----------|
| LUN-DET-01 | 2025-03-14（月全食）| `false` | `true` | NASA 数据 |
| LUN-DET-02 | 2024-03-25（半影月食）| `false` | `true` | NASA 数据（阈值内） |
| LUN-DET-03 | 2024-09-18（月偏食）| `false` | `true` | NASA 数据 |
| LUN-DET-04 | 2024-04-08（日全食）| `true` | `false` | NASA 数据 |
| LUN-DET-05 | 2024-06-15（无交食）| `false` | `false` | Stellarium 验证 |

**注意**：`detectEclipse` 的月食阈值为 `180° − angle < 1.02°`，该阈值对半影月食可能漏检（因为半影月食的地影轴偏离可能 > 1.02°）。这属于简化模型的已知局限，需求文档已声明 "仅判断是否可能发生"。

## 7. 性能验证

### 7.1 帧率基准

| 场景 | 中端设备目标 | 测试方法 |
|------|-------------|----------|
| 步骤 3，截头锥+截面盘渲染，1x 流速 | ≥ 55fps | Chrome DevTools Performance 面板录制 30s |
| 快速拖拽滑块 | 无掉帧 below 45fps | 连续拖拽 10 次，取最低帧率 |
| 切换 10 次月食事件 | 每次切换后帧率恢复 ≥ 55fps | 事件切换不留下性能残留 |

### 7.2 内存与显存

| 指标 | 目标 | 测试方法 |
|------|------|----------|
| 进入月食演示后 JS Heap 增长 | ≤ 25MB | Chrome DevTools Memory 面板 before/after 对比 |
| 截头锥重建频率 | ≤ 1 次/秒 | 在 Performance 面板中检查 `CylinderGeometry` 构造函数调用频率 |
| 切换 10 次事件后 GPU 显存 | 无持续增长 | Chrome 任务管理器或 `chrome://gpu` 观察 |

### 7.3 几何重建优化验证

**测试方法**：在严格模式下，固定时间不变（滑块不动），观察 `UniverseViewer` 渲染循环。

| 条件 | 预期行为 |
|------|----------|
| 时间不变、轨道不变 | `earthUmbraCone.geometry` 不重建（尺寸变化为 0） |
| 时间推进 1 分钟 | 地月距离变化极小，仍不重建 |
| 时间推进 1 小时 | 地月距离变化显著（~3,000 km），可能触发 1 次重建 |
