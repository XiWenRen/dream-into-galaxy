# 性能验证方案

> 版本: v1.0 | 日期: 2026-06-08 | 范围: 全系统性能

---

## 1. 验证目标

确保系统在各种设备和时间流速下都能流畅运行，无卡顿、无内存泄漏。

---

## 2. 测试环境

### 2.1 硬件分级

| 级别 | CPU | GPU | 内存 | 代表设备 |
|------|-----|-----|------|----------|
| 高端 | M3 Pro / i7-13700 | RTX 4070 / M3 GPU | 16GB | MacBook Pro 14" |
| 中端 | i5-1240P / R5 6600U | 核显 Iris Xe | 8GB | MacBook Air |
| 低端 | i3-10110U | UHD 620 | 4GB | 老旧笔记本 |

### 2.2 浏览器

Chrome 最新版（作为主要测试浏览器）

---

## 3. 帧率测试

### 3.1 测试场景

| 场景编号 | 描述 |
|----------|------|
| S1 | 宇宙视角，默认相机，1x 流速 |
| S2 | 宇宙视角，跟随地球，1x 流速 |
| S3 | 地面观星，北京，1x 流速 |
| S4 | 宇宙视角，默认相机，3600x 流速 |
| S5 | 地面观星，北京，3600x 流速 |
| S6 | 宇宙视角，真实比例，1x 流速 |

### 3.2 测试方法

1. 打开 Chrome DevTools Performance 面板
2. 录制 30 秒
3. 记录以下指标：
   - 平均帧率 (FPS)
   - 1% 低帧率 (1% Low FPS)
   - 帧时间分布 (Frame Time Distribution)

### 3.3 通过标准

| 场景 | 高端 | 中端 | 低端 |
|------|------|------|------|
| S1 | ≥ 60fps | ≥ 60fps | ≥ 30fps |
| S2 | ≥ 60fps | ≥ 60fps | ≥ 30fps |
| S3 | ≥ 60fps | ≥ 55fps | ≥ 25fps |
| S4 | ≥ 60fps | ≥ 45fps | ≥ 20fps |
| S5 | ≥ 60fps | ≥ 40fps | ≥ 15fps |
| S6 | ≥ 60fps | ≥ 60fps | ≥ 30fps |

## 4. 内存测试

### 4.1 测试方法

1. Chrome DevTools Memory 面板
2. 初始堆快照
3. 运行 10 分钟（1x 和 3600x 各 5 分钟）
4. 最终堆快照
5. 对比对象数量和内存增长

### 4.2 通过标准

| 指标 | 目标 |
|------|------|
| JS 堆内存 | ≤ 200MB |
| 10 分钟内存增长 | ≤ 50MB |
| 对象泄漏 | 0（核心对象计数稳定） |

---

## 5. 显存测试

### 4.1 测试方法

1. Chrome `chrome://gpu` 页面
2. 观察 GPU 内存占用
3. 或使用 `renderer.info` 统计 Three.js 资源

### 4.2 通过标准

| 指标 | 目标 |
|------|------|
| GPU 显存 | ≤ 300MB |
| Texture 数量 | ≤ 50 |
| Geometry 数量 | ≤ 100 |

---

## 6. 启动时间测试

### 6.1 测试方法

1. Lighthouse Performance 审计
2. 或手动计时：从输入 URL 到首屏可交互

### 6.2 通过标准

| 指标 | 目标 |
|------|------|
| First Contentful Paint (FCP) | ≤ 1.5s |
| Largest Contentful Paint (LCP) | ≤ 2.5s |
| Time to Interactive (TTI) | ≤ 3.5s |
| Total Blocking Time (TBT) | ≤ 200ms |

---

## 7. 高流速稳定性测试

### 7.1 测试方法

1. 设置时间流速为 86400x（1秒=1天）
2. 连续运行 1 小时（模拟 365 年）
3. 观察：
   - 帧率是否稳定
   - 内存是否持续增长
   - 行星位置是否合理（无跳变）
   - 是否有 GC 导致的卡顿

### 7.2 通过标准

- 帧率波动 < 20%
- 内存增长 < 100MB
- 无行星位置跳变
- GC 卡顿间隔 > 10 秒

---

## 8. 压力测试

### 8.1 测试方法

1. 同时开启所有视觉效果（云层、剖面、轨道线、坐标轴、网格）
2. 快速切换模式和行星
3. 连续缩放

### 8.2 通过标准

- 无崩溃
- 帧率下降 < 50%
- 无内存溢出
