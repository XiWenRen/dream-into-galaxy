# 天文精度验证方案

> 版本: v1.0 | 日期: 2026-06-08 | 范围: 全系统天文计算精度

---

## 1. 验证目标

确保所有天文计算结果与权威数据源（NASA JPL Horizons、IAU 标准、Stellarium）的偏差在允许范围内。

---

## 2. 权威数据源

### 2.1 NASA JPL Horizons

**网址**: https://ssd.jpl.nasa.gov/horizons/

**使用方式**:
1. 选择 Ephemeris Type: VECTORS
2. 选择 Target Body: 需要验证的行星/月球
3. 选择 Coordinate Origin: Sun (body center)
4. 选择 Time Span: 需要验证的日期
5. 选择 Output Units: AU 和 days
6. 下载结果作为黄金标准

### 2.2 Stellarium

**用途**: 
- 验证地面观星的恒星位置、日月位置、月相
- 验证星座连线和名称
- 免费开源，跨平台

### 2.3 NOAA 节气数据

**网址**: https://www.ngdc.noaa.gov/

**用途**: 验证 24 节气的精确时刻

## 3. 行星轨道精度验证

### 3.1 验证方法

1. 选取 12 个测试日期（每月 1 日）
2. 对每个日期，用 Horizons 获取 8 颗行星的日心坐标
3. 用 OrbitEngine 计算同一日期的坐标
4. 计算欧氏距离偏差

### 3.2 允许偏差

| 天体 | 允许偏差 (AU) | 允许角度偏差 |
|------|--------------|-------------|
| 水星 | ±0.01 | ±1° |
| 金星 | ±0.01 | ±0.5° |
| 地球 | ±0.005 | ±0.3° |
| 火星 | ±0.01 | ±0.5° |
| 木星 | ±0.01 | ±0.1° |
| 土星 | ±0.01 | ±0.05° |
| 天王星 | ±0.01 | ±0.03° |
| 海王星 | ±0.01 | ±0.02° |

## 4. 月球位置精度验证

### 4.1 验证方法

1. 选取 6 个测试日期（包含月食日期）
2. 用 Horizons 获取月球的地球相对坐标
3. 用 OrbitEngine 计算同一日期的坐标
4. 计算角度偏差

### 4.2 允许偏差

| 场景 | 允许偏差 |
|------|----------|
| 普通日期 | ±0.5° |
| 月食日期 | ±1.0° |

### 4.3 关键验证日期

| 日期 | 事件 | 允许偏差 |
|------|------|----------|
| 2020-01-10 | 月全食 | ±1.0° |
| 2024-03-25 | 满月 | ±0.5° |
| 2024-09-18 | 满月 | ±0.5° |

---

## 5. 太阳黄经与节气验证

### 5.1 验证方法

1. 用 AstrophenomenaEngine 计算全年各日期的太阳黄经
2. 与 NOAA 发布的节气时刻对比

### 5.2 允许偏差

| 参数 | 允许偏差 |
|------|----------|
| 太阳黄经 | ±0.1° |
| 节气时刻 | ±8 小时 |

### 5.3 2024 年节气验证

| 节气 | 天文年历时刻 | 引擎计算 | 偏差 |

| 夏至 | 2024-06-21 10:51 | | |
| 秋分 | 2024-09-22 18:43 | | |
| 冬至 | 2024-12-21 17:20 | | |

## 6. 月相验证

### 6.1 验证方法

1. 选取 12 个测试日期（每月 15 日左右）
2. 用引擎计算月相
3. 与 Stellarium / 天文年历对比

### 6.2 允许偏差

| 参数 | 允许偏差 |
|------|----------|
| 月相索引 | ±0.5 天 |
| 照亮比例 | ±5% |

---

## 7. 恒星位置验证

### 7.1 验证方法

1. 选取 10 颗代表性恒星（覆盖不同赤经/赤纬）
2. 计算当前历元的赤道坐标（含岁差修正）
3. 与 SIMBAD 数据库对比

### 7.2 允许偏差

| 参数 | 允许偏差 |
|------|----------|
| 赤经 | ±1 角分 |
| 赤纬 | ±1 角分 |

---

## 8. 交食验证

### 8.1 验证方法

1. 对 NASA 交食数据表中的每个事件
2. 用引擎的 detectEclipse 检测该日期
3. 验证是否识别为交食

### 8.2 允许偏差

| 参数 | 允许偏差 |
|------|----------|
| 交食发生 | 必须识别 |
| 交食类型 | 不要求（简化模型无法区分全食/环食） |
