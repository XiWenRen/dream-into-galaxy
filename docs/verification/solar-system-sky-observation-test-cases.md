# 太阳系星空观测验证文档

**Solar System Sky Observation Verification Test Cases**

**版本**: v0.1  
**日期**: 2026-05-24  
**用途**: 作为 GalaxySim3D 星空模式系统测试的权威预期结果参考  
**编制依据**: NASA JPL Horizons Ephemeris, IAU 2006 星历框架, Tomasko et al. (2005) Huygens DISR  

---

## 1. 文档说明

本文档定义了在 GalaxySim3D 星空模式下，登录到太阳系内不同星体表面时，应观测到的天空景象的精确预期结果。每颗星体按统一模板组织测试用例，覆盖昼夜变化、纬度差异、季节变化、主导天体可见性、特殊天象等维度。

**观测星体范围**：
- 行星：水星、金星、地球、火星、木星、土星、天王星、海王星
- 天然卫星：月球、火卫一(Phobos)、火卫二(Deimos)、木卫一(Io)、木卫二(Europa)、木卫三(Ganymede)、木卫四(Callisto)、土卫六(Titan)、土卫五(Rhea)、土卫二(Enceladus)、天卫三(Titania)、天卫四(Oberon)、天卫一(Ariel)、海卫一(Triton)、海卫八(Proteus)

---

## 2. 统一测试用例模板

每个测试用例严格包含以下字段：

| 字段 | 说明 |
|------|------|
| **TC-ID** | 唯一编号，格式：`[观测者星体]-[场景类别]-[序号]` |
| **观测者星体** | 当前登录星体 |
| **观测位置** | `(纬度, 经度)`，单位度。无固体表面的星体标注为 N/A |
| **模拟时间** | UTC 时间 + J2000 日数，附天文描述 |
| **太阳状态** | 太阳相对于地平线状态（方位、仰角、角直径、视星等） |
| **主导天体** | 该星体的母行星/卫星，预期可见性描述 |
| **预期可见天体清单** | 应出现的天体：方位角(Az)、仰角(Alt)、角直径、视星等 |
| **预期不可见天体** | 应不可见的天体及原因 |
| **星座/深空天体** | 可见的星座区域或特殊深空天体 |
| **特殊天象** | 食、冲、合、最大伸长、静止点等 |
| **环境条件** | 大气散射、光污染、潮汐锁定面、表面反照率等 |
| **校验点** | 系统需验证的精确数值（角度误差容忍 ≤ 2°） |
| **天文依据** | 数据来源与计算公式 |

**场景类别编码**：
- `DAY`：白天观测（太阳在地平线以上）
- `NIGHT`：夜间观测（太阳在地平线下，且天文曙暮光结束）
- `TWILIGHT`：晨昏过渡（民用曙暮光范围内，-6° > Alt > -18°）
- `POLAR`：极区特殊现象
- `SEASONAL`：季节/周年变化
- `DOM`：主导天体观测（从卫星看母行星）
- `RING`：行星环系统可见性
- `SUN`：太阳在遥远距离的表现
- `SAT`：其他卫星互视
- `ATM`：大气层效应
- `ECLIPSE`：食象

## 3. 地球 (Earth) 测试用例

### TC-EARTH-DAY-01：北京春分正午太阳位置

| 字段 | 内容 |
|------|------|
| **TC-ID** | `EARTH-DAY-01` |
| **观测者星体** | 地球 |
| **观测位置** | (39.9°N, 116.4°E) — 北京 |
| **模拟时间** | 2024-03-20 12:00 CST (UTC+8)，J2000+8856.0 日，春分正午 |
| **太阳状态** | 上中天，Az ≈ 180° (正南)，Alt ≈ 50.1°，角直径 ≈ 0.53°，视星等 -26.74 |
| **主导天体** | 月球 — 此时位于天球另一侧或地平线以下，不可见 |
| **预期可见天体清单** | **太阳**：Az 180°，Alt 50.1°，角直径 0.53°，视星等 -26.74（全天最亮） |
| **预期不可见天体** | 月球（地平下或被日光淹没）<br>行星（被日光淹没）<br>恒星（被日光+大气散射淹没，仅天顶方向极亮星可能勉强可见） |
| **星座/深空天体** | 无 |
| **特殊天象** | 太阳经过本地子午圈（上中天）；春分日昼夜等长 |
| **环境条件** | 大气散射强（瑞利散射），天空呈亮蓝色；地平附近偏白/淡黄；地面受直射光照 |
| **校验点** | ① 太阳仰角 = 90° - \|39.9° - 0°\| = 50.1° ± 2°<br>② 太阳方位角 = 180°（正南）± 2°<br>③ 天空背景色应为白天蓝色系（R<0.4, G<0.6, B>0.8）<br>④ 除太阳外所有天体透明度应 < 0.05 或被截断 |
| **天文依据** | 正午高度角公式 h = 90° - \|φ - δ\|；春分 δ=0°，φ=39.9° → h=50.1° |

### TC-EARTH-NIGHT-01：北京冬至子夜星空

| 字段 | 内容 |
|------|------|
| **TC-ID** | `EARTH-NIGHT-01` |
| **观测者星体** | 地球 |
| **观测位置** | (39.9°N, 116.4°E) — 北京 |
| **模拟时间** | 2024-12-21 00:00 CST，冬至子夜 |
| **太阳状态** | 在地平线以下约 -73°，完全不可见 |
| **主导天体** | 月球（假设上弦月）：Az ≈ 270°（正西），Alt ≈ 35°，角直径 0.5°，视星等 -12.2 |
| **预期可见天体清单** | **月球**：Az 270°，Alt 35°，角直径 0.5°，相位约 50%（亮面朝西）<br>**木星**：若位于金牛座，Az ≈ 160-200°，Alt > 40°，视星等 -2.5<br>**猎户座**：Az ≈ 210°（西南），Alt 40-60°，冬季最显著星座<br>— 参宿四（Betelgeuse）：Az ≈ 220°，Alt ≈ 45°，视星等 +0.5，呈橙红色<br>— 参宿七（Rigel）：Az ≈ 225°，Alt ≈ 35°，视星等 +0.1，呈蓝白色<br>**天狼星（大犬座α）**：Az ≈ 200°，Alt ≈ 25°，视星等 -1.46，全天最亮恒星<br>**金牛座**：Az ≈ 180-220°，Alt 40-60°，含毕宿五（Aldebaran，+0.85等，红色）<br>**双子座**：Az ≈ 100-140°，Alt 60-80°，含北河二（Castor）、北河三（Pollux，+1.15等）<br>**大熊座（北斗七星）**：北方天空，Alt ≈ 20-50°，斗柄指向下/北（冬季特征）<br>**御夫座**：含五车二（Capella，+0.08等），北方高空 |
| **预期不可见天体** | 太阳（地平下 -73°）<br>金星（可能位于日面附近）<br>土星（可能位于日面附近或被地平遮挡）<br>南十字座（北京纬度不可见，赤纬太南）<br>大麦哲伦云（仅南半球可见） |
| **星座/深空天体** | **猎户座大星云（M42）**：猎户座腰带下方，肉眼可见模糊光斑<br>**昴星团（M45）**：金牛座，肉眼可见疏散星团<br>**冬季大三角**：天狼星（大犬座）、南河三（小犬座）、参宿四（猎户座）构成<br>**冬季大椭圆**：五车二、毕宿五、参宿七、天狼星、南河三、北河三、五车二 |
| **特殊天象** | 冬至夜最长；北斗七星斗柄指向正北下方（"斗柄北指，天下皆冬"） |
| **环境条件** | 完全暗夜，无月光时肉眼极限星等约 6.5；有上弦月时极限星等降至约 5.0 |
| **校验点** | ① 太阳仰角 < -18°（天文曙暮光以下）<br>② 猎户座至少 5 颗主星可见（参宿四、参宿七、参宿一、参宿二、参宿三）<br>③ 天狼星视星等显示约 -1.46 ± 0.2<br>④ 北斗七星勺口两颗星（天枢、天璇）连线指向北极星（小熊座α，+1.98等）<br>⑤ 北极星仰角 ≈ 40°（约等于北京纬度）<br>⑥ 天空背景色为深黑（R,G,B < 0.05） |
| **天文依据** | 冬至 δ = -23.44°；可观测赤纬范围：φ - 90° < δ < 90° - φ → 北京可见 δ > -50.1° 的天体 |

### TC-EARTH-TWILIGHT-01：北京春分民用曙暮光

| 字段 | 内容 |
|------|------|
| **TC-ID** | `EARTH-TWILIGHT-01` |
| **观测者星体** | 地球 |
| **观测位置** | (39.9°N, 116.4°E) — 北京 |
| **模拟时间** | 2024-03-20 19:00 CST（日落后约 1 小时） |
| **太阳状态** | 太阳中心位于地平下约 -6° 到 -12°（民用曙暮光阶段），Az ≈ 270°（西方地平线） |
| **主导天体** | 月球（假设满月后不久）：东方低空升起，呈橙黄色 |
| **预期可见天体清单** | **金星**（若作为昏星）：西方低空，Az ≈ 260-280°，Alt < 15°，视星等 -4.4，呈明亮白色（"长庚星"）<br>**木星**：若可见，位于东方/南方，Alt > 20°<br>**天狼星等亮星**：东方天空开始出现<br>**月球**：东方低空，Alt < 10°，呈橙红色（大气消光） |
| **预期不可见天体** | 中等亮度恒星（被暮光淹没）<br>暗于 3 等的恒星不可见 |
| **星座/深空天体** | 仅最亮恒星可见：天狼星、织女星（若在天顶附近）、大角星等 |
| **特殊天象** | 民用曙暮光阶段，天空从蓝色渐变为深蓝→紫→橙红色（地平线方向） |
| **环境条件** | 三段式曙暮光：0° ~ -6° 民用曙暮光（亮星可见）；-6° ~ -12° 航海曙暮光（地平线模糊可见）；-12° ~ -18° 天文曙暮光（接近全黑） |
| **校验点** | ① 天空背景色应为渐变色（西方橙红→东方深蓝）<br>② 地平线附近可见金星等亮行星<br>③ 太阳仰角在 -6° ~ -18° 范围内<br>④ 星座连线透明度应在 0.1 ~ 0.4 之间（随暮光深度递减） |
| **天文依据** | 民用曙暮光定义：太阳中心位于地平下 0° ~ 6°；航海曙暮光：6° ~ 12°；天文曙暮光：12° ~ 18° |

### TC-EARTH-POLAR-01：北极点夏至极昼

| 字段 | 内容 |
|------|------|
| **TC-ID** | `EARTH-POLAR-01` |
| **观测者星体** | 地球 |
| **观测位置** | (90.0°N, 0°E) — 北极点 |
| **模拟时间** | 2024-06-21 00:00 UTC，夏至 |
| **太阳状态** | 太阳全天不落下，Alt 最低约 +23.4°（位于地平线上），Az 缓慢绕圈；最高 Alt ≈ 23.4° + 天顶距变化，实际在北极点太阳始终维持 Alt ≈ 23.4° 绕圈 |
| **主导天体** | 月球 — 视轨道位置，可能也在地平线以上 |
| **预期可见天体清单** | **太阳**：全天可见，绕圈运动（逆时针），Alt ≈ 23.4°（等于黄赤交角），Az 24小时转 360°<br>所有恒星始终在地平线以下或被日光淹没（极昼无暗夜） |
| **预期不可见天体** | 全部恒星（极昼期间日光持续照亮天空）<br>北极星（位于天顶，但极昼期间被日光淹没不可见） |
| **星座/深空天体** | 无 |
| **特殊天象** | 极昼现象：太阳 24 小时不落下；北极点处太阳始终维持在约 23.4° 高度绕转 |
| **环境条件** | 持续白昼，天空始终亮；太阳高度角低（斜射），地面光照柔和 |
| **校验点** | ① 太阳仰角始终 > 0°（极昼验证）<br>② 太阳 24 小时内绕圈 Az 0° → 360°<br>③ 太阳最低 Alt ≈ 23.4° ± 2°（黄赤交角）<br>④ 无恒星可见（天空亮度始终 > 0.2）<br>⑤ 北极星位于天顶（Az 任意，Alt = 90°）但不可见 |
| **天文依据** | 北极点 φ = 90°，夏至 δ = +23.44°，太阳高度角 = 90° - \|90° - 23.44°\| = 23.44°，全天维持此高度绕转 |

### TC-EARTH-SEASONAL-01：北京 vs 悉尼同时刻星座对比

| 字段 | 内容 |
|------|------|
| **TC-ID** | `EARTH-SEASONAL-01` |
| **观测者星体** | 地球 |
| **观测位置 A** | (39.9°N, 116.4°E) — 北京 |
| **观测位置 B** | (33.9°S, 151.2°E) — 悉尼 |
| **模拟时间** | 2024-06-21 00:00 UTC（北京夏至子夜 / 悉尼冬至子夜） |
| **太阳状态** | 北京：太阳在地平下约 -35°<br>悉尼：太阳在地平下约 -80° |
| **主导天体** | 月球 — 视月相 |
| **预期可见天体清单（北京）** | **夏季大三角**：牛郎星（Altair，天鹰座α，Alt ≈ 50°）、织女星（Vega，天琴座α，Alt ≈ 70°）、天津四（Deneb，天鹅座α，Alt ≈ 60°）<br>**天蝎座**：南方低空，Alt < 20°，心宿二（Antares，+1.0等，红色）<br>**北斗七星**：北方天空，Alt ≈ 40°，斗柄指南（夏季特征"斗柄南指，天下皆夏"）<br>**大角星（Arcturus）**：西方低空，即将落下 |
| **预期可见天体清单（悉尼）** | **猎户座**：冬季北半球星座，在悉尼冬季夜空高悬，Alt ≈ 40-60°<br>**天蝎座**：南方高空，Alt ≈ 60-80°（ Sydney 纬度更南，天蝎座更高）<br>**南十字座（Crux）**：南方高空，Alt ≈ 30-50°，全天最著名南天星座<br>**大麦哲伦云（LMC）**：南天极附近，肉眼可见模糊云状光斑，Alt ≈ 20-40°<br>**半人马座α（南门二，Rigil Kentaurus）**：南方低空，全天第三亮星，视星等 -0.01<br>**半人马座β（马腹一，Hadar）**：南方，视星等 +0.6<br>**人马座/射手座**：头顶附近，银河中心方向 |
| **预期不可见天体** | **北京不可见**：南十字座、大麦哲伦云、小麦哲伦云（SMC）、船底座η（Eta Carinae 星云）<br>**悉尼不可见**：北极星（始终在地平下）、仙后座大部分（部分时间可见但很低）、小熊座大部分 |
| **星座/深空天体** | **北京**：银河从天鹅座经天鹰座延伸至人马座方向（南方地平线附近）<br>**悉尼**：银河中心（人马座方向）几乎过天顶，极为壮观；麦哲伦云清晰可见 |
| **特殊天象** | 南北半球季节相反：北京夏季 = 悉尼冬季；同一 UTC 时刻两地看到的星空互补 |
| **环境条件** | 两地均为子夜，暗夜条件 |
| **校验点** | ① 北京：织女星 Alt > 65°（北京夏季天顶附近最亮星）<br>② 北京：北极星仰角 ≈ 40°（约等于北京纬度）<br>③ 悉尼：南十字座至少 4 颗主星可见，Alt > 20°<br>④ 悉尼：北极星不可见（Alt < 0°）<br>⑤ 两地同时看到的恒星集合交集应很小（仅赤道附近星座如猎户座、天蝎座部分可见）<br>⑥ 悉尼可见大麦哲伦云为模糊光斑 |
| **天文依据** | 可观测赤纬范围：-(90°-\|φ\|) < δ < (90°-\|φ\|)。北京可见 δ > -50.1°；悉尼可见 δ < +56.1° |

### TC-EARTH-ECLIPSE-01：日全食期间天空变化

| 字段 | 内容 |
|------|------|
| **TC-ID** | `EARTH-ECLIPSE-01` |
| **观测者星体** | 地球 |
| **观测位置** | 全食带中心（以 2024-04-08 北美日全食为例，约 45°N, 75°W） |
| **模拟时间** | 2024-04-08 19:00 UTC（全食阶段） |
| **太阳状态** | 太阳被月球完全遮挡，仅日冕可见；天空亮度骤降至类似深夜 |

| **预期可见天体清单** | **无恒星可见**（Titan 大气光学深度 τ ≈ 1.3，可见光几乎无法穿透）<br>**无行星可见**（除木星可能极暗可见，但被大气散射淹没）<br>若系统模拟近红外/雷达波段：可穿透大气看到暗弱天体 |
| **预期不可见天体** | 全部恒星（被大气散射和吸收阻挡）<br>银河系（不可见）<br>其他星系/深空天体（不可见） |
| **星座/深空天体** | 无 |
| **特殊天象** | Titan 表面"夜空"并非黑色，而是呈现暗橙黄色（大气散射的土星反射光和星际背景光） |
| **环境条件** | **Titan 大气关键参数**：<br>• 表面温度：94 K（-179°C）<br>• 表面气压：1.47 bar<br>• 可见光光学深度 τ ≈ 1.3（仅 27% 的可见光能穿透）<br>• 大气主要由 N₂ 和 CH₄ 组成，甲烷强烈吸收红光和红外<br>• 存在厚密的碳氢化合物雾霾层（haze layers），从表面延伸到 500 km 以上<br>• 散射类型：前向散射为主（太阳光/土星光照方向天空更亮） |
| **校验点** | ① 即使在无太阳、无土星的"最暗"时刻，天空背景亮度仍 > 0.1（不是纯黑）<br>② 天空颜色为暗橙黄色/褐色（#6B5344 ~ #8B7355），不应为黑色<br>③ 恒星透明度应 < 0.05（几乎不可见）<br>④ 若在高层大气（> 100 km）观测：恒星应可见，天空趋近黑色<br>⑤ 太阳/土星附近天空亮度梯度极大（强前向散射） |
| **天文依据** | Titan 大气光学深度：Tomasko et al. (2005) Huygens DISR data: τ ≈ 1.3 at λ = 0.55 μm; τ decreases at longer wavelengths (τ ≈ 0.1 at λ = 1 μm); McKay et al. (1989) haze models |

## 6. 通用校验规则

以下规则适用于所有星体的星空观测验证：

### 6.1 地平线截断规则
- 任何天体计算仰角 Alt < -2° 时，应被截断不可见
- Alt 在 -2° ~ +2° 范围内，天体应部分可见（考虑大气折射和星体自身角半径）

### 6.2 大气散射规则
- **无大气星体**（水星、月球、火卫、木卫等）：白天太阳眩光淹没附近星空，但背向太阳方向极暗恒星仍可能可见
- **稀薄大气星体**（火星）：天空呈粉红色/橙红色，恒星在白天被淹没，夜间清晰可见
- **浓密大气星体**（金星、土卫六、巨行星云层）：可见光几乎完全被散射/吸收，恒星永远不可见（或仅最亮者微弱可见）
- **中等大气星体**（地球）：遵循标准瑞利散射模型，蓝天天顶→白天地平→黑夜过渡

### 6.3 主导天体规则
- 对于**潮汐锁定卫星**（月球、主要木卫、土卫、天卫、海卫一），母行星在天空中**固定不动**（不升不落），仅有微小天平动
- 主导天体的角直径和视星等必须按真实轨道参数计算
- 主导天体应正确显示相位（被太阳照射的部分）

### 6.4 角度精度容忍度
- 方位角(Az) 和 仰角(Alt) 的计算误差：≤ 2°（恒星/行星），≤ 0.5°（太阳/月球/主导天体）
- 角直径计算误差：≤ 10%
- 视星等计算误差：≤ 0.5 等（用于亮度排序正确即可）

### 6.5 时间基准
- 所有计算基于 J2000.0 历元（2000-01-01 12:00 TT）
- 岁差、章动效应可忽略（误差 < 1°，在容忍范围内）
- 光行时效应可忽略（太阳系内最大光行时约 0.03°）
