# 地球 (Earth) 星空观测验证用例

**观测者星体**: Earth (地球)  
**无固体表面**: 有  
**大气状态**: 标准大气（气压 1.013 bar，N₂+O₂）  
**卫星数量**: 1（月球）  

## 星体基本参数

| 参数 | 数值 |
|------|------|
| 距太阳平均距离 | 1.000 AU (149.6×10⁶ km) |
| 太阳角直径 | 0.53° |
| 太阳视星等 | -26.74 |
| 自转周期 | 23h 56m 4s（恒星日） |
| 自转轴倾角 | 23.44° |
| 卫星（月球）平均距离 | 384,400 km |
| 月球角直径 | 0.5° |
| 月球视星等（满月） | -12.74 |
| 可见光大气光学深度 | τ ≈ 0.1（晴天）~ 1.0（阴天） |

> **注意**: 本文件只包含地球特有的高优先级用例。完整的地球用例集（含 7 个详细用例）已在大纲文档中定义。

## 测试用例

### TC-EARTH-DAY-01：春分正午太阳位置

| 字段 | 内容 |
|------|------|
| **TC-ID** | `EARTH-DAY-01` |
| **观测位置** | (39.9°N, 116.4°E) — 北京 |
| **模拟时间** | 春分日 12:00 CST |
| **太阳状态** | 上中天，Az = 180°，Alt = 50.1°，角直径 0.53°，视星等 -26.74 |
| **主导天体** | 月球 — 通常在地平线以下或被日光淹没 |
| **预期可见天体清单** | **太阳**：Az 180°，Alt 50.1° |
| **预期不可见天体** | 月球、行星、恒星（被日光+大气散射淹没） |
| **星座/深空天体** | 无 |
| **特殊天象** | 春分昼夜等长 |
| **环境条件** | 瑞利散射，天空亮蓝色；地平附近偏白 |
| **校验点** | ① 太阳 Alt = 90° - \|39.9° - 0°\| = 50.1° ± 2°
② 天空背景色为白天蓝色系
③ 除太阳外所有天体透明度 < 0.05 |
| **天文依据** | h = 90° - \|φ - δ\| |

### TC-EARTH-NIGHT-01：冬至子夜星空

| 字段 | 内容 |
|------|------|
| **TC-ID** | `EARTH-NIGHT-01` |
| **观测位置** | (39.9°N, 116.4°E) — 北京 |
| **模拟时间** | 冬至 00:00 CST |
| **太阳状态** | 地平下约 -73° |
| **主导天体** | 月球（假设上弦月）：Az ≈ 270°，Alt ≈ 35° |
| **预期可见天体清单** | **月球**：Az 270°，Alt 35°，相位 50%
**木星**：Az ≈ 180°，Alt > 40°，m ≈ -2.5
**猎户座**：Az ≈ 210°，Alt 40-60°
**天狼星**：Az ≈ 200°，Alt ≈ 25°，m = -1.46
**金牛座**：含毕宿五
**双子座**：含北河三
**大熊座（北斗）**：北方，斗柄指北 |
| **预期不可见天体** | 太阳；南十字座；大麦哲伦云 |
| **星座/深空天体** | M42（猎户座大星云）、M45（昴星团）、冬季大三角 |
| **特殊天象** | 冬至夜最长；北斗斗柄北指 |
| **环境条件** | 暗夜，极限星等约 6.5 |
| **校验点** | ① 太阳 Alt < -18°
② 猎户座至少 5 颗主星可见
③ 天狼星 m ≈ -1.46
④ 北极星 Alt ≈ 40°（等于纬度）
⑤ 天空背景深黑 |
| **天文依据** | 可观测 δ > -(90° - φ) = -50.1° |

### TC-EARTH-SEASONAL-01：北京 vs 悉尼季节对比

| 字段 | 内容 |
|------|------|
| **TC-ID** | `EARTH-SEASONAL-01` |
| **观测位置 A** | (39.9°N, 116.4°E) — 北京 |
| **观测位置 B** | (33.9°S, 151.2°E) — 悉尼 |
| **模拟时间** | 夏至/冬至子夜 |
| **太阳状态** | 北京：地平下 -35°；悉尼：地平下 -80° |
| **主导天体** | 月球 |
| **预期可见天体清单（北京夏至）** | 夏季大三角（牛郎星、织女星 Alt ≈ 70°、天津四）
天蝎座（南方低空）
北斗（斗柄指南） |
| **预期可见天体清单（悉尼冬至）** | 猎户座（高悬）
天蝎座（高空）
南十字座（Alt 30-50°）
大麦哲伦云（肉眼可见）
半人马座α（m = -0.01） |
| **预期不可见天体** | 北京：南十字座、大麦哲伦云
悉尼：北极星、小熊座 |
| **星座/深空天体** | 北京：银河延伸至南方地平线
悉尼：银河中心过天顶，大麦哲伦云 |
| **特殊天象** | 南北半球季节相反，星空互补 |
| **环境条件** | 两地均为子夜暗夜 |
| **校验点** | ① 北京织女星 Alt > 65°
② 悉尼南十字座 Alt > 20°
③ 悉尼北极星 Alt < 0°
④ 两地交集仅赤道星座 |
| **天文依据** | 可观测范围：-(90°-\|φ\|) < δ < (90°-\|φ\|) |

### TC-EARTH-POLAR-01：北极点夏至极昼

| 字段 | 内容 |
|------|------|
| **TC-ID** | `EARTH-POLAR-01` |
| **观测位置** | (90°N, 0°E) — 北极点 |
| **模拟时间** | 夏至 |
| **太阳状态** | 全天不落下，Alt ≈ 23.4° 绕圈 |
| **主导天体** | 月球 |
| **预期可见天体清单** | **太阳**：全天可见，Alt ≈ 23.4° 绕圈，Az 24h 转 360° |
| **预期不可见天体** | 全部恒星（极昼淹没） |
| **星座/深空天体** | 无 |
| **特殊天象** | 极昼；太阳高度角 = 黄赤交角 |
| **环境条件** | 持续白昼；太阳斜射 |
| **校验点** | ① 太阳始终 Alt > 0°
② 太阳最低 Alt ≈ 23.4°
③ 无恒星可见 |
| **天文依据** | 北极点 φ=90°，夏至 δ=23.44°，h = 90°-\|90°-23.44°\| = 23.44° |

### TC-EARTH-ECLIPSE-01：日全食天空变化

| 字段 | 内容 |
|------|------|
| **TC-ID** | `EARTH-ECLIPSE-01` |
| **观测位置** | 全食带中心 |
| **模拟时间** | 全食阶段 |
| **太阳状态** | 被月球完全遮挡，仅日冕可见 |
| **主导天体** | 月球：黑色圆盘遮挡太阳，周围银白色日冕 |
| **预期可见天体清单** | 日冕（银白色光晕）
水星（通常被淹没，日食时可见）
木星、火星、金星（若在天区）
亮星（天狼星等） |
| **预期不可见天体** | 太阳本体 |
| **星座/深空天体** | 无（天空仍不够暗） |
| **特殊天象** | 天空骤变黑暗；温度下降 |
| **环境条件** | 天空亮度降至 1/10000 |
| **校验点** | ① 太阳本体被遮挡
② 天空变为深蓝/黑色
③ 行星在食甚时可见
④ 日冕精灵尺寸为太阳半径 2-3 倍 |
| **天文依据** | 日全食：月球角直径 ≥ 太阳角直径 |
