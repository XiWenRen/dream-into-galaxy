# 天卫一 (Ariel) 星空观测验证用例

**观测者星体**: Ariel (天卫一) — 天王星最靠近的主要卫星之一  
**无固体表面**: 有（岩石+冰壳，地质活跃）  
**大气状态**: 无显著大气  
**母行星**: Uranus (天王星)  

## 星体基本参数

| 参数 | 数值 |
|------|------|
| 距天王星中心 | 190,900 km |
| 距天王星表面 | 约 140,000 km |
| 天王星角直径（从 Ariel 看） | 约 **19.0°**（地球上看月球的 **38 倍**！） |
| 天王星视星等（从 Ariel 看） | 约 -20.0（比满月亮约 400 倍） |
| 自转周期 | 2.52 地球日（同步自转） |
| 公转周期 | 2.52 地球日 |
| 表面温度 | -213°C |

## 测试用例

### TC-ARIEL-DOM-01：Ariel 面向面观测天王星

| 字段 | 内容 |
|------|------|
| **TC-ID** | `ARIEL-DOM-01` |
| **观测位置** | (0°N, 0°E) — Ariel 面向天王星面中央 |
| **模拟时间** | 任意 |
| **太阳状态** | 视轨道位置 |
| **主导天体** | **天王星**：潮汐锁定 → 固定在天空。角直径约 **19.0°**（月球 **38 倍**！），视星等 **-20.0**（满月亮 **400 倍**！）。
这是太阳系中最壮观的天王星视角！ |
| **预期可见天体清单** | **天王星**：Az ≈ 180°，Alt ≈ 90°，角直径 ≈ 19.0°，视星等 ≈ -20.0
天王星青蓝色圆盘占据巨大天空面积 |
| **预期不可见天体** | 恒星（被天王星强光淹没） |
| **星座/深空天体** | 无 |
| **特殊天象** | 从 Ariel 看天王星是太阳系中最壮观的天王星视角：19° 直径 = 38 倍满月！ |
| **环境条件** | 无大气；极低温 -213°C；天王星极端强光 |
| **校验点** | ① 天王星角直径 ≈ 19.0°（约 20°）
② 天王星视星等 ≈ -20.0
③ 天王星颜色青蓝色
④ 天王星云带（若模拟）应可见 |
| **天文依据** | Ariel a=190,900 km；天王星半径 25,362 km；角直径 = 2×arcsin(25362/190900) ≈ 19.0° |
