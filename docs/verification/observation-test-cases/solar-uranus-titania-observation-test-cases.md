# 天卫三 (Titania) 星空观测验证用例

**观测者星体**: Titania (天卫三) — 天王星最大的卫星  
**无固体表面**: 有（岩石+冰壳）  
**大气状态**: 无显著大气  
**母行星**: Uranus (天王星)  

## 星体基本参数

| 参数 | 数值 |
|------|------|
| 距天王星中心 | 435,910 km |
| 距天王星表面 | 约 385,000 km |
| 天王星角直径（从 Titania 看） | 约 8.5°（地球上看月球的 **17 倍**） |
| 天王星视星等（从 Titania 看） | 约 -16.5（比满月亮约 30 倍） |
| 自转周期 | 8.71 地球日（同步自转） |
| 公转周期 | 8.71 地球日 |
| 表面温度 | -210°C |

## 测试用例

### TC-TITANIA-DOM-01：Titania 面向面观测天王星

| 字段 | 内容 |
|------|------|
| **TC-ID** | `TITANIA-DOM-01` |
| **观测位置** | (0°N, 0°E) — Titania 面向天王星面中央 |
| **模拟时间** | 任意 |
| **太阳状态** | 视轨道位置 |
| **主导天体** | **天王星**：潮汐锁定 → 固定在天空。角直径约 **8.5°**（月球 17 倍），视星等 **-16.5**（满月亮 30 倍）。
天王星呈青蓝色大圆盘（甲烷大气吸收红光）。 |
| **预期可见天体清单** | **天王星**：Az ≈ 180°，Alt ≈ 90°，角直径 ≈ 8.5°，视星等 ≈ -16.5
天王星青蓝色圆盘清晰可见 |
| **预期不可见天体** | 恒星（被天王星强光淹没） |
| **星座/深空天体** | 无 |
| **特殊天象** | 天王星在 Titania 天空中呈美丽青蓝色（甲烷大气特征色） |
| **环境条件** | 无大气；极低温 -210°C；天王星强光 |
| **校验点** | ① 天王星角直径 ≈ 8.5°
② 天王星视星等 ≈ -16.5
③ 天王星颜色青蓝色（#40A0A0）
④ 无恒星可见 |
| **天文依据** | Titania a=435,910 km；天王星半径 25,362 km；角直径 = 2×arcsin(25362/435910) ≈ 8.45° |

### TC-TITANIA-NIGHT-01：Titania 背向面夜间

| 字段 | 内容 |
|------|------|
| **TC-ID** | `TITANIA-NIGHT-01` |
| **观测位置** | (0°N, 180°E) — Titania 背向面 |
| **模拟时间** | 子夜 |
| **太阳状态** | 地平下 |
| **主导天体** | 天王星：不可见 |
| **预期可见天体清单** | **恒星**：极清晰（无大气）
**行星**：木星、土星、海王星 |
| **预期不可见天体** | 天王星 |
| **星座/深空天体** | 全部可见 |
| **特殊天象** | 背向面是理想观测点 |
| **环境条件** | 无大气；纯黑天空 |
| **校验点** | ① 天王星不可见
② 星空极清晰 |
| **天文依据** | 潮汐锁定 |
