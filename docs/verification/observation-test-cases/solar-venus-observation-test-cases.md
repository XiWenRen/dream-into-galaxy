# 金星 (Venus) 星空观测验证用例

**观测者星体**: Venus (金星)  
**无固体表面**: 有（岩石行星，有固体表面）  
**大气状态**: 浓密 CO₂ 大气（气压 93 bar = 地球 92 倍）  
**卫星数量**: 0  

## 星体基本参数

| 参数 | 数值 |
|------|------|
| 距太阳平均距离 | 0.723 AU (108.2×10⁶ km) |
| 太阳角直径（平均） | 0.73°（地球上看太阳的 1.4 倍） |
| 太阳视星等（平均） | -27.4（比地球亮 1.6 倍） |
| 自转周期 | 243 地球日（逆向自转，比公转还慢） |
| 公转周期 | 225 地球日 |
| 一个"金星日"（太阳两次上中天） | 约 116.8 地球日 |
| 自转轴倾角 | 177.4°（逆向，几乎完全倒置） |
| 表面温度 | 约 465°C（全球均匀，温室效应） |
| 大气成分 | CO₂ 96.5%，N₂ 3.5%，H₂SO₄ 云层 |
| 可见光光学深度 | τ > 100（表面完全看不到太阳/星空） |
| 云层顶部高度 | 约 60-70 km（气压 ~0.1-1 bar） |

## 测试用例

### TC-VENUS-DAY-01：金星表面正午（永远看不到清晰太阳）

| 字段 | 内容 |
|------|------|
| **TC-ID** | `VENUS-DAY-01` |
| **观测位置** | (0°N, 0°E) — 金星赤道 |
| **模拟时间** | 金星当地正午 |
| **太阳状态** | 太阳在金星表面不可直接看见！浓密大气和硫酸云层完全遮挡太阳；到达表面的光为漫射光（类似阴天） |
| **主导天体** | 无（金星无卫星） |
| **预期可见天体清单** | **无**（表面无可见天体） |
| **预期不可见天体** | 太阳（被大气完全遮挡，仅漫射光到达表面）
恒星（被大气完全遮挡）
行星（被大气完全遮挡） |
| **星座/深空天体** | 无 |
| **特殊天象** | 金星表面永远看不到太阳圆盘，光照类似地球阴天；太阳位置仅能通过亮度变化和方向粗略判断 |
| **环境条件** | 浓密 CO₂ + H₂SO₄ 大气：
• 气压 93 bar
• 光学深度 τ > 100（可见光完全无法穿透）
• 天空呈永恒橙黄色/黄褐色（CO₂ 和硫酸液滴散射）
• 表面温度 465°C（全球均匀，无昼夜温差） |
| **校验点** | ① 金星表面不应渲染任何天体（太阳、恒星、行星均不可见）
② 天空背景应为均匀的橙黄色/黄褐色（#D4A574 ~ #C4956A），无特征
③ 无曙暮光/日夜过渡效果（大气散射极强，表面永远均匀照亮）
④ 环境光亮度均匀，无明确光源方向 |
| **天文依据** | 金星大气光学深度 τ ≈ 100+；Venera 着陆器数据显示表面光照均匀、无阴影 |

### TC-VENUS-ATM-01：金星云层顶部（约 60 km）观测

| 字段 | 内容 |
|------|------|
| **TC-ID** | `VENUS-ATM-01` |
| **观测位置** | (0°N, 0°E) — 金星云层顶部（约 60 km 高度，气压 ~0.1 bar） |
| **模拟时间** | 金星当地正午 |
| **太阳状态** | 太阳在云层顶部可见！但呈模糊白色圆盘（被高层云散射），角直径 ≈ 0.73°，视星等 ≈ -27.4 |
| **主导天体** | 无 |
| **预期可见天体清单** | **太阳**：模糊白色圆盘（无清晰边缘），角直径 0.73°，视星等 -27.4，周围有强烈散射光晕
**地球**：若位于夜天方向，可能极暗可见（视星等约 -2.5） |
| **预期不可见天体** | 恒星（被云层散射淹没）
行星（除地球外均不可见） |
| **星座/深空天体** | 无 |
| **特殊天象** | 金星逆向自转 → 太阳从**西边升起、东边落下**（如果能在表面看到的话） |
| **环境条件** | 云层顶部：气压 0.1-1 bar，温度约 -20°C 到 30°C；浓密云层，可见光散射强；天空呈黄白色 |
| **校验点** | ① 云层顶部太阳应可见但边缘模糊（散射效应）
② 太阳周围应有强烈光晕（云层散射）
③ 无恒星可见（云层仍太厚）
④ 天空颜色为黄白色（#F5E6C8），非蓝色也非黑色 |
| **天文依据** | 金星云层顶部（~60 km）光学深度约 1-10；Pioneer Venus 和 Akatsuki 任务成像 |

### TC-VENUS-HIGH-01：金星高空（约 80 km）观测星空

| 字段 | 内容 |
|------|------|
| **TC-ID** | `VENUS-HIGH-01` |
| **观测位置** | (0°N, 0°E) — 金星 80 km 高空（气压 ~0.01 bar，大气极稀薄） |
| **模拟时间** | 金星子夜 |
| **太阳状态** | 在地平线以下（子夜），完全不可见 |
| **主导天体** | 无 |
| **预期可见天体清单** | **地球**：视星等约 -2.5，呈蓝白色亮点（金星上看地球为内行星，类似从地球看金星）
**水星**：视星等约 -1.0（若位于夜天）
**木星**：视星等约 -1.5
**恒星**：可见！但受残余大气散射影响，极限星等约 3-4 等（不如地面清晰） |
| **预期不可见天体** | 太阳（地平下） |
| **星座/深空天体** | 黄道带星座可见 |
| **特殊天象** | 金星逆向自转：若从高空看到太阳，太阳从西边升起 |
| **环境条件** | 80 km 高度：气压极低（~0.01 bar），但仍有少量散射；温度约 -100°C；接近真空但仍非完全透明 |
| **校验点** | ① 高空应可见亮恒星和行星（极限星等约 3-4）
② 地球应作为最亮行星之一可见
③ 天空背景趋近黑色但非纯黑（残余散射）
④ 金星逆向自转：太阳运动方向与大多数行星相反 |
| **天文依据** | 金星大气标高约 15 km；80 km 处大气密度约为表面 0.001% |

### TC-VENUS-SURFACE-01：金星地表"夜间"（实际永远均匀照亮）

| 字段 | 内容 |
|------|------|
| **TC-ID** | `VENUS-SURFACE-01` |
| **观测位置** | (0°N, 0°E) — 金星赤道表面 |
| **模拟时间** | 金星子夜（太阳在反方向） |
| **太阳状态** | 太阳在反方向地平线以下，但浓密大气散射使表面仍被均匀照亮（类似地球阴天正午） |
| **主导天体** | 无 |
| **预期可见天体清单** | **无**（表面永远看不到任何天体） |
| **预期不可见天体** | 全部天体（被 93 bar CO₂ 大气完全遮挡） |
| **星座/深空天体** | 无 |
| **特殊天象** | 金星表面无"夜晚"概念：即使太阳在反方向，大气散射仍使全球均匀照亮，表面温度永远 465°C |
| **环境条件** | 永恒均匀光照；永恒 465°C；永恒橙黄色天空；无昼夜变化；无季节变化（自转轴倾角 177° 但无季节） |
| **校验点** | ① 金星表面任何时刻天空亮度应相同（无昼夜变化）
② 天空颜色永远为橙黄色（#D4A76A ~ #C4956A）
③ 不应有"夜间"模式（恒星不可见）
④ 不应有曙暮光效果 |
| **天文依据** | Venera 13/14 着陆器数据：表面光照均匀，无昼夜变化；温度恒定在 455-475°C |
