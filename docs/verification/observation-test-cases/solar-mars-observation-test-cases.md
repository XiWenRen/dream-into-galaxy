# 火星 (Mars) 星空观测验证用例

**观测者星体**: Mars (火星)  
**无固体表面**: 有  
**大气状态**: 稀薄 CO₂ 大气（气压 0.006 bar = 地球 0.6%）  
**卫星数量**: 2（Phobos 火卫一、Deimos 火卫二）  

## 星体基本参数

| 参数 | 数值 |
|------|------|
| 距太阳平均距离 | 1.524 AU (227.9×10⁶ km) |
| 太阳角直径 | 0.35°（地球上看太阳的 2/3） |
| 太阳视星等 | -25.9（比地球暗 1.7 倍） |
| 自转周期 | 24h 37m 22s（火星日 = Sol） |
| 自转轴倾角 | 25.2°（类似地球，有季节变化） |
| 卫星 Phobos 轨道距离 | 9,377 km |
| 卫星 Deimos 轨道距离 | 23,460 km |
| 表面温度 | -80°C ~ 20°C |
| 大气成分 | CO₂ 95.3%，N₂ 2.7%，Ar 1.6% |
| 可见光大气光学深度 | τ ≈ 0.3-1.0（沙尘暴时可达 τ > 5） |

## 测试用例

### TC-MARS-DAY-01：火星正午观测太阳

| 字段 | 内容 |
|------|------|
| **TC-ID** | `MARS-DAY-01` |
| **观测位置** | (0°N, 0°E) — 火星赤道 |
| **模拟时间** | 火星春分正午 |
| **太阳状态** | 上中天，Az = 180°，Alt ≈ 90° - 纬度 = 90°（赤道），角直径 ≈ 0.35°，视星等 ≈ -25.9 |
| **主导天体** | **Phobos（火卫一）**：可能快速掠过天空（周期 7.7h < 火星自转周期 24.6h）
**Deimos（火卫二）**：缓慢移动（周期 30.3h > 火星自转周期） |
| **预期可见天体清单** | **太阳**：Az 180°，Alt ≈ 90°（赤道），角直径 0.35°（比地球上看小 1/3），视星等 -25.9，呈蓝白色（大气散射较少）
**Phobos**：若位于可见天区，角直径约 0.14°，视星等约 -6.0（比满月亮 5 倍！），形状不规则，快速西升东落 |
| **预期不可见天体** | 恒星（白天被日光+大气尘埃散射淹没）
行星（被日光淹没） |
| **星座/深空天体** | 无 |
| **特殊天象** | 火星太阳日（Sol）= 24h 37m，比地球日长约 39 分钟 |
| **环境条件** | 稀薄 CO₂ + 氧化铁尘埃大气：
• 天空呈粉红色/橙红色（尘埃散射红光）
• 太阳周围有蓝色光晕（尘埃散射蓝光向前）
• 地平线附近天空偏白/黄褐色 |
| **校验点** | ① 太阳角直径 ≈ 0.35° ± 0.05°（近日点 0.47°，远日点 0.30°）
② 太阳视星等 ≈ -25.9（比地球太阳暗约 1.7 倍）
③ 天空颜色为粉红色/橙红色（#E8A090 ~ #D08060），非蓝色
④ 太阳周围有蓝色光晕（火星独特现象）
⑤ Phobos 若可见，应呈现不规则形状 |
| **天文依据** | 火星轨道 e=0.093；火星探测器（Curiosity、Perseverance）图像确认粉红色天空和蓝色日晕 |

### TC-MARS-NIGHT-01：火星子夜观测星空

| 字段 | 内容 |
|------|------|
| **TC-ID** | `MARS-NIGHT-01` |
| **观测位置** | (0°N, 0°E) — 火星赤道 |
| **模拟时间** | 火星子夜 |
| **太阳状态** | 地平下约 -90°（赤道子夜） |
| **主导天体** | **Phobos**：可能在地平线上（取决于轨道相位），快速移动
**Deimos**：可能在天空中缓慢移动 |
| **预期可见天体清单** | **地球**：视星等约 -1.5（从火星看地球是内行星），呈蓝白色亮点
**金星**：视星等约 -3.0（若位于夜天）
**木星**：视星等约 -2.0
**土星**：视星等约 +0.5
**Phobos**：视星等约 -6.0（比满月亮 5 倍！），角直径 0.14°，快速西升东落（周期 7.7h）
**Deimos**：视星等约 -3.0，角直径 0.03°，缓慢移动（周期 30.3h）
**全部恒星**：可见！稀薄大气消光小，极限星等约 6.0（比地球略好） |
| **预期不可见天体** | 太阳（地平下） |
| **星座/深空天体** | 所有星座可见；黄道带星座中地球和金星作为"晨星/昏星"可见 |
| **特殊天象** | 火星上看地球：呈蓝白色亮星，类似从地球看金星；可通过地球反照光看到地球圆盘和月球 |
| **环境条件** | 稀薄大气：夜间星空清晰，但比水星/月球略差（仍有微弱散射）；温度极低（-80°C） |
| **校验点** | ① 地球应作为明亮内行星可见（m ≈ -1.5，类似从地球看金星）
② Phobos 应在数小时内完成西升东落（周期 7.7h）
③ Deimos 应在约 30 小时内缓慢绕圈（周期 30.3h）
④ 恒星可见，但可能有微弱闪烁（大气稀薄但仍有湍流）
⑤ 天空背景趋近黑色但非纯黑（残余大气散射） |
| **天文依据** | Phobos 轨道周期 7.66h < 火星自转 24.6h → 西升东落；Deimos 轨道周期 30.35h > 火星自转 → 东升西落但缓慢 |

### TC-MARS-PHOBOS-01：观测火卫一（Phobos）快速横越天空

| 字段 | 内容 |
|------|------|
| **TC-ID** | `MARS-PHOBOS-01` |
| **观测位置** | (0°N, 0°E) — 火星赤道 |
| **模拟时间** | Phobos 上中天时刻 |
| **太阳状态** | 假设为火星白天 |
| **主导天体** | **Phobos**：从火星看角直径约 0.14°（约 8.4 角分，小于月球的 1/3），视星等约 -6.0，形状不规则（27×22×18 km），表面布满陨石坑 |
| **预期可见天体清单** | **Phobos**：快速从西方升起、东方落下（周期仅 7.7h），在天空中移动速度约为月球的 3 倍
Phobos 表面细节可能可见（陨石坑、不规则形状）
Phobos 呈现相位变化（被太阳照射的部分变化） |
| **预期不可见天体** | Deimos（可能位于另一侧天空） |
| **星座/深空天体** | 无（白天） |
| **特殊天象** | Phobos 轨道在火星同步轨道以内（9,377 km < 同步轨道 20,400 km），因此轨道周期 < 火星自转周期 → **西升东落**（与大多数天体相反）
Phobos 正在逐渐靠近火星（潮汐减速），最终约 5000 万年后将撞上火星或形成环 |
| **环境条件** | 白天；粉红色天空；Phobos 在日光下呈灰色/棕灰色 |
| **校验点** | ① Phobos 角直径 ≈ 0.14°（月球 1/3）
② Phobos 西升东落（与太阳/恒星方向相反）
③ Phobos 在约 4 小时内从地平线一侧移动到另一侧（半天球跨越）
④ Phobos 呈现不规则形状（非完美圆形）
⑤ Phobos 视星等约 -6.0（比满月亮 5 倍） |
| **天文依据** | Phobos a=9,377 km，尺寸 27×22×18 km，角直径 ≈ arcsin(27/9377) ≈ 0.165° max；轨道周期 7.66h |

### TC-MARS-DEIMOS-01：观测火卫二（Deimos）缓慢移动

| 字段 | 内容 |
|------|------|
| **TC-ID** | `MARS-DEIMOS-01` |
| **观测位置** | (0°N, 0°E) — 火星赤道 |
| **模拟时间** | Deimos 上中天时刻 |
| **太阳状态** | 火星白天或夜间 |
| **主导天体** | **Deimos**：从火星看角直径约 0.03°（约 2 角分，类似恒星），视星等约 -3.0，形状不规则（15×12×11 km） |
| **预期可见天体清单** | **Deimos**：缓慢东升西落（周期 30.3h，略大于火星日 24.6h），在天空中移动极慢（约 2-3 天完成一次完整的东升西落）
Deimos 呈现相位变化 |
| **预期不可见天体** | Phobos（可能位于另一侧） |
| **星座/深空天体** | 夜间可见 |
| **特殊天象** | Deimos 轨道在火星同步轨道以内但接近（23,460 km < 同步轨道 20,400 km...等等，23,460 > 20,400，所以 Deimos 实际上在同步轨道之外？让我重新计算。

火星同步轨道 = (GM/ω²)^(1/3)
火星质量 M = 6.42×10²³ kg
火星自转角速度 ω = 2π/(24.6×3600) = 7.09×10⁻⁵ rad/s
同步轨道半径 = (6.67×10⁻¹¹ × 6.42×10²³ / (7.09×10⁻⁵)²)^(1/3)
= (4.28×10¹³ / 5.03×10⁻⁹)^(1/3)
= (8.51×10²¹)^(1/3)
= 2.04×10⁷ m = 20,400 km

Deimos 轨道 23,460 km > 同步轨道 20,400 km
所以 Deimos 轨道周期 30.3h > 火星自转 24.6h
因此 Deimos **东升西落**，但比太阳慢（每天落后约 5.7h）

让我修正。 |
| **特殊天象** | Deimos 轨道在火星同步轨道**之外**（23,460 km > 20,400 km），轨道周期 30.3h > 火星自转 24.6h → **东升西落**，但比太阳慢（每天落后约 5.7 小时） |
| **环境条件** | 白天/夜间均可观测 |
| **校验点** | ① Deimos 角直径 ≈ 0.03°（约 2 角分，类似点状）
② Deimos 东升西落但极慢（约 2-3 天完成一次完整起落循环）
③ Deimos 视星等约 -3.0（与木星从地球看相当）
④ Deimos 呈不规则形状，但角直径小难以分辨 |
| **天文依据** | Deimos a=23,460 km，尺寸 15×12×11 km，角直径 ≈ arcsin(15/23460) ≈ 0.037°；轨道周期 30.35h |

### TC-MARS-DUST-01：火星全球性沙尘暴期间观测

| 字段 | 内容 |
|------|------|
| **TC-ID** | `MARS-DUST-01` |
| **观测位置** | (0°N, 0°E) — 火星赤道 |
| **模拟时间** | 全球性沙尘暴期间（如 2018 年、2001 年） |
| **太阳状态** | 太阳在天空中可见但极度昏暗，呈淡蓝色小圆盘（尘埃散射红光、透蓝光） |
| **主导天体** | Phobos、Deimos — 可能不可见或被极度衰减 |
| **预期可见天体清单** | **太阳**：极度昏暗，呈淡蓝色（尘埃前向散射蓝光），角直径仍 0.35°，但亮度下降 2-3 个星等
**无恒星可见**
**无卫星可见** |
| **预期不可见天体** | 恒星（被沙尘完全淹没）
Phobos、Deimos（被沙尘淹没）
行星（被沙尘淹没） |
| **星座/深空天体** | 无 |
| **特殊天象** | 全球性沙尘暴：太阳变暗、天空变为深红褐色、地表光照降至地球的 1%；沙尘可持续数月 |
| **环境条件** | 沙尘暴期间大气光学深度 τ 可达 3-10（极端情况下）：
• 天空变为深红褐色/铁锈色（#8B4513 ~ #A0522D）
• 太阳呈淡蓝色（类似地球阴天）
• 地表光照极弱 |
| **校验点** | ① 太阳亮度下降 > 50%（τ > 1 时）
② 天空颜色变为深红褐色（沙尘散射特征）
③ 太阳颜色偏蓝（与晴天相反）
④ 无恒星可见（极限星等降至 < 0）
⑤ Phobos/Deimos 不可见 |
| **天文依据** | 火星沙尘暴光学深度：区域性 τ ~ 1-3，全球性 τ ~ 3-10；Mariner 9、Mars Global Surveyor 数据 |
