# 木卫一 (Io) 星空观测验证用例

**观测者星体**: Io (木卫一) — 木星的第一颗伽利略卫星  
**无固体表面**: 有（岩石+硫化物表面）  
**大气状态**: 极稀薄 SO₂ 大气（表面气压 ~10⁻¹⁰ bar）  
**母行星**: Jupiter (木星)  

## 星体基本参数

| 参数 | 数值 |
|------|------|
| 距木星中心 | 421,700 km |
| 距木星表面 | 约 350,000 km |
| 木星角直径（从 Io 看） | 约 19.6°（地球上看月球的 **39 倍**！） |
| 木星视星等（从 Io 看） | 约 -21.5（比满月亮约 1500 倍！） |
| 自转周期 | 1.77 地球日（同步自转，潮汐锁定） |
| 公转周期 | 1.77 地球日 |
| 表面温度 | -180°C ~ +1,600°C（火山活动区） |
| 大气成分 | SO₂ 极稀薄大气 |

## 测试用例

### TC-IO-DOM-01：Io 面向面观测木星

| 字段 | 内容 |
|------|------|
| **TC-ID** | `IO-DOM-01` |
| **观测位置** | (0°N, 0°E) — Io 面向木星面中央 |
| **模拟时间** | 任意（木星固定在天空） |
| **太阳状态** | 视轨道位置 |
| **主导天体** | **木星**：由于潮汐锁定，木星在 Io 面向面的天空中**几乎固定不动**。
木星角直径约 **19.6°**（地球上看月球的 **39 倍**！），视星等约 **-21.5**（比满月亮约 **1500 倍**！）。
木星呈巨大黄白色/棕色条纹圆盘，赤道云带（棕色/白色交替）和著名的大红斑清晰可见。
木星占据天空巨大面积，是天空中最壮观的天体。 |
| **预期可见天体清单** | **木星**：Az ≈ 180°，Alt ≈ 90°（赤道中央），角直径 ≈ 19.6°，视星等 ≈ -21.5
木星条纹云带：棕色赤道带、白色区清晰可见
大红斑：若面向，应可见为椭圆形红斑（约 3° × 1.5° 从 Io 看）
木星四颗主要卫星（包括 Io 自身倒影？不，Io 在木星表面不可见） |
| **预期不可见天体** | 恒星（被木星强光淹没）
行星（被木星强光淹没） |
| **星座/深空天体** | 无（木星太亮） |
| **特殊天象** | 木星在 Io 天空中占据约 **19.6°**，这意味着木星视面积约为满月的 **1500 倍**！
从 Io 看，木星比从地球看太阳还要大 37 倍！ |
| **环境条件** | 极稀薄 SO₂ 大气 → 无显著散射；木星强光主导；表面火山活动频繁 |
| **校验点** | ① 木星 Az 变化 < 5°（潮汐锁定）
② 木星角直径 ≈ 19.6°（约 20°）
③ 木星视星等 ≈ -21.5
④ 木星条纹云带应可见（至少 2-3 条主要云带）
⑤ 大红斑若在视野中应可见
⑥ 天空背向木星方向应为纯黑 |
| **天文依据** | Io 轨道 a=421,700 km；木星赤道半径 71,492 km；角直径 = 2×arcsin(71492/421700) ≈ 19.5° |

### TC-IO-VOLCANO-01：Io 火山活动期间观测

| 字段 | 内容 |
|------|------|
| **TC-ID** | `IO-VOLCANO-01` |
| **观测位置** | 火山活动区附近 |
| **模拟时间** | 火山喷发期间 |
| **太阳状态** | 任意 |
| **主导天体** | **木星**：固定在天空 |
| **预期可见天体清单** | **木星**：巨大圆盘
**火山喷发羽流**：SO₂ 羽流可达数百公里高，在夜空中可能可见为黄色/橙色光柱
**熔岩流**：夜间可能发出暗红色光芒 |
| **预期不可见天体** | 恒星（白天被木星/太阳光淹没；夜间可能被火山光干扰） |
| **星座/深空天体** | 夜间无木星强光方向可见 |
| **特殊天象** | Io 是太阳系火山最活跃的天体，有 400+ 座活火山；火山羽流在阳光下可见为巨大光柱 |
| **环境条件** | 火山活动频繁；硫黄表面（黄/橙/红色）；极稀薄大气 |
| **校验点** | ① 火山喷发若模拟应可见
② 木星始终固定在天空
③ 天空颜色受火山活动影响（SO₂ 大气可能有微弱散射） |
| **天文依据** | Io 火山由潮汐加热驱动；New Horizons、Galileo 任务观测到巨大火山羽流 |

### TC-IO-SAT-01：从 Io 观测其他伽利略卫星

| 字段 | 内容 |
|------|------|
| **TC-ID** | `IO-SAT-01` |
| **观测位置** | (0°N, 0°E) — Io 面向木星面 |
| **模拟时间** | 其他卫星位于 Io 可见天区时 |
| **太阳状态** | 任意 |
| **主导天体** | **木星**：固定在天空 |
| **预期可见天体清单** | **Europa（木卫二）**：从 Io 看角直径约 0.5-1.0°，视星等约 -5.0，快速移动（轨道周期 3.55 日）
**Ganymede（木卫三）**：角直径约 0.3-0.6°，视星等约 -4.0
**Callisto（木卫四）**：角直径约 0.2-0.4°，视星等约 -3.0 |
| **预期不可见天体** | 恒星（被木星强光淹没） |
| **星座/深空天体** | 无 |
| **特殊天象** | 其他伽利略卫星在 Io 天空中快速移动，呈现相位变化 |
| **环境条件** | 木星强光主导；极稀薄大气 |
| **校验点** | ① Europa 应作为明亮天体可见（m ≈ -5）
② 其他卫星应呈现圆盘面（角直径 > 0.1°）
③ 卫星应有明确轨道运动 |
| **天文依据** | 伽利略卫星轨道：Europa a=671,000 km，Ganymede a=1,070,000 km，Callisto a=1,883,000 km |
