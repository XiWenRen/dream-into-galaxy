# 海卫一 (Triton) 星空观测验证用例

**观测者星体**: Triton (海卫一) — 海王星最大的卫星，逆行轨道  
**无固体表面**: 有（氮冰+水冰表面）  
**大气状态**: 极稀薄 N₂ 大气（表面气压 ~10⁻⁵ bar）  
**母行星**: Neptune (海王星)  

## 星体基本参数

| 参数 | 数值 |
|------|------|
| 距海王星中心 | 354,760 km |
| 距海王星表面 | 约 306,000 km |
| 海王星角直径（从 Triton 看） | 约 7.2°（地球上看月球的 **14 倍**） |
| 海王星视星等（从 Triton 看） | 约 -17.0（比满月亮约 50 倍） |
| 自转周期 | 5.88 地球日（同步自转） |
| 公转周期 | 5.88 地球日 |
| 轨道倾角 | 157°（逆行轨道，相对于海王星赤道） |
| 表面温度 | -235°C |

## 测试用例

### TC-TRITON-DOM-01：Triton 面向面观测海王星

| 字段 | 内容 |
|------|------|
| **TC-ID** | `TRITON-DOM-01` |
| **观测位置** | (0°N, 0°E) — Triton 面向海王星面中央 |
| **模拟时间** | 任意 |
| **太阳状态** | 视轨道位置 |
| **主导天体** | **海王星**：潮汐锁定 → 固定在天空。角直径约 **7.2°**（月球 14 倍），视星等 **-17.0**（满月亮 50 倍）。
海王星呈深蓝色大圆盘（甲烷大气）。 |
| **预期可见天体清单** | **海王星**：Az ≈ 180°，Alt ≈ 90°，角直径 ≈ 7.2°，视星等 ≈ -17.0
海王星深蓝色圆盘 |
| **预期不可见天体** | 恒星（被海王星强光淹没） |
| **星座/深空天体** | 无 |
| **特殊天象** | Triton 逆行轨道且倾角大（157°），从 Triton 看海王星高纬度区域 |
| **环境条件** | 极稀薄 N₂ 大气；极低温 -235°C；海王星强光 |
| **校验点** | ① 海王星角直径 ≈ 7.2°
② 海王星视星等 ≈ -17.0
③ 海王星颜色深蓝色（#1A3A5A）
④ 无恒星可见 |
| **天文依据** | Triton a=354,760 km；海王星半径 24,622 km；角直径 = 2×arcsin(24622/354760) ≈ 7.15° |

### TC-TRITON-GEYSER-01：Triton 冰火山活动观测

| 字段 | 内容 |
|------|------|
| **TC-ID** | `TRITON-GEYSER-01` |
| **观测位置** | Triton 极区 |
| **模拟时间** | 冰火山活动期间 |
| **太阳状态** | 任意 |
| **主导天体** | **海王星**：固定在天空 |
| **预期可见天体清单** | **海王星**：巨大深蓝色圆盘
**氮气喷射羽流**：从表面喷射，高达 8 km，在阳光下可见 |
| **预期不可见天体** | 恒星 |
| **星座/深空天体** | 无 |
| **特殊天象** | Triton 有冰火山（cryovolcanism），喷射氮气和尘埃 |
| **环境条件** | 极低温 -235°C；氮冰表面 |
| **校验点** | ① 喷射羽流若模拟应可见
② 海王星始终固定在天空 |
| **天文依据** | Voyager 2 发现 Triton 冰火山喷射；羽流高达 8 km |

### TC-TRITON-RETROGRADE-01：Triton 逆行轨道效果

| 字段 | 内容 |
|------|------|
| **TC-ID** | `TRITON-RETROGRADE-01` |
| **观测位置** | (0°N, 0°E) — Triton 表面 |
| **模拟时间** | 任意 |
| **太阳状态** | 视位置 |
| **主导天体** | **海王星**：固定在天空 |
| **预期可见天体清单** | **海王星**：固定在天空
**太阳**：运动方向与大多数卫星相反（由于逆行轨道） |
| **预期不可见天体** | 无 |
| **星座/深空天体** | 背向面可见 |
| **特殊天象** | Triton 逆行轨道意味着从 Triton 看，太阳和其他天体运动方向与"正常"方向相反 |
| **环境条件** | 逆行轨道无特殊环境差异 |
| **校验点** | ① 海王星固定在天空
② 太阳视运动方向与顺行卫星相反（若系统模拟） |
| **天文依据** | Triton 轨道倾角 157°（逆行）；可能是被海王星捕获的柯伊伯带天体 |
