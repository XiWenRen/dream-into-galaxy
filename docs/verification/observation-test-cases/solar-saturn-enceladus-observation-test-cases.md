# 土卫二 (Enceladus) 星空观测验证用例

**观测者星体**: Enceladus (土卫二) — 土星的小型卫星，南极有水冰喷射  
**无固体表面**: 有（水冰表面，反照率极高）  
**大气状态**: 极稀薄水蒸气大气  
**母行星**: Saturn (土星)  

## 星体基本参数

| 参数 | 数值 |
|------|------|
| 距土星中心 | 238,020 km |
| 距土星表面 | 约 122,000 km |
| 土星角直径（从 Enceladus 看） | 约 **18.8°**（地球上看月球的 **37 倍**！） |
| 土星视星等（从 Enceladus 看） | 约 -19.0（比满月亮约 400 倍） |
| 土星环角直径（从 Enceladus 看） | 约 35-40°（横跨大半天空！） |
| 自转周期 | 1.37 地球日（同步自转） |
| 公转周期 | 1.37 地球日 |
| 表面温度 | -198°C |
| 表面反照率 | 0.99+（太阳系最高之一） |

## 测试用例

### TC-ENCELADUS-DOM-01：Enceladus 面向面观测土星

| 字段 | 内容 |
|------|------|
| **TC-ID** | `ENCELADUS-DOM-01` |
| **观测位置** | (0°N, 0°E) — Enceladus 面向土星面中央 |
| **模拟时间** | 任意 |
| **太阳状态** | 视轨道位置 |
| **主导天体** | **土星**：潮汐锁定 → 固定在天空。角直径约 **18.8°**（月球 **37 倍**！），视星等约 **-19.0**（满月亮 **400 倍**！）。
土星环角直径约 **35-40°**，横跨大半天空！
这是太阳系中最壮观的土星视角之一。 |
| **预期可见天体清单** | **土星**：Az ≈ 180°，Alt ≈ 90°，角直径 ≈ 18.8°，视星等 ≈ -19.0
**土星环**：角直径 35-40°，横跨天空！
**卡西尼缝**：在巨大环面上可见为暗带 |
| **预期不可见天体** | 恒星（土星强光淹没）
行星 |
| **星座/深空天体** | 无 |
| **特殊天象** | 从 Enceladus 看土星是太阳系中最壮观的行星视角之一：土星占据近 20°，环系统横跨 40°！ |
| **环境条件** | 极亮冰面（反照率 0.99）；极稀薄大气；土星极端强光 |
| **校验点** | ① 土星角直径 ≈ 18.8°（约 20°）
② 土星视星等 ≈ -19.0
③ 土星环角直径 > 35°（横跨大半天空）
④ 卡西尼缝可见 |
| **天文依据** | Enceladus a=238,020 km；土星半径 60,268 km；角直径 = 2×arcsin(60268/238020) ≈ 18.8° |

### TC-ENCELADUS-PLUME-01：Enceladus 南极水冰喷射观测

| 字段 | 内容 |
|------|------|
| **TC-ID** | `ENCELADUS-PLUME-01` |
| **观测位置** | Enceladus 南极 |
| **模拟时间** | 喷射活动期间 |
| **太阳状态** | 任意 |
| **主导天体** | **土星**：固定在天空 |
| **预期可见天体清单** | **土星**：巨大圆盘
**水冰喷射羽流**：从南极裂缝喷射，高达数百公里，在阳光下可见为明亮光柱 |
| **预期不可见天体** | 恒星 |
| **星座/深空天体** | 无 |
| **特殊天象** | Enceladus 南极"虎纹"裂缝喷射水冰和有机分子，形成土星 E 环的主要物质来源 |
| **环境条件** | 极低温 -198°C；冰面；土星强光 |
| **校验点** | ① 喷射羽流若模拟应可见
② 土星始终巨大 |
| **天文依据** | Cassini 任务发现 Enceladus 南极喷射；羽流含 H₂O、CO₂、CH₄、NH₃ |
