# 木卫二 (Europa) 星空观测验证用例

**观测者星体**: Europa (木卫二) — 木星的第二颗伽利略卫星  
**无固体表面**: 有（冰壳表面）  
**大气状态**: 极稀薄 O₂ 大气（表面气压 ~10⁻¹² bar）  
**母行星**: Jupiter (木星)  

## 星体基本参数

| 参数 | 数值 |
|------|------|
| 距木星中心 | 671,034 km |
| 距木星表面 | 约 600,000 km |
| 木星角直径（从 Europa 看） | 约 12.2°（地球上看月球的 **24 倍**） |
| 木星视星等（从 Europa 看） | 约 -20.5（比满月亮约 500 倍） |
| 自转周期 | 3.55 地球日（同步自转） |
| 公转周期 | 3.55 地球日 |
| 表面温度 | -160°C（冰壳表面） |
| 表面反照率 | 0.64（极高，太阳系最高之一） |

## 测试用例

### TC-EUROPA-DOM-01：Europa 面向面观测木星

| 字段 | 内容 |
|------|------|
| **TC-ID** | `EUROPA-DOM-01` |
| **观测位置** | (0°N, 0°E) — Europa 面向木星面中央 |
| **模拟时间** | 任意 |
| **太阳状态** | 视轨道位置 |
| **主导天体** | **木星**：潮汐锁定 → 固定在天空。角直径约 **12.2°**（月球 24 倍），视星等约 **-20.5**（满月亮 500 倍）。
木星条纹云带清晰可见。 |
| **预期可见天体清单** | **木星**：Az ≈ 180°，Alt ≈ 90°，角直径 ≈ 12.2°，视星等 ≈ -20.5
木星云带：棕色/白色条纹清晰 |
| **预期不可见天体** | 恒星（被木星强光淹没） |
| **星座/深空天体** | 无 |
| **特殊天象** | 木星在 Europa 天空中占据巨大面积；冰壳表面反射强烈（反照率 0.64） |
| **环境条件** | 冰壳表面极白；极稀薄 O₂ 大气；木星强光 |
| **校验点** | ① 木星角直径 ≈ 12.2°
② 木星视星等 ≈ -20.5
③ 木星条纹可见
④ 冰壳表面反射强光 |
| **天文依据** | Europa a=671,034 km；木星半径 71,492 km；角直径 = 2×arcsin(71492/671034) ≈ 12.2° |

### TC-EUROPA-SURFACE-01：Europa 冰壳表面特性

| 字段 | 内容 |
|------|------|
| **TC-ID** | `EUROPA-SURFACE-01` |
| **观测位置** | (0°N, 0°E) — Europa 赤道 |
| **模拟时间** | 当地正午 |
| **太阳状态** | 太阳角直径 0.10°，视星等 -24.5（从木星系统看） |
| **主导天体** | **木星**：固定在天空 |
| **预期可见天体清单** | **木星**：巨大圆盘
**太阳**：小圆盘 |
| **预期不可见天体** | 恒星 |
| **星座/深空天体** | 无 |
| **特殊天象** | Europa 冰壳表面反照率 0.64 → 表面极亮；冰壳下可能有液态水海洋 |
| **环境条件** | 冰壳表面温度 -160°C；表面布满裂纹和冰脊；极稀薄 O₂ 大气 |
| **校验点** | ① 冰壳表面应呈现亮白色/蓝白色（高反照率）
② 表面地形（冰裂纹）若模拟应可见 |
| **天文依据** | Europa 反照率 0.64（Voyager/Galileo 测量） |
