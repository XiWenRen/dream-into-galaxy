# 天王星 (Uranus) 星空观测验证用例

**观测者星体**: Uranus (天王星)  
**无固体表面**: 无（冰巨星，假设在云层顶部 ~1 bar）  
**大气状态**: H₂/He + 甲烷大气  
**卫星数量**: 27（Titania、Oberon、Ariel 为最大）  

## 星体基本参数

| 参数 | 数值 |
|------|------|
| 距太阳平均距离 | 19.22 AU (2,872×10⁶ km) |
| 太阳角直径 | 0.028°（约 1.7 角分） |
| 太阳视星等 | -20.9（比地球暗约 450 倍） |
| 自转周期 | 17h 14m |
| 自转轴倾角 | 97.8°（几乎"躺平"，逆行自转） |
| 云层顶部温度 | 约 -195°C |
| 大气成分 | H₂ 83%，He 15%，CH₄ 2.3% |

## 测试用例

### TC-URANUS-DAY-01：天王星云层顶部正午观测太阳

| 字段 | 内容 |
|------|------|
| **TC-ID** | `URANUS-DAY-01` |
| **观测位置** | (0°N, 0°E) — 天王星赤道云层顶部 |
| **模拟时间** | 当地正午 |
| **太阳状态** | 太阳极小但明亮，Az = 180°，Alt ≈ 90°，角直径 ≈ 0.028°（约 1.7 角分），视星等 ≈ -20.9 |
| **主导天体** | 无 |
| **预期可见天体清单** | **太阳**：极小的亮白色圆盘，角直径 0.028°（约为从地球看金星角直径的 1/2），视星等 -20.9 |
| **预期不可见天体** | 恒星（白天被淹没）
行星 |
| **星座/深空天体** | 无 |
| **特殊天象** | 天王星极端轴倾角 97.8° → 极区经历 42 年连续白昼/黑夜 |
| **环境条件** | 甲烷大气 → 天空呈青蓝色（甲烷吸收红光）；极低温 -195°C |
| **校验点** | ① 太阳角直径 ≈ 0.028°（极小的点状/小圆盘）
② 太阳视星等 ≈ -20.9
③ 天空颜色为青蓝色（#40A0A0）
④ 无恒星可见 |
| **天文依据** | 天王星距太阳 19.2 AU；太阳角直径 = 0.53°/19.2 ≈ 0.028° |

### TC-URANUS-SEASONAL-01：天王星极区 42 年极昼

| 字段 | 内容 |
|------|------|
| **TC-ID** | `URANUS-SEASONAL-01` |
| **观测位置** | (90°N, 0°E) — 天王星北极 |
| **模拟时间** | 北半球夏季（持续约 42 年） |
| **太阳状态** | 太阳在北极天空中 42 年不落下，Alt ≈ 7.8°（90° - 97.8° + 黄赤交角修正），实际上由于轴倾角 97.8°，北极夏季太阳接近地平线 |
等等，让我重新计算。

天王星轴倾角 97.8° 意味着北极几乎指向黄道面。
当北极指向太阳时（北半球夏至），太阳在北极的天空中的高度角：
由于轴倾角 > 90°，北极实际上在夏季"背对"太阳？
不，让我重新理解。

天王星轴倾角 97.8° 是指自转轴相对于轨道面法线的倾角。
这意味着天王星的"北极"实际上指向黄道面以下约 8°。
在北半球夏季，北极指向太阳方向，太阳在北极天空中高度角 ≈ 90° - (180° - 97.8°) = 7.8°？

这很复杂。让我简化：
由于轴倾角 97.8°，天王星的季节极端：
- 北极夏季：太阳在北极地平线上约 7.8° 高度，42 年不落下
- 北极冬季：太阳 42 年不升起
- 赤道：正常昼夜交替

让我用这个简化描述。 |
| **太阳状态** | 太阳在北极天空中约 42 年不落下，Alt ≈ 7.8°（接近地平线），呈极小的亮盘 |
| **主导天体** | 无 |
| **预期可见天体清单** | **太阳**：42 年可见，Alt ≈ 7.8°，角直径 0.028°，视星等 -20.9 |
| **预期不可见天体** | 恒星（极昼期间被太阳淹没） |
| **星座/深空天体** | 无 |
| **特殊天象** | 42 年极昼/极夜：天王星极端轴倾角导致极区经历长达 42 年的连续白昼或黑夜 |
| **环境条件** | 北极夏季：太阳接近地平线持续 42 年；温度约 -195°C |
| **校验点** | ① 太阳在北极 42 年内始终 Alt > 0°
② 太阳最高 Alt ≈ 7.8°（极低）
③ 极昼期间无恒星可见 |
| **天文依据** | 天王星轴倾角 97.8°；北极极昼持续 ≈ 土星轨道周期/2 ≈ 42 年 |

### TC-URANUS-NIGHT-01：天王星云层顶夜间观测

| 字段 | 内容 |
|------|------|
| **TC-ID** | `URANUS-NIGHT-01` |
| **观测位置** | (0°N, 0°E) — 天王星赤道 |
| **模拟时间** | 子夜 |
| **太阳状态** | 地平下 |
| **主导天体** | 无 |
| **预期可见天体清单** | **木星**：视星等约 -1.0（天王星-木星距离约 14-18 AU）
**土星**：视星等约 +0.5（距离约 10 AU）
**海王星**：视星等约 +5.0（距离约 10 AU）
**恒星**：可见（甲烷大气在夜间仍散射，但比白天弱） |
| **预期不可见天体** | 无 |
| **星座/深空天体** | 亮恒星可见 |
| **特殊天象** | 天王星极光 |
| **环境条件** | 夜间甲烷大气；天空趋近黑色但可能有微弱青蓝色残余 |
| **校验点** | ① 木星应作为最亮行星可见（m ≈ -1）
② 土星应清晰可见（m ≈ +0.5）
③ 天空背景趋近黑色 |
| **天文依据** | 天王星-土星距离约 10 AU；天王星-木星距离约 14-18 AU |
