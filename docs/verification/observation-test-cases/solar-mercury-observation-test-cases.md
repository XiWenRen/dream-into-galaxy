# 水星 (Mercury) 星空观测验证用例

**观测者星体**: Mercury (水星)  
**无固体表面**: 有（岩石行星，有固体表面）  
**大气状态**: 可忽略（表面气压 ~10⁻¹⁵ bar， exosphere 极稀薄）  
**卫星数量**: 0  

## 星体基本参数

| 参数 | 数值 |
|------|------|
| 距太阳平均距离 | 0.387 AU (57.9×10⁶ km) |
| 太阳角直径（平均） | 1.38°（地球上看太阳的 2.6 倍） |
| 太阳角直径（近日点） | 1.76° |
| 太阳角直径（远日点） | 1.10° |
| 太阳视星等（平均） | -27.9（比地球亮 2.3 倍） |
| 太阳视星等（近日点） | -28.6 |
| 自转周期 | 58.6 地球日 |
| 公转周期 | 88.0 地球日 |
| 太阳连续两次上中天（一个"水星日"） | 176 地球日 |
| 自转轴倾角 | 0.03°（几乎无倾角，无季节变化） |
| 表面重力 | 3.7 m/s² (0.38g) |
| 表面温度（白天） | 约 430°C |
| 表面温度（夜间） | 约 -180°C |

## 测试用例

### TC-MERCURY-DAY-01：水星正午观测太阳

| 字段 | 内容 |
|------|------|
| **TC-ID** | `MERCURY-DAY-01` |
| **观测位置** | (0°N, 0°E) — 水星赤道 |
| **模拟时间** | 水星当地正午（太阳上中天） |
| **太阳状态** | 太阳在天空中巨大且极亮，Az = 180°，Alt ≈ 90° - 纬度 = 90°，角直径 ≈ 1.38°（平均）~ 1.76°（近日点），视星等 -27.9 ~ -28.6 |
| **主导天体** | 无（水星无卫星） |
| **预期可见天体清单** | **太阳**：Az 180°，Alt ≈ 90°，角直径 1.38°（巨大圆盘），视星等 -27.9 |
| **预期不可见天体** | 全部恒星（被太阳眩光淹没）
全部行星（被太阳眩光淹没） |
| **星座/深空天体** | 无 |
| **特殊天象** | 太阳在近日点时比地球上看大 2.6 倍、亮 5.7 倍；水星无大气，太阳边缘锐利无散射 |
| **环境条件** | 无大气 → 无瑞利散射，天空在背向太阳方向为纯黑；但太阳眩光极大，导致太阳附近很大角度内天体不可见 |
| **校验点** | ① 太阳角直径在 1.1° ~ 1.8° 范围内变化（轨道离心率 e=0.206）
② 太阳视星等 ≤ -27.5
③ 太阳附近 30° 范围内无恒星可见（无大气但眩光效应）
④ 天空背向太阳方向应为纯黑色（RGB < 0.02） |
| **天文依据** | 水星轨道 e=0.206；近日点 0.307 AU，远日点 0.467 AU；角直径 = 0.53°/d |

### TC-MERCURY-NIGHT-01：水星子夜观测星空

| 字段 | 内容 |
|------|------|
| **TC-ID** | `MERCURY-NIGHT-01` |
| **观测位置** | (0°N, 0°E) — 水星赤道 |
| **模拟时间** | 水星子夜（太阳在地平下） |
| **太阳状态** | 在地平线以下约 -90°（赤道子夜），完全不可见 |
| **主导天体** | 无 |
| **预期可见天体清单** | **地球**：视星等约 -3.0（从水星看地球是内行星，类似从地球看金星），呈蓝白色点状
**金星**：若位于夜天，视星等约 -3.0，呈明亮白色
**火星**：视星等约 +1.5
**木星**：视星等约 -1.5
**全部恒星**（无大气遮挡）：肉眼极限星等约 6.5 ~ 7.0（比地球略好，无大气散射） |
| **预期不可见天体** | 太阳（地平下） |
| **星座/深空天体** | 所有星座均可见（无大气消光），包括黄道带星座 |
| **特殊天象** | 水星无大气 → 星空极度清晰锐利；恒星不闪烁（无大气湍流） |
| **环境条件** | 无大气、无散射、无闪烁；表面温度极低（-180°C）；地面反照率低（类似月球） |
| **校验点** | ① 全部恒星应清晰可见（无大气消光影响）
② 恒星不闪烁（无大气湍流）
③ 地球应作为"晨星/昏星"可见（视星等约 -3，类似金星从地球看）
④ 天空背景为纯黑色 |
| **天文依据** | 无大气行星：恒星视宁度（seeing）为零；地球从水星看视星等估算：地球反照率 0.3，角直径约 0.02°，m ≈ -3.0 |

### TC-MERCURY-TWILIGHT-01：水星地平线附近太阳

| 字段 | 内容 |
|------|------|
| **TC-ID** | `MERCURY-TWILIGHT-01` |
| **观测位置** | (0°N, 0°E) — 水星赤道 |
| **模拟时间** | 日出前/日落后（太阳位于地平线下 0° ~ -5°） |
| **太阳状态** | 太阳在地平线附近，角直径 1.38°（巨大），呈扁平椭圆（地平折射极弱，几乎无） |
| **主导天体** | 无 |
| **预期可见天体清单** | **太阳**：巨大的橙红色圆盘（地表无大气散射，颜色来自表面反射），角直径 1.38°
**地球**（若位于该方向）：可能作为明亮"晨星"可见 |
| **预期不可见天体** | 暗恒星（被太阳眩光淹没） |
| **星座/深空天体** | 仅最亮恒星 |
| **特殊天象** | 水星无大气 → 无黎明/黄昏渐变；太阳从地平线升起/落下时边缘锐利，无红化/扁平效应 |
| **环境条件** | 无大气 → 无曙暮光；太阳一旦落下，天空立即变为纯黑；无"黄昏"过渡 |
| **校验点** | ① 太阳在地平线附近应保持圆形（无大气折射扁平化）
② 太阳落下后，天空应在 1° 仰角范围内从亮变纯黑（无大气散射延迟）
③ 无曙暮光效果（天空不应有渐变色彩） |
| **天文依据** | 无大气行星无大气折射（折射角 ~0°）；无散射 → 曙暮光不存在 |

### TC-MERCURY-SEASONAL-01：水星极区永昼坑底

| 字段 | 内容 |
|------|------|
| **TC-ID** | `MERCURY-SEASONAL-01` |
| **观测位置** | (90°N, 0°E) — 水星北极点（或靠近极区的陨石坑底部） |
| **模拟时间** | 任意时刻 |
| **太阳状态** | 水星自转轴倾角仅 0.03°，但轨道离心率大 → 极区某些陨石坑底部永远照不到太阳（"冷阱"）
在极区坑底：太阳可能永远在地平线上或地平线下，取决于坑的位置 |
| **主导天体** | 无 |
| **预期可见天体清单** | 若位于永远照不到太阳的坑底：**无太阳**
**星空**：永远可见（无大气，无日光干扰）
**地球**：若位于可见天区，呈明亮蓝白色点 |
| **预期不可见天体** | 太阳（位于坑边缘上方或被遮挡） |
| **星座/深空天体** | 所有星座可见（无大气，无日光） |
| **特殊天象** | 水星极区陨石坑底部可能存在永久阴影区（"cold traps"），温度极低，是太阳系最冷区域之一；坑底观测者永远看不到太阳，但能看到璀璨星空 |
| **环境条件** | 永久阴影区温度约 -180°C 以下；无大气；无光照 |
| **校验点** | ① 位于极区坑底的观测者应永远看不到太阳（太阳 Alt 始终 < 0° 或被地形遮挡）
② 星空应始终完全可见（无大气消光，无日光干扰）
③ 天空背景纯黑 |
| **天文依据** | 水星 Messenger 任务确认极区陨石坑存在永久阴影区和水冰沉积（Chabot et al., 2012） |
