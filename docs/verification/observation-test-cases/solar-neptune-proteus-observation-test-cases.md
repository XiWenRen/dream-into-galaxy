# 海卫八 (Proteus) 星空观测验证用例

**观测者星体**: Proteus (海卫八) — 海王星最大的内卫星，形状不规则  
**无固体表面**: 有（岩石/冰，形状不规则 440×416×404 km）  
**大气状态**: 无  
**母行星**: Neptune (海王星)  

## 星体基本参数

| 参数 | 数值 |
|------|------|
| 距海王星中心 | 117,647 km |
| 距海王星表面 | 约 69,000 km |
| 海王星角直径（从 Proteus 看） | 约 **21.7°**（地球上看月球的 **43 倍**！） |
| 海王星视星等（从 Proteus 看） | 约 -20.5（比满月亮约 600 倍） |
| 自转周期 | 1.12 地球日（同步自转） |
| 公转周期 | 1.12 地球日 |
| 表面温度 | -220°C |

## 测试用例

### TC-PROTEUS-DOM-01：Proteus 面向面观测海王星

| 字段 | 内容 |
|------|------|
| **TC-ID** | `PROTEUS-DOM-01` |
| **观测位置** | (0°N, 0°E) — Proteus 面向海王星面中央 |
| **模拟时间** | 任意 |
| **太阳状态** | 视轨道位置 |
| **主导天体** | **海王星**：潮汐锁定 → 固定在天空。角直径约 **21.7°**（月球 **43 倍**！），视星等 **-20.5**（满月亮 **600 倍**！）。
这是太阳系中所有卫星看母行星的**最大视角之一**！ |
| **预期可见天体清单** | **海王星**：Az ≈ 180°，Alt ≈ 90°，角直径 ≈ 21.7°，视星等 ≈ -20.5
海王星深蓝色圆盘占据巨大天空面积 |
| **预期不可见天体** | 恒星（被海王星强光淹没） |
| **星座/深空天体** | 无 |
| **特殊天象** | 从 Proteus 看海王星是太阳系中最壮观的视角之一：21.7° 直径 = 43 倍满月！海王星在天空中占据的面积相当于 40 个满月并排！ |
| **环境条件** | 无大气；形状不规则表面；极低温 -220°C；海王星极端强光 |
| **校验点** | ① 海王星角直径 ≈ 21.7°（约 22°）
② 海王星视星等 ≈ -20.5
③ 海王星颜色深蓝色
④ 海王星大暗斑（若模拟且面向）应可见
⑤ 无恒星可见 |
| **天文依据** | Proteus a=117,647 km；海王星半径 24,622 km；角直径 = 2×arcsin(24622/117647) ≈ 21.7° |

### TC-PROTEUS-SHAPE-01：Proteus 不规则形状观测

| 字段 | 内容 |
|------|------|
| **TC-ID** | `PROTEUS-SHAPE-01` |
| **观测位置** | Proteus 表面 |
| **模拟时间** | 任意 |
| **太阳状态** | 视位置 |
| **主导天体** | **海王星**：固定在天空 |
| **预期可见天体清单** | **海王星**：巨大深蓝色圆盘
**地平线**：由于 Proteus 不规则形状，地平线可能不是平滑曲线 |
| **预期不可见天体** | 恒星 |
| **星座/深空天体** | 无 |
| **特殊天象** | Proteus 是太阳系最大的不规则形状卫星之一，地平线在不同方向可能有不同曲率 |
| **环境条件** | 无大气；不规则形状 |
| **校验点** | ① 海王星固定在天空
② 地平线曲率若模拟应反映不规则形状 |
| **天文依据** | Proteus 尺寸 440×416×404 km，太小的引力无法使其成球形 |
