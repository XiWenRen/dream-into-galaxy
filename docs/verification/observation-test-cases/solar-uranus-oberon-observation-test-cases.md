# 天卫四 (Oberon) 星空观测验证用例

**观测者星体**: Oberon (天卫四) — 天王星最外层主要卫星  
**无固体表面**: 有（岩石+冰壳，布满陨石坑）  
**大气状态**: 无显著大气  
**母行星**: Uranus (天王星)  

## 星体基本参数

| 参数 | 数值 |
|------|------|
| 距天王星中心 | 583,520 km |
| 距天王星表面 | 约 533,000 km |
| 天王星角直径（从 Oberon 看） | 约 6.4°（地球上看月球的 **13 倍**） |
| 天王星视星等（从 Oberon 看） | 约 -15.5（比满月亮约 12 倍） |
| 自转周期 | 13.46 地球日（同步自转） |
| 公转周期 | 13.46 地球日 |
| 表面温度 | -200°C |

## 测试用例

### TC-OBERON-DOM-01：Oberon 面向面观测天王星

| 字段 | 内容 |
|------|------|
| **TC-ID** | `OBERON-DOM-01` |
| **观测位置** | (0°N, 0°E) — Oberon 面向天王星面中央 |
| **模拟时间** | 任意 |
| **太阳状态** | 视轨道位置 |
| **主导天体** | **天王星**：潮汐锁定 → 固定在天空。角直径约 **6.4°**（月球 13 倍），视星等 **-15.5**（满月亮 12 倍）。青蓝色圆盘。 |
| **预期可见天体清单** | **天王星**：Az ≈ 180°，Alt ≈ 90°，角直径 ≈ 6.4°，视星等 ≈ -15.5 |
| **预期不可见天体** | 恒星 |
| **星座/深空天体** | 无 |
| **特殊天象** | Oberon 是天王星最外层主要卫星，天王星在其天空中仍大且亮 |
| **环境条件** | 无大气；极低温；天王星强光 |
| **校验点** | ① 天王星角直径 ≈ 6.4°
② 天王星视星等 ≈ -15.5
③ 天王星颜色青蓝色 |
| **天文依据** | Oberon a=583,520 km；天王星半径 25,362 km；角直径 = 2×arcsin(25362/583520) ≈ 6.35° |
