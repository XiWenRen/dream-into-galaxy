# 火卫一 (Phobos) 星空观测验证用例

**观测者星体**: Phobos (火卫一) — 火星的内卫星，形状不规则  
**无固体表面**: 有（岩石，形状不规则 27×22×18 km）  
**大气状态**: 无  
**母行星**: Mars (火星)  

## 星体基本参数

| 参数 | 数值 |
|------|------|
| 距火星中心 | 9,377 km |
| 距火星表面 | 约 6,000 km |
| 火星角直径（从 Phobos 看） | 约 42.8°（地球上看月球的 **86 倍**！） |
| 火星视星等（从 Phobos 看） | 约 -21.0（比满月亮约 1500 倍） |
| 自转周期 | 7.66 小时（同步自转） |
| 公转周期 | 7.66 小时 |
| 表面温度 | -40°C ~ -4°C |

## 测试用例

### TC-PHOBOS-DOM-01：Phobos 面向面观测火星

| 字段 | 内容 |
|------|------|
| **TC-ID** | `PHOBOS-DOM-01` |
| **观测位置** | (0°N, 0°E) — Phobos 面向火星面中央 |
| **模拟时间** | 任意 |
| **太阳状态** | 视轨道位置 |
| **主导天体** | **火星**：潮汐锁定 → 固定在天空。角直径约 **42.8°**（月球 **86 倍**！），视星等 **-21.0**（满月亮 **1500 倍**！）。
这是太阳系中所有卫星看母行星的**最大视角**！ |
| **预期可见天体清单** | **火星**：Az ≈ 180°，Alt ≈ 90°，角直径 ≈ 42.8°，视星等 ≈ -21.0
火星呈红色大圆盘，表面地形（奥林帕斯山、水手号峡谷等）可能可见！ |
| **预期不可见天体** | 恒星（被火星强光淹没） |
| **星座/深空天体** | 无 |
| **特殊天象** | 从 Phobos 看火星是太阳系中最壮观的行星视角：42.8° 直径 = 86 倍满月！
火星在天空中占据的面积相当于整个大熊座！ |
| **环境条件** | 无大气；形状不规则；极近距离火星；火星极端强光 |
| **校验点** | ① 火星角直径 ≈ 42.8°（约 43°）
② 火星视星等 ≈ -21.0
③ 火星颜色红色（#CD5C5C）
④ 火星表面大型地形（奥林帕斯山等）若模拟应可见
⑤ 无恒星可见 |
| **天文依据** | Phobos a=9,377 km；火星半径 3,390 km；角直径 = 2×arcsin(3390/9377) ≈ 42.8° |

### TC-PHOBOS-ORBIT-01：Phobos 快速轨道效果

| 字段 | 内容 |
|------|------|
| **TC-ID** | `PHOBOS-ORBIT-01` |
| **观测位置** | Phobos 表面 |
| **模拟时间** | 任意 |
| **太阳状态** | 视位置 |
| **主导天体** | **火星**：固定在天空 |
| **预期可见天体清单** | **火星**：固定在天空
**太阳**：在 Phobos 天空中快速移动（Phobos 日仅 7.66 小时）
**Deimos**：可能可见为缓慢移动亮点 |
| **预期不可见天体** | 恒星 |
| **星座/深空天体** | 无 |
| **特殊天象** | Phobos 轨道周期仅 7.66 小时 < 火星自转 24.6 小时 → 从 Phobos 看，太阳**西升东落**！
Phobos 日（太阳两次上中天）仅 7.66 小时。 |
| **环境条件** | 无大气；快速昼夜交替 |
| **校验点** | ① 火星固定在天空
② 太阳西升东落（与火星表面相反）
③ Phobos 日 ≈ 7.66 小时 |
| **天文依据** | Phobos 轨道 7.66h < 火星自转 24.6h → 逆行视运动 |
