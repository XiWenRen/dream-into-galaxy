# 月球 (Moon) 星空观测验证用例

**观测者星体**: Moon (月球) — 地球的天然卫星  
**无固体表面**: 有（岩石表面，无大气）  
**大气状态**: 无（表面气压 ~10⁻¹² bar，真空）  
**母行星**: Earth (地球)  

## 星体基本参数

| 参数 | 数值 |
|------|------|
| 距地球平均距离 | 384,400 km |
| 地球角直径（从月球看） | 约 2.0°（月球看地球的 4 倍） |
| 地球视星等（从月球看） | 约 -17.0（比满月亮约 100 倍） |
| 自转周期 | 27.3 地球日（同步自转，潮汐锁定） |
| 公转周期 | 27.3 地球日 |
| 自转轴倾角 | 1.5°（几乎无季节变化） |
| 表面温度（白天） | 约 120°C |
| 表面温度（夜间） | 约 -170°C |

## 测试用例

### TC-MOON-DOM-01：月球面向面观测地球

| 字段 | 内容 |
|------|------|
| **TC-ID** | `MOON-DOM-01` |
| **观测位置** | (0°N, 0°E) — 月球正面中央 |
| **模拟时间** | 任意时刻（地球固定在天空） |
| **太阳状态** | 视月球相位和轨道位置而定 |
| **主导天体** | **地球**：由于潮汐锁定，地球在月球面向面的天空中**几乎固定不动**（不升不落），仅有微小天平动（±7.6°）。
地球角直径约 2.0°（月球从地球看直径的 4 倍），视星等约 -17.0（比满月亮约 100 倍！）。
地球呈现蓝白色圆盘，可见大陆、海洋、云层。 |
| **预期可见天体清单** | **地球**：Az ≈ 180°，Alt ≈ 90°（赤道正面中央），角直径 ≈ 2.0°，视星等 ≈ -17.0
地球呈现相位变化（类似月球月相，但相反：月球"新月"时地球"满月"）
地球大气层可见蓝色光环（瑞利散射）
地球表面大陆轮廓可能可见 |
| **预期不可见天体** | 无特定 |
| **星座/深空天体** | 全部恒星可见（无大气遮挡） |
| **特殊天象** | 地球在月球天空中"静止不动" — 这是潮汐锁定的直接结果；地球是月球天空中最大、最亮、最壮观的天体 |
| **环境条件** | 无大气、无散射、无闪烁；真空环境；极端温差 |
| **校验点** | ① 地球 Az 变化 < ±8°（天平动范围）
② 地球 Alt 由观测者纬度决定（赤道 ≈ 90°）
③ 地球角直径 ≈ 2.0°（4 倍月球从地球看）
④ 地球视星等 ≈ -17.0（比满月亮 100 倍）
⑤ 地球呈现相位变化（与月球相位相反）
⑥ 地球周围应有蓝色光晕（大气瑞利散射） |
| **天文依据** | 月球同步自转：自转周期 = 公转周期；天平动 ±7.6°；地球角直径 = 2×arctan(6371/384400) ≈ 1.9° |

### TC-MOON-NIGHT-01：月球月夜星空

| 字段 | 内容 |
|------|------|
| **TC-ID** | `MOON-NIGHT-01` |
| **观测位置** | (0°N, 0°E) — 月球正面 |
| **模拟时间** | 月球子夜（太阳在背向面） |
| **太阳状态** | 在地平线以下（背向面方向） |
| **主导天体** | **地球**：地球被太阳部分照射，呈现相位（可能为"地相"），照亮月球表面（地照） |
| **预期可见天体清单** | **地球**：呈蓝白色圆盘，有明确相位
**全部恒星**：清晰可见（无大气），肉眼极限星等约 7.0-8.0（比地球好，无大气散射）
**行星**：
— 金星：视星等约 -4.5（从月球看）
— 火星：视星等约 -1.5
— 木星：视星等约 -2.5
— 土星：视星等约 +0.5 |
| **预期不可见天体** | 太阳（地平下） |
| **星座/深空天体** | 所有星座、深空天体（M42、M45、银河等）均极清晰 |
| **特殊天象** | **地照**：地球反射光照射月球表面（类似地球上的"月照"），使月球暗面隐约可见蓝灰色光 |
| **环境条件** | 无大气 → 星空极度清晰锐利；恒星不闪烁；无散射 → 天空在背向太阳方向为纯黑 |
| **校验点** | ① 地球应作为最大最亮天体可见
② 全部恒星应清晰可见（极限星等 > 7）
③ 恒星不闪烁（无大气湍流）
④ 天空背景纯黑（RGB < 0.01）
⑤ 地照应照亮月球表面（环境光来自地球反射） |
| **天文依据** | 无大气行星：恒星极限星等提高约 1 等；地照亮度约为月照的 100 倍 |

### TC-MOON-ECLIPSE-01：月全食期间观测地球

| 字段 | 内容 |
|------|------|
| **TC-ID** | `MOON-ECLIPSE-01` |
| **观测位置** | (0°N, 0°E) — 月球正面 |
| **模拟时间** | 月全食期间 |
| **太阳状态** | 太阳被地球完全遮挡（从月球看为"日食"） |
| **主导天体** | **地球**：遮挡太阳，在地球边缘形成红色光环（地球大气瑞利散射+折射，将红光偏折到月球上） |
| **预期可见天体清单** | **地球**：黑色圆盘遮挡太阳，周围环绕**红色光环**（波长较长的红光被大气折射到月球上）
**日冕**：可能可见（太阳外层大气）
**恒星**：日食期间大量恒星显现 |
| **预期不可见天体** | 太阳本体（被地球遮挡） |
| **星座/深空天体** | 日食期间深空天体清晰可见 |
| **特殊天象** | 从月球看"日全食"：地球遮挡太阳，但由于地球大气折射，月球表面不会被完全黑暗笼罩，而是被红色光照亮（类似地球上的月全食呈红色） |
| **环境条件** | 月全食期间月球表面呈暗红色（地球大气折射的红光）；温度骤降 |
| **校验点** | ① 地球周围应有红色光环（大气折射红光）
② 月球表面应呈现暗红色（被地球折射光照亮）
③ 日食期间恒星大量显现
④ 太阳本体被完全遮挡 |
| **天文依据** | 月全食原理：地球遮挡直射阳光，但大气折射红光到月球；月球表面呈暗红色 |

### TC-MOON-BACK-01：月球背向面（无地球）

| 字段 | 内容 |
|------|------|
| **TC-ID** | `MOON-BACK-01` |
| **观测位置** | (0°N, 180°E) — 月球背面中央 |
| **模拟时间** | 月球背面子夜 |
| **太阳状态** | 地平下 |
| **主导天体** | **地球**：完全不可见（背向面永远看不到地球） |
| **预期可见天体清单** | **全部恒星**：极清晰（无大气，无地球光污染）
**行星**：金星、火星、木星、土星等
**银河**：极为壮观（无地球光污染）
**深空天体**：全部可见 |
| **预期不可见天体** | **地球**：完全不可见（潮汐锁定的背向面）
太阳（地平下） |
| **星座/深空天体** | 所有星座、银河中心、深空天体均极清晰 |
| **特殊天象** | 月球背向面是太阳系最理想的射电/光学观测点之一：无地球电磁干扰、无地球光污染、无大气 |
| **环境条件** | 无大气；无地球光照干扰；纯黑天空；极端寒冷（-170°C） |
| **校验点** | ① 地球完全不可见（Alt < 0° 或被月球本体遮挡）
② 银河应极为清晰（无地球光污染）
③ 天空背景纯黑
④ 恒星极限星等 > 7.5 |
| **天文依据** | 潮汐锁定卫星背向面永远看不到母行星 |
