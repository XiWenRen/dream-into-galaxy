# 木卫三 (Ganymede) 星空观测验证用例

**观测者星体**: Ganymede (木卫三) — 木星的第三颗伽利略卫星，太阳系最大卫星  
**无固体表面**: 有（岩石+冰壳）  
**大气状态**: 极稀薄 O₂ 大气  
**母行星**: Jupiter (木星)  

## 星体基本参数

| 参数 | 数值 |
|------|------|
| 距木星中心 | 1,070,412 km |
| 距木星表面 | 约 999,000 km |
| 木星角直径（从 Ganymede 看） | 约 7.7°（地球上看月球的 **15 倍**） |
| 木星视星等（从 Ganymede 看） | 约 -19.5（比满月亮约 200 倍） |
| 自转周期 | 7.15 地球日（同步自转） |
| 公转周期 | 7.15 地球日 |
| 半径 | 2,634 km（比水星还大！） |
| 表面温度 | -160°C ~ -100°C |

## 测试用例

### TC-GANYMEDE-DOM-01：Ganymede 面向面观测木星

| 字段 | 内容 |
|------|------|
| **TC-ID** | `GANYMEDE-DOM-01` |
| **观测位置** | (0°N, 0°E) — Ganymede 面向木星面中央 |
| **模拟时间** | 任意 |
| **太阳状态** | 视轨道位置 |
| **主导天体** | **木星**：潮汐锁定 → 固定在天空。角直径约 **7.7°**（月球 15 倍），视星等约 **-19.5**（满月亮 200 倍）。木星条纹云带可见。 |
| **预期可见天体清单** | **木星**：Az ≈ 180°，Alt ≈ 90°，角直径 ≈ 7.7°，视星等 ≈ -19.5
木星云带：棕色/白色条纹可见 |
| **预期不可见天体** | 恒星（被木星强光淹没） |
| **星座/深空天体** | 无 |
| **特殊天象** | 木星在 Ganymede 天空中仍占据巨大面积（7.7° = 15 倍满月）；Ganymede 是太阳系最大卫星 |
| **环境条件** | 冰壳+岩石表面；极稀薄 O₂ 大气；木星强光 |
| **校验点** | ① 木星角直径 ≈ 7.7°
② 木星视星等 ≈ -19.5
③ 木星条纹可见 |
| **天文依据** | Ganymede a=1,070,412 km；木星半径 71,492 km；角直径 = 2×arcsin(71492/1070412) ≈ 7.65° |

### TC-GANYMEDE-NIGHT-01：Ganymede 背向面夜间观测

| 字段 | 内容 |
|------|------|
| **TC-ID** | `GANYMEDE-NIGHT-01` |
| **观测位置** | (0°N, 180°E) — Ganymede 背向木星面 |
| **模拟时间** | 子夜（木星在背向面地平下） |
| **太阳状态** | 视位置 |
| **主导天体** | **木星**：不可见（背向面） |
| **预期可见天体清单** | **恒星**：清晰可见（无大气遮挡）
**行星**：地球、金星、火星等
**Io、Europa、Callisto**：其他伽利略卫星若位于可见天区 |
| **预期不可见天体** | 木星（背向面） |
| **星座/深空天体** | 所有星座、银河可见 |
| **特殊天象** | Ganymede 背向面无木星光照干扰，是观测外太空的理想位置 |
| **环境条件** | 无大气 → 星空极清晰 |
| **校验点** | ① 木星完全不可见
② 恒星极清晰
③ 天空纯黑 |
| **天文依据** | 潮汐锁定卫星背向面永远看不到母行星 |
