# 火卫二 (Deimos) 星空观测验证用例

**观测者星体**: Deimos (火卫二) — 火星的外卫星，形状不规则  
**无固体表面**: 有（岩石，形状不规则 15×12×11 km）  
**大气状态**: 无  
**母行星**: Mars (火星)  

## 星体基本参数

| 参数 | 数值 |
|------|------|
| 距火星中心 | 23,460 km |
| 距火星表面 | 约 20,000 km |
| 火星角直径（从 Deimos 看） | 约 16.5°（地球上看月球的 **33 倍**） |
| 火星视星等（从 Deimos 看） | 约 -18.5（比满月亮约 200 倍） |
| 自转周期 | 30.35 小时（同步自转） |
| 公转周期 | 30.35 小时 |
| 表面温度 | -40°C ~ -4°C |

## 测试用例

### TC-DEIMOS-DOM-01：Deimos 面向面观测火星

| 字段 | 内容 |
|------|------|
| **TC-ID** | `DEIMOS-DOM-01` |
| **观测位置** | (0°N, 0°E) — Deimos 面向火星面中央 |
| **模拟时间** | 任意 |
| **太阳状态** | 视轨道位置 |
| **主导天体** | **火星**：潮汐锁定 → 固定在天空。角直径约 **16.5°**（月球 **33 倍**），视星等 **-18.5**（满月亮 **200 倍**）。
火星呈红色大圆盘，表面地形清晰可见。 |
| **预期可见天体清单** | **火星**：Az ≈ 180°，Alt ≈ 90°，角直径 ≈ 16.5°，视星等 ≈ -18.5
火星红色圆盘，表面大型地形可见 |
| **预期不可见天体** | 恒星（被火星强光淹没） |
| **星座/深空天体** | 无 |
| **特殊天象** | 从 Deimos 看火星占据 16.5°，是天空中绝对主导天体 |
| **环境条件** | 无大气；形状不规则；火星强光 |
| **校验点** | ① 火星角直径 ≈ 16.5°
② 火星视星等 ≈ -18.5
③ 火星颜色红色
④ 表面地形可见 |
| **天文依据** | Deimos a=23,460 km；火星半径 3,390 km；角直径 = 2×arcsin(3390/23460) ≈ 16.5° |

### TC-DEIMOS-ORBIT-01：Deimos 缓慢轨道效果

| 字段 | 内容 |
|------|------|
| **TC-ID** | `DEIMOS-ORBIT-01` |
| **观测位置** | Deimos 表面 |
| **模拟时间** | 任意 |
| **太阳状态** | 视位置 |
| **主导天体** | **火星**：固定在天空 |
| **预期可见天体清单** | **火星**：固定在天空
**太阳**：东升西落，但比火星表面慢（Deimos 周期 30.35h > 火星日 24.6h）
**Phobos**：可能可见为快速移动亮点 |
| **预期不可见天体** | 恒星 |
| **星座/深空天体** | 无 |
| **特殊天象** | Deimos 轨道周期 30.35h > 火星自转 24.6h → 太阳东升西落，但比火星表面慢约 5.7 小时/日 |
| **环境条件** | 无大气 |
| **校验点** | ① 火星固定在天空
② 太阳东升西落但缓慢
③ Deimos 日 ≈ 30.35 小时 |
| **天文依据** | Deimos 轨道 30.35h > 火星自转 24.6h → 顺行但缓慢 |
