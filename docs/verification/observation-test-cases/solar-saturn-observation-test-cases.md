# 土星 (Saturn) 星空观测验证用例

**观测者星体**: Saturn (土星)  
**无固体表面**: 无（气态巨行星，假设在云层顶部 ~0.1-1 bar）  
**大气状态**: 浓密 H₂/He 大气  
**卫星数量**: 82+（Titan 为最大）  

## 星体基本参数

| 参数 | 数值 |
|------|------|
| 距太阳平均距离 | 9.583 AU (1,434×10⁶ km) |
| 太阳角直径 | 0.055°（地球上看太阳的 1/10） |
| 太阳视星等 | -21.8（比地球暗 120 倍） |
| 自转周期 | 10h 33m |
| 自转轴倾角 | 26.7°（有明显季节变化） |
| 环系统外径（A环） | 136,780 km（直径） |
| 环系统内径（D环内缘） | 66,900 km |
| 云层顶部温度 | 约 -140°C |

## 测试用例

### TC-SATURN-DAY-01：土星云层顶部正午观测太阳

| 字段 | 内容 |
|------|------|
| **TC-ID** | `SATURN-DAY-01` |
| **观测位置** | (0°N, 0°E) — 土星赤道云层顶部 |
| **模拟时间** | 土星夏至正午 |
| **太阳状态** | 太阳很小但明亮，Az = 180°，Alt ≈ 63°（90° - 26.7° 轴倾角），角直径 ≈ 0.055°，视星等 ≈ -21.8 |
| **主导天体** | 无 |
| **预期可见天体清单** | **太阳**：Az 180°，Alt ≈ 63°，角直径 0.055°，视星等 -21.8，呈白色小圆盘，周围有氨云散射光晕 |
| **预期不可见天体** | 恒星（云层散射）
行星 |
| **星座/深空天体** | 无 |
| **特殊天象** | 土星环在云层顶部视角下呈巨大拱形结构，从地平线一侧延伸到另一侧 |
| **环境条件** | H₂/He + 氨云大气；天空呈黄白色；环系统遮挡部分天空 |
| **校验点** | ① 太阳角直径 ≈ 0.055° ± 0.005°
② 太阳视星等 ≈ -21.8
③ 天空颜色黄白色（#F0E8C8）
④ 环系统在视野中呈拱形 |
| **天文依据** | 土星距太阳 9.58 AU；太阳角直径 = 0.53°/9.58 ≈ 0.055° |

### TC-SATURN-RING-01：从土星云层顶部看环系统

| 字段 | 内容 |
|------|------|
| **TC-ID** | `SATURN-RING-01` |
| **观测位置** | (26.7°N, 0°E) — 土星北极（轴倾角方向） |
| **模拟时间** | 土星夏至（太阳照射北半球） |
| **太阳状态** | 太阳在北天高空 |
| **主导天体** | 无 |
| **预期可见天体清单** | **环系统**：从土星北极看，环面呈巨大圆盘状（正面视角），横跨整个天空地平线到地平线
A环、B环、卡西尼缝、恩克缝均应可见
环面呈灰白色/米黄色（冰粒散射） |
| **预期不可见天体** | 无 |
| **星座/深空天体** | 若夜间：可见恒星 |
| **特殊天象** | 土星环从内部看呈壮观拱形；北极夏季时环面被阳光照亮 |
| **环境条件** | 环系统遮挡部分天空；环反射光增加环境亮度 |
| **校验点** | ① 环系统应从一侧地平线延伸到另一侧（完整拱形）
② 卡西尼缝应可见为环中的暗带
③ 环面亮度在北夏时应较高 |
| **天文依据** | 土星环厚度约 10-100 m，但宽度达 136,780 km |

### TC-SATURN-NIGHT-01：土星云层顶夜间观测外行星

| 字段 | 内容 |
|------|------|
| **TC-ID** | `SATURN-NIGHT-01` |
| **观测位置** | (0°N, 0°E) — 土星赤道 |
| **模拟时间** | 土星子夜 |
| **太阳状态** | 地平下 |
| **主导天体** | 无 |
| **预期可见天体清单** | **木星**：视星等约 -1.5（土星-木星距离 4.3-6.5 AU），夜空中最亮外行星
**天王星**：视星等约 +4.0（距离约 10 AU）
**地球**：视星等约 +3.5 |
| **预期不可见天体** | 恒星（若云层散射强则可能不可见） |
| **星座/深空天体** | 亮恒星可见 |
| **特殊天象** | 土星极光（极区）：巨大极光椭圆 |
| **环境条件** | 夜间云层顶部；温度 -140°C |
| **校验点** | ① 木星应作为最亮行星可见
② 天王星在理想条件下可能可见（m ≈ +4）
③ 土星极光在极区应可见 |
| **天文依据** | 土星-木星距离 4.3-6.5 AU |
