# 海王星 (Neptune) 星空观测验证用例

**观测者星体**: Neptune (海王星)  
**无固体表面**: 无（冰巨星，假设在云层顶部 ~1 bar）  
**大气状态**: H₂/He + 甲烷大气  
**卫星数量**: 14（Triton 为最大）  

## 星体基本参数

| 参数 | 数值 |
|------|------|
| 距太阳平均距离 | 30.07 AU (4,498×10⁶ km) |
| 太阳角直径 | 0.018°（约 1.1 角分） |
| 太阳视星等 | -20.1（比地球暗约 900 倍） |
| 自转周期 | 16h 6m |
| 自转轴倾角 | 28.3° |
| 云层顶部温度 | 约 -200°C |
| 大气成分 | H₂ 80%，He 19%，CH₄ 1-2% |
| 最大风速 | 2,100 km/h（太阳系最快） |

## 测试用例

### TC-NEPTUNE-DAY-01：海王星云层顶部正午观测太阳

| 字段 | 内容 |
|------|------|
| **TC-ID** | `NEPTUNE-DAY-01` |
| **观测位置** | (0°N, 0°E) — 海王星赤道云层顶部 |
| **模拟时间** | 当地正午 |
| **太阳状态** | 太阳在天空中极小，Az = 180°，Alt ≈ 90°，角直径 ≈ 0.018°（约 1.1 角分），视星等 ≈ -20.1 |
| **主导天体** | 无 |
| **预期可见天体清单** | **太阳**：极小的亮白色圆盘，角直径 0.018°（约为从地球看木星角直径的 1/3），视星等 -20.1 |
| **预期不可见天体** | 恒星（白天被淹没）
行星 |
| **星座/深空天体** | 无 |
| **特殊天象** | 太阳在海王星天空中仅为一个极亮小点；海王星是太阳系最远的行星 |
| **环境条件** | 甲烷大气 → 天空呈深蓝色（甲烷吸收红光）；极端低温 -200°C；超音速风暴 |
| **校验点** | ① 太阳角直径 ≈ 0.018°（极小的点状）
② 太阳视星等 ≈ -20.1
③ 天空颜色为深蓝色（#1A3A5A）
④ 无恒星可见 |
| **天文依据** | 海王星距太阳 30.1 AU；太阳角直径 = 0.53°/30.1 ≈ 0.018° |

### TC-NEPTUNE-NIGHT-01：海王星云层顶夜间观测外行星

| 字段 | 内容 |
|------|------|
| **TC-ID** | `NEPTUNE-NIGHT-01` |
| **观测位置** | (0°N, 0°E) — 海王星赤道 |
| **模拟时间** | 子夜 |
| **太阳状态** | 地平下 |
| **主导天体** | 无 |
| **预期可见天体清单** | **木星**：视星等约 -0.5（海王星-木星距离约 24-28 AU）
**土星**：视星等约 +0.2（距离约 20 AU）
**天王星**：视星等约 +2.5（距离约 10 AU）
**恒星**：可见（夜间甲烷大气散射减弱） |
| **预期不可见天体** | 无 |
| **星座/深空天体** | 亮恒星可见 |
| **特殊天象** | 海王星大暗斑（若系统模拟）：巨大反气旋风暴，类似木星大红斑 |
| **环境条件** | 夜间甲烷大气；温度 -200°C |
| **校验点** | ① 木星应作为最亮行星可见（m ≈ -0.5）
② 土星应清晰可见（m ≈ +0.2）
③ 天空背景趋近黑色 |
| **天文依据** | 海王星-土星距离约 20 AU；海王星-木星距离约 24-28 AU |

### TC-NEPTUNE-SUN-01：太阳在海王星距离的极端表现

| 字段 | 内容 |
|------|------|
| **TC-ID** | `NEPTUNE-SUN-01` |
| **观测位置** | (0°N, 0°E) — 海王星赤道 |
| **模拟时间** | 当地正午 vs 子夜对比 |
| **太阳状态** | 正午：太阳为极小极亮圆盘（0.018°，-20.1 等）
子夜：太阳在地平下 |
| **主导天体** | 无 |
| **预期可见天体清单** | 正午：仅太阳可见
子夜：木星、土星、恒星可见 |
| **预期不可见天体** | 正午：全部其他天体 |
| **星座/深空天体** | 子夜可见 |
| **特殊天象** | 海王星接收到的太阳辐射仅为地球的 1/900；太阳亮度与从地球看木星相当（m ≈ -20 vs -26.7） |
| **环境条件** | 极端寒冷；微弱光照 |
| **校验点** | ① 太阳在海王星天空中的亮度 ≈ 从地球看木星亮度（m ≈ -20）
② 太阳角直径仅约 1.1 角分（接近人眼分辨极限）
③ 正午天空仍较暗（类似地球 deep twilight） |
| **天文依据** | 亮度反比于距离平方：30² = 900 倍衰减 |
