# 木卫四 (Callisto) 星空观测验证用例

**观测者星体**: Callisto (木卫四) — 木星的第四颗伽利略卫星，最外层伽利略卫星  
**无固体表面**: 有（岩石+冰壳，布满陨石坑）  
**大气状态**: 极稀薄 CO₂ 大气  
**母行星**: Jupiter (木星)  

## 星体基本参数

| 参数 | 数值 |
|------|------|
| 距木星中心 | 1,882,709 km |
| 距木星表面 | 约 1,811,000 km |
| 木星角直径（从 Callisto 看） | 约 4.4°（地球上看月球的 **8.8 倍**） |
| 木星视星等（从 Callisto 看） | 约 -18.0（比满月亮约 70 倍） |
| 自转周期 | 16.69 地球日（同步自转） |
| 公转周期 | 16.69 地球日 |
| 表面温度 | -150°C ~ -100°C |

## 测试用例

### TC-CALLISTO-DOM-01：Callisto 面向面观测木星

| 字段 | 内容 |
|------|------|
| **TC-ID** | `CALLISTO-DOM-01` |
| **观测位置** | (0°N, 0°E) — Callisto 面向木星面中央 |
| **模拟时间** | 任意 |
| **太阳状态** | 视轨道位置 |
| **主导天体** | **木星**：潮汐锁定 → 固定在天空。角直径约 **4.4°**（月球 8.8 倍），视星等约 **-18.0**（满月亮 70 倍）。木星圆盘清晰可见。 |
| **预期可见天体清单** | **木星**：Az ≈ 180°，Alt ≈ 90°，角直径 ≈ 4.4°，视星等 ≈ -18.0
木星圆盘：云带可见但角尺寸较小 |
| **预期不可见天体** | 恒星（被木星强光淹没） |
| **星座/深空天体** | 无 |
| **特殊天象** | Callisto 是伽利略卫星中最远离木星的，木星在其天空中仍大且亮（4.4° 直径 = 8.8 倍月球） |
| **环境条件** | 布满陨石坑的冰壳表面；极稀薄大气；木星强光 |
| **校验点** | ① 木星角直径 ≈ 4.4°
② 木星视星等 ≈ -18.0
③ 木星云带可见 |
| **天文依据** | Callisto a=1,882,709 km；木星半径 71,492 km；角直径 = 2×arcsin(71492/1882709) ≈ 4.35° |

### TC-CALLISTO-NIGHT-01：Callisto 背向面夜间

| 字段 | 内容 |
|------|------|
| **TC-ID** | `CALLISTO-NIGHT-01` |
| **观测位置** | (0°N, 180°E) — Callisto 背向面 |
| **模拟时间** | 子夜 |
| **太阳状态** | 地平下 |
| **主导天体** | 木星：不可见 |
| **预期可见天体清单** | **恒星**：清晰
**行星**：地球、金星等
**其他伽利略卫星**：若位于可见天区 |
| **预期不可见天体** | 木星 |
| **星座/深空天体** | 全部可见 |
| **特殊天象** | Callisto 背向面无木星干扰，星空清晰 |
| **环境条件** | 无大气 |
| **校验点** | ① 木星不可见
② 星空清晰 |
| **天文依据** | 潮汐锁定 |
