# 土卫五 (Rhea) 星空观测验证用例

**观测者星体**: Rhea (土卫五) — 土星的第二大卫星  
**无固体表面**: 有（冰质表面，反照率高）  
**大气状态**: 极稀薄 O₂/CO₂ 大气  
**母行星**: Saturn (土星)  

## 星体基本参数

| 参数 | 数值 |
|------|------|
| 距土星中心 | 527,040 km |
| 距土星表面 | 约 411,000 km |
| 土星角直径（从 Rhea 看） | 约 8.5°（地球上看月球的 **17 倍**） |
| 土星视星等（从 Rhea 看） | 约 -16.0（比满月亮约 25 倍） |
| 土星环角直径（从 Rhea 看） | 约 18-20° |
| 自转周期 | 4.52 地球日（同步自转） |
| 公转周期 | 4.52 地球日 |
| 表面温度 | -174°C |
| 表面反照率 | 0.6 |

## 测试用例

### TC-RHEA-DOM-01：Rhea 面向面观测土星

| 字段 | 内容 |
|------|------|
| **TC-ID** | `RHEA-DOM-01` |
| **观测位置** | (0°N, 0°E) — Rhea 面向土星面中央 |
| **模拟时间** | 任意 |
| **太阳状态** | 视轨道位置 |
| **主导天体** | **土星**：潮汐锁定 → 固定在天空。角直径约 **8.5°**（月球 17 倍），视星等约 **-16.0**（满月亮 25 倍）。土星环极宽。 |
| **预期可见天体清单** | **土星**：Az ≈ 180°，Alt ≈ 90°，角直径 8.5°，视星等 -16.0
**土星环**：角直径约 18-20°，极为壮观
**太阳**：角直径 0.055° |
| **预期不可见天体** | 恒星（若系统模拟稀薄大气散射） |
| **星座/深空天体** | 无 |
| **特殊天象** | 从 Rhea 看土星环比从 Titan 看更宽（Rhea 更靠近土星） |
| **环境条件** | 冰质表面；极稀薄大气；土星强光 |
| **校验点** | ① 土星角直径 ≈ 8.5°
② 土星视星等 ≈ -16.0
③ 土星环角直径 > 18°
④ 卡西尼缝可见 |
| **天文依据** | Rhea a=527,040 km；土星半径 60,268 km；角直径 = 2×arcsin(60268/527040) ≈ 8.46° |

### TC-RHEA-SAT-01：从 Rhea 观测其他土星卫星

| 字段 | 内容 |
|------|------|
| **TC-ID** | `RHEA-SAT-01` |
| **观测位置** | (0°N, 0°E) — Rhea 面向面 |
| **模拟时间** | 其他卫星接近时 |
| **太阳状态** | 任意 |
| **主导天体** | **土星**：固定在天空 |
| **预期可见天体清单** | **Titan**：从 Rhea 看角直径约 0.5-1.0°，视星等约 -5.0
**Enceladus**：角直径约 0.1-0.3°，视星等约 -2.0
**Dione**：若存在，角直径约 0.2-0.4° |
| **预期不可见天体** | 恒星 |
| **星座/深空天体** | 无 |
| **特殊天象** | 多卫星互视，快速轨道运动 |
| **环境条件** | 冰质表面；土星强光 |
| **校验点** | ① Titan 可见且明亮
② 其他卫星快速移动 |
| **天文依据** | 土星卫星轨道间距相对较小，互视明显 |
