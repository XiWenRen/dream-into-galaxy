# 木星 (Jupiter) 星空观测验证用例

**观测者星体**: Jupiter (木星)  
**无固体表面**: 无（气态巨行星，假设在云层顶部 ~0.1-1 bar）  
**大气状态**: 浓密 H₂/He 大气  
**卫星数量**: 79+（4 颗伽利略卫星为最大）  

## 星体基本参数

| 参数 | 数值 |
|------|------|
| 距太阳平均距离 | 5.204 AU (778.5×10⁶ km) |
| 太阳角直径 | 0.10°（地球上看太阳的 1/5） |
| 太阳视星等 | -24.5（比地球暗 16 倍） |
| 自转周期 | 9h 55m 30s（太阳系最快自转） |
| 自转轴倾角 | 3.1°（几乎无季节变化） |
| 云层顶部气压参考 | ~0.1-1 bar（作为"表面"参考） |
| 云层顶部温度 | 约 -140°C |
| 可见光大气光学深度 | 云层顶部 τ ≈ 1-10（可见光无法穿透深层） |

## 测试用例

### TC-JUPITER-DAY-01：木星云层顶部正午观测太阳

| 字段 | 内容 |
|------|------|
| **TC-ID** | `JUPITER-DAY-01` |
| **观测位置** | (0°N, 0°E) — 木星赤道云层顶部 |
| **模拟时间** | 木星当地正午 |
| **太阳状态** | 太阳在天空中较小但明亮，Az = 180°，Alt ≈ 90°，角直径 ≈ 0.10°，视星等 ≈ -24.5 |
| **主导天体** | 无（木星自身为气态巨行星，无固体表面主导天体概念；但若在云层顶部，木星自身占据整个下方视野） |
| **预期可见天体清单** | **太阳**：Az 180°，Alt ≈ 90°，角直径 0.10°（地球 1/5），视星等 -24.5，呈白色小圆盘 |
| **预期不可见天体** | 恒星（被浓密云层散射淹没）
行星（除土星在特定配置外）
卫星（白天被日光淹没） |
| **星座/深空天体** | 无 |
| **特殊天象** | 木星自转极快（9.9h），太阳在天空中移动迅速；一天只有约 10 小时 |
| **环境条件** | 木星云层顶部：
• H₂/He 大气 + 氨/水冰晶云层
• 天空呈黄白色/灰白色（氨云散射）
• 可见光无法穿透深层大气
• 强烈辐射带（但云层顶部观测者不直接暴露） |
| **校验点** | ① 太阳角直径 ≈ 0.10°（近日点 0.11°，远日点 0.09°）
② 太阳视星等 ≈ -24.5（比地球太阳暗约 2.5 个星等）
③ 天空颜色为黄白色/灰白色（#E8E0C0），非蓝色
④ 无恒星可见（云层散射强） |
| **天文依据** | 木星轨道 5.2 AU；太阳角直径 = 0.53°/5.2 ≈ 0.10° |

### TC-JUPITER-NIGHT-01：木星云层顶夜间观测

| 字段 | 内容 |
|------|------|
| **TC-ID** | `JUPITER-NIGHT-01` |
| **观测位置** | (0°N, 0°E) — 木星赤道云层顶部 |
| **模拟时间** | 木星子夜 |
| **太阳状态** | 在地平线以下 |
| **主导天体** | 无（木星自身占据下方） |
| **预期可见天体清单** | **土星**：若位于夜天，视星等约 +1.5（从木星看土星距离约 4.3-6.5 AU），呈黄白色
**地球**：视星等约 +2.5（从外行星看地球）
**金星**：视星等约 +1.0（若位于夜天）
**卫星**：伽利略卫星在木星附近夜天可见，但云层顶部视角下...实际上从木星云层顶部无法直接看到卫星（它们在上方天空） |
| **预期不可见天体** | 恒星（木星云层顶部大气仍散射光线，即使夜间也有背景光） |
| **星座/深空天体** | 可能可见亮恒星（若高层大气足够透明） |
| **特殊天象** | 木星极光（若位于极区）：巨大、持久的紫外/可见光极光，比地球极光亮数百倍 |
| **环境条件** | 木星云层顶部夜间：仍可能有残余散射光；温度约 -140°C |
| **校验点** | ① 土星应作为最亮外行星可见（m ≈ +1.5）
② 天空背景趋近黑色但可能有残余散射
③ 木星极光在极区应可见（如系统模拟） |
| **天文依据** | 木星-土星距离 4.3-6.5 AU（共轨共振周期约 20 年） |

### TC-JUPITER-ATM-01：木星大气层深度对观测的影响

| 字段 | 内容 |
|------|------|
| **TC-ID** | `JUPITER-ATM-01` |
| **观测位置** | 木星不同高度层 |
| **模拟时间** | 任意 |
| **太阳状态** | 随深度增加而迅速衰减 |
| **主导天体** | 无 |
| **预期可见天体清单** | **云层顶部（~0.1 bar）**：太阳可见（模糊），无恒星
**氨云层（~1 bar）**：太阳极暗，天空呈灰白色
**水云层（~5 bar）**：太阳不可见，完全黑暗
**深层（> 10 bar）**：完全黑暗，高压高温 |
| **预期不可见天体** | 所有天体（随深度增加） |
| **星座/深空天体** | 无 |
| **特殊天象** | 木星大气分层：氨云 → 硫化铵云 → 水云 → 深层大气 |
| **环境条件** | 不同高度层：
• 0.1 bar：-140°C，氨冰晶云
• 1 bar：-100°C，氨云
• 5 bar：+20°C，水云
• > 10 bar：> 100°C，完全黑暗 |
| **校验点** | ① 不同高度层天空亮度/颜色应不同
② 深层完全无光照（木星不发光，仅反射太阳光）
③ 云层顶部是唯一能"看到天空"的层级 |
| **天文依据** | Galileo 探测器进入木星大气数据；Juno 任务微波探测 |
