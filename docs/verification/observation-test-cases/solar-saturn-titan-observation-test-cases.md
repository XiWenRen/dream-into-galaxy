# 土卫六 (Titan) 星空观测验证用例

**观测者星体**: Titan (土卫六) — 土星最大的卫星，太阳系第二大卫星  
**无固体表面**: 有（岩石核心+水冰地壳+碳氢化合物湖泊）  
**大气状态**: 浓密 N₂/CH₄ 大气（表面气压 1.47 bar）  
**母行星**: Saturn (土星)  

## 星体基本参数

| 参数 | 数值 |
|------|------|
| 距土星中心 | 1,221,870 km |
| 距土星表面 | 约 1,106,000 km |
| 土星角直径（从 Titan 看） | 约 5.7°（地球上看月球的 **11 倍**） |
| 土星视星等（从 Titan 看） | 约 -14.8（比满月亮约 10 倍） |
| 土星环角直径（从 Titan 看） | 约 12.8°（A环外缘） |
| 自转周期 | 15.95 地球日（同步自转，潮汐锁定） |
| 公转周期 | 15.95 地球日 |
| 表面温度 | -179°C |
| 大气成分 | N₂ 98.4%，CH₄ 1.4%，H₂ 0.1% |
| 可见光光学深度 | τ ≈ 1.3（0.55 μm） |

> **注意**: 完整 Titan 用例集（含 6 个详细用例）已在大纲文档中定义。本文档为核心验证。

## 测试用例

### TC-TITAN-DOM-01：Titan 面向面观测土星

| 字段 | 内容 |
|------|------|
| **TC-ID** | `TITAN-DOM-01` |
| **观测位置** | (0°N, 0°E) — Titan 面向土星面中央 |
| **模拟时间** | 任意 |
| **太阳状态** | 视土星公转位置 |
| **主导天体** | **土星**：潮汐锁定 → 固定在天空。角直径约 **5.7°**，视星等 **-14.8**。
土星环角直径约 **12.8°**，卡西尼缝可见。
天空呈永恒橙黄色（大气散射）。 |
| **预期可见天体清单** | **土星**：Az ≈ 180°，Alt ≈ 90°，角直径 5.7°，视星等 -14.8
**土星环**：角直径 12.8°，卡西尼缝可见
**太阳**：角直径 0.055°，视星等 -21.8 |
| **预期不可见天体** | 恒星（大气 τ≈1.3 遮挡）
行星 |
| **星座/深空天体** | 几乎不可见 |
| **特殊天象** | 土星固定不动；浓密大气使天空永远橙黄色 |
| **环境条件** | 浓密 N₂/CH₄ 大气；τ≈1.3；天空橙黄色；表面温度 -179°C |
| **校验点** | ① 土星角直径 ≈ 5.7° ± 0.2°
② 土星视星等 ≈ -14.8
③ 土星环角直径 > 12°
④ 卡西尼缝可见
⑤ 天空颜色橙黄色（#8B7355）
⑥ 恒星不可见 |
| **天文依据** | Titan a=1,221,870 km；土星半径 60,268 km；角直径 = 2×arcsin(60268/1221870) ≈ 5.66° |

### TC-TITAN-BACK-01：Titan 背向面（无土星）

| 字段 | 内容 |
|------|------|
| **TC-ID** | `TITAN-BACK-01` |
| **观测位置** | (0°N, 180°E) — Titan 背向面 |
| **模拟时间** | 土星冲日期间 |
| **太阳状态** | 在天空中较高位置 |
| **主导天体** | **土星**：完全不可见 |
| **预期可见天体清单** | **太阳**：Az ≈ 180°，Alt ≈ 60°，角直径 0.055°
**木星**：可能可见（m ≈ -2.0） |
| **预期不可见天体** | 土星（背向面）
恒星（大气遮挡） |
| **星座/深空天体** | 无 |
| **特殊天象** | 背向面 42 年看不到土星（土星公转周期的一半） |
| **环境条件** | 无土星光照，但大气仍散射阳光 |
| **校验点** | ① 土星不可见
② 太阳为主光源
③ 天空仍橙黄色 |
| **天文依据** | 潮汐锁定卫星背向面看不到母行星 |

### TC-TITAN-ATM-01：Titan 大气对星空遮挡

| 字段 | 内容 |
|------|------|
| **TC-ID** | `TITAN-ATM-01` |
| **观测位置** | (0°N, 0°E) — Titan 表面 |
| **模拟时间** | 背向面子夜 |
| **太阳状态** | 地平下 |
| **主导天体** | 土星：地平下或低空 |
| **预期可见天体清单** | **无恒星可见**（τ≈1.3）
**无行星可见** |
| **预期不可见天体** | 全部天体（大气遮挡） |
| **星座/深空天体** | 无 |
| **特殊天象** | Titan 表面"夜空"非黑色，而是暗橙黄色（大气散射） |
| **环境条件** | τ≈1.3；N₂/CH₄ 大气；天空暗橙黄色 |
| **校验点** | ① 天空亮度 > 0.1（非纯黑）
② 天空颜色暗橙黄色
③ 恒星透明度 < 0.05 |
| **天文依据** | Tomasko et al. (2005) Huygens DISR: τ ≈ 1.3 at 0.55 μm |
